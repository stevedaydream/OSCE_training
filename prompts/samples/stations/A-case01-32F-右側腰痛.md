# 2. 第一印象與危險分流

**這一題的每一條生活史都在指路，而且它們指向不只一個方向。**

### 憋尿 → 感染那條線

尿液滯留在膀胱裡愈久，細菌繁殖的機會愈多。加上**女性尿道短**，泌尿道感染的機率本來就遠高於男性。
**「常憋尿」是很具體的風險因子，不是無關的生活描述。**

### 大量飲茶 → 結石那條線

【推論】這一條容易被當成閒聊帶過，但它有兩層意義：

1. **茶含草酸**，長期大量攝取會提高**草酸鈣結石**的風險
2. **以茶代水**——很多人覺得「我喝很多水啊，我一直在喝茶」，但實際的**有效水分攝取不足**，
   尿液濃縮，結石更容易形成

**這條線索的價值不只在診斷，更在衛教**：對她講「要多喝水」是沒有用的，她會說她一直在喝。
要講的是**「把茶換成白開水」**。

### 右側腰痛放射至下腹 → 輸尿管絞痛的走向

疼痛沿輸尿管走行往下轉位：腰 → 側腹 → 下腹 → 鼠蹊。
**單純的腎盂腎炎疼痛多半固定在腰部、持續而不放射**——**這個放射的型態，是本題最偏向結石的一項。**

### 頻尿兩週 → 位置的線索

【推論】上段的結石不會造成頻尿。會刺激膀胱造成頻尿急尿的，是**已經下移到輸尿管下段、
靠近膀胱交界處的結石**。所以這兩週的頻尿，可能是結石一路往下移動的紀錄。
（但要注意：**女性的頻尿兩週，最常見的解釋仍然是單純的泌尿道感染**，兩者無法只靠這一項分開。）

### 發燒 → 這一項改變整題的性質

**單純的結石不發燒。**
一旦「阻塞」加上「發燒」，要想的就是——**阻塞的上游是不是已經變成一個封閉的膿腔。**

### 生命徵象怎麼讀【推論】

- **T 38.0 ＋ HR 90**：發燒到 38 度，心跳只有 90 **偏低而不是偏高**。不要因為心跳還好就安心。
- **32 歲女性血壓 150/67，這個數字不正常。** 最可能是疼痛引起的交感神經反應，
  但**不能直接歸因於痛就算了**——要問她平常的血壓，並在急性期過後追蹤。
- **RR 20** 在正常上限。**呼吸速率是敗血症最早變化的生命徵象之一**，要追蹤而不是看過就算。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **阻塞性腎盂腎炎（膿腎）** | 結石 ＋ 發燒 = 抗生素治不好的那一種 | **腎臟超音波看水腎 ＋ 尿液看膿尿** |
| **敗血症** | 已發燒兩天，RR 20 在上限 | 意識、末梢灌流、lactate |
| **懷孕（含異位妊娠）** | 32 歲女性，下腹痛，**且會改變影像與用藥** | **驗孕，非驗不可** |
| 卵巢囊腫扭轉／骨盆腔發炎 | 右側痛放射至下腹，位置重疊 | 婦科病史、下腹壓痛型態 |
| 急性闌尾炎 | 右側痛放射至下腹 | 腹部觸診、反彈痛、有無食慾不振先行 |

> ⚠️ **驗孕在這一題不是「順便」，是硬性要求。** 它同時影響三件事：
> **鑑別診斷**（異位妊娠會致命）、**影像選擇**（要不要讓她吃輻射）、**抗生素選擇**（部分藥物孕期禁用）。

# 3. 焦點式病史（5 分鐘，優先順序由上而下）

## 最優先的五題

1. **「最後一次月經是什麼時候？有沒有可能懷孕？」**
   → **32 歲女性下腹痛，這一題必須問，而且要問得自然不尷尬。** 影響鑑別、影像與用藥
2. **「這兩天有沒有發冷發抖到牙齒打顫？」**
   → **rigor 是菌血症的訊號**，比單純「有發燒」更有分量
3. **「小便有沒有變紅、有沒有血絲？」**
   → 血尿支持結石。**但完全阻塞時可以沒有血尿，沒血尿不能推翻**
4. **「痛起來是一陣一陣的絞痛，還是一直持續？痛的時候你想躺著不動，還是一直翻來翻去？」**
   → **結石病人躁動換姿勢；腹膜炎與腹腔發炎病人不敢動。** 答案本身就有鑑別力
5. **「以前有沒有泌尿道感染過？多久一次？有沒有結石？」**
   → 反覆感染要想結構問題；結石復發率高

## 婦科（本題必問，情境完全沒給）

- 月經週期規不規則？這次月經正常嗎？
- **有沒有不正常的陰道分泌物、有沒有異味？**（骨盆腔發炎）
- 下腹痛跟月經週期有沒有關係？
- 性生活史與避孕方式（**問法要有分寸，可先說明為什麼要問**）

## 生活史（情境給了兩條，要問到量化）

- **「您說常憋尿——大概多久才會去一次？工作是不是不方便離開座位？」**
  → 量化，也是後面衛教的切入點
- **「茶大概一天喝多少？是取代白開水，還是茶跟水都有喝？」**
  → **這一題是本題衛教的關鍵。** 要分清楚她的「有效水分攝取」到底有多少
- 一天總共喝多少水（不含茶）？
- 有沒有在吃鈣片、高劑量維他命 C、利尿劑？

## 其他必問

- 兩週前怎麼開始的？頻尿和腰痛哪一個先出現？
- 解尿會不會燒灼刺痛？有沒有急尿、解不乾淨？
- 這兩天尿量有沒有變少？
- 有沒有噁心嘔吐？
- 有沒有咳嗽、腹瀉、皮膚傷口？（排除其他發燒來源）
- **平常血壓大概多少？**（判讀 150/67 的基準）
- 有沒有糖尿病？有沒有藥物過敏？

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| **沒有懷孕可能、驗孕陰性** | **排除異位妊娠**，並解除影像與用藥的限制 |
| 沒有異常陰道分泌物、無性接觸相關症狀 | 降低骨盆腔發炎 |
| 沒有咳嗽、腹瀉、皮膚傷口 | 降低其他系統的感染來源 |
| 沒有轉移到右下腹的痛、沒有食慾不振先行 | 降低急性闌尾炎 |
| 沒有畏寒發抖、意識清楚 | 降低菌血症（但**不排除**） |

# 4. 焦點式身體評估（5 分鐘，最多 8 項）

| 必做？ | 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **必做** | **一般外觀、姿勢與意識** | 全身 | 「我先看您現在的姿勢跟精神狀況，也跟您說說話。目的是判斷疼痛的型態，同時評估發燒有沒有影響到您的意識。」 | **躁動、一直換姿勢找不到舒服的位置**；意識清楚 | **完全不敢動 → 腹腔內發炎**；意識改變 → 敗血症警訊 |
| **必做** | **末梢灌流與皮膚溫度** | 四肢末梢、軀幹 | 「我摸一下您的手腳跟身體比較溫度。目的是評估發燒對血液循環的影響，這關係到感染的嚴重程度。」 | 末梢溫暖（早期高排血量期） | **濕冷、花斑 → 已進入休克** |
| **必做** | **右側肋脊角叩擊痛（左側對照）** | 雙側後腰肋脊角 | 「請您坐起來稍微前傾，我要輕敲您後腰兩邊，先敲左邊再敲右邊做比較。目的是檢查腎臟有沒有發炎或阻塞。會痛請馬上告訴我。」 | **右側陽性、左側陰性** | 雙側陽性 → 雙側病變，更嚴重 |
| **必做** | **腹部觸診（含下腹與恥骨上）與反彈痛** | 四象限、恥骨上 | 「我要輕壓您的肚子，從離痛最遠的地方開始，也包括下腹膀胱的位置，最後會壓下去再快速放開。目的是找出壓痛位置，也確認腹膜有沒有發炎。會痛請馬上說。」 | **右側腹深部壓痛、無反彈痛**；膀胱不脹 | **右下腹反彈痛 → 闌尾炎**；下腹雙側壓痛 → 骨盆腔發炎 |
| **必做** | **腹部視診（含腹股溝）與腸蠕動音** | 腹部、雙側腹股溝 | 「我要看您的肚子外觀跟鼠蹊部，再用聽診器聽腸子的聲音。目的是看有沒有脹起來或腫塊，也判斷腸道蠕動——因為腎臟的劇痛會讓腸子暫時變慢。我會注意隱私，也會先聽再壓。」 | 腹部平坦、腸音減弱 | 高亢金屬音 → 腸阻塞 |
| **必做** | **心肺聽診與全身皮膚** | 雙肺、心尖、全身 | 「我聽一下您的心音跟呼吸音，也快速看一下皮膚有沒有傷口或紅腫。目的是確認發燒有沒有其他來源。」 | 正常、無傷口 | 局部囉音 → 肺炎；紅腫 → 蜂窩性組織炎 |
| 有時間 | 結膜與黏膜 | 眼瞼結膜、口腔 | 「我看一下您的下眼瞼跟嘴唇，目的是評估有沒有貧血和脫水。」 | 可能偏乾 | 蒼白 → 貧血 |
| 有時間 | **婦科相關評估之轉介判斷** | — | 「如果需要進一步做婦科方面的檢查，我會請醫師評估後安排，並由適當的人員執行。」 | 依病史決定 | 下腹雙側壓痛、分泌物異常 → 需婦科評估 |

**這一題的檢查順序為什麼這樣排**：**前兩項先評估「她有多危險」，第三項之後才問「病灶在哪裡」。**
因為有發燒，敗血症的評估優先於定位——**定位錯了還可以再查，敗血症延誤了追不回來。**

> **與男性版本的差異**：這一題**沒有陰囊檢查**（那是男性用來排除睪丸扭轉的），
> 取而代之的是**下腹雙側的觸診型態**（分辨單側輸尿管痛與雙側骨盆腔發炎），
> 以及**婦科評估的轉介判斷**——內診不是專科護理師在這個情境下該自行執行的項目。

# 5. 需安排的檢查

## 階段一：床邊立即

- **驗孕（尿液 hCG）** ← **本題排第一，不是第三**
  - 目的：排除**異位妊娠**（會致命），並決定影像與抗生素的限制
  - **在安排任何有輻射的檢查之前必須有結果**
- **尿液常規 ＋ 尿沉渣** ← **CP 值最高的一項**
  - 目的：**同時回答兩個問題**——有沒有血尿（支持結石）、**有沒有膿尿（感染）**
  - 預期發現：**紅血球 ↑，且白血球酯酶與亞硝酸鹽陽性、見膿尿**
  - **陰性時下一步**：尿液完全乾淨要大幅回頭重想（但**完全阻塞時尿液可以正常**——阻塞側的尿流不下來）
- **尿液培養 ＋ 血液培養兩套** ← **務必在給抗生素之前留取**
- **POCT 血糖 ＋ lactate ＋ 完整生命徵象重測**

## 階段二：非侵入性、無輻射

- **腎臟及膀胱超音波** ← **本題的關鍵檢查，它決定內科病還是外科病**
  - 目的：**看右側有沒有水腎**——這是「阻塞」的間接證據；順帶看膀胱殘尿
  - 預期發現：**右側水腎**
  - **陽性的意義：水腎 ＋ 膿尿 ＋ 發燒 = 阻塞性腎盂腎炎，這不是抗生素治得好的病**
  - 陰性時下一步：無水腎則往**單純急性腎盂腎炎**走
- **骨盆腔超音波**：一併排除卵巢與子宮附件的病灶（同一次檢查、同樣無輻射）

## 階段三：有輻射

- **非顯影低劑量電腦斷層（結石 protocol）**

> **本題我不會先開電腦斷層，而且理由比男性版本更強：她是 32 歲女性、育齡。**
>
> 超音波沒有輻射、床邊五分鐘、當下有答案，而且**它一次回答我需要的兩個問題**——
> 右腎有沒有水腎（泌尿），以及卵巢與子宮附件有沒有病灶（婦科）。
> 這一題我要的不是「結石精確在第幾公分」，是「**上游有沒有塞住**」。
>
> 升級到 CT 的條件：
> 1. **驗孕陰性**（前提）
> 2. 超音波見水腎，需精確定位結石以決定引流方式 → **非顯影低劑量** CT
>    （**找結石不需要顯影劑，打了反而會蓋住結石**）
> 3. 超音波乾淨但病人持續劇痛或臨床惡化
>
> **但這一題真正的重點不是選哪個影像，是不要為了等影像而延後抗生素。**
> 發燒 ＋ 疑似泌尿道感染，**培養留完就該向醫師報告請求評估給藥，不必等超音波排到。**

# 6. 檢驗

**即時（< 15 分）**

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| **尿液 hCG** | **陽性 → 整題重寫**（異位妊娠、影像與用藥限制） |
| **尿液常規** | **紅血球 ↑ → 支持結石；白血球＋亞硝酸鹽 ↑ → 感染。兩者同時陽性 = 本題最擔心的組合** |
| **Lactate** | **↑ → 組織灌流不足，敗血症警訊** |
| 血糖 | ↑↑ → 未診斷的糖尿病，改變風險評估 |

**常規（1 小時內）**

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| CBC/DC | **WBC ↑ 併 left shift → 細菌感染**；**WBC 過低反而是敗血症的壞徵象** |
| CRP、Procalcitonin | ↑ 支持細菌感染 |
| **BUN/Cr** | **↑ → 阻塞已影響腎功能，或敗血症造成的急性腎損傷** |
| 電解質 | — |
| **PT/INR、血小板** | **凝血異常 ＋ 血小板下降 → 敗血症併 DIC 的早期徵象** |
| 尿酸、鈣、磷 | 結石成因評估（非急性期必要，但呼應飲茶那條線索） |

**需時間**：**尿液培養 ＋ 血液培養 ×2**——抗生素前務必留取，錯過沒有第二次。

# 7. 前三個鑑別診斷

> **這一題的三格有一個特別的關係：①＋② 同時成立就是 ③。**

## ① 主診斷：右側輸尿管結石併阻塞

**支持證據**
- **右側腰痛放射至下腹部**——輸尿管絞痛沿輸尿管走行轉位的典型型態。
  **這是本題最偏向結石的一項**，因為單純腎盂腎炎的疼痛多半固定在腰部、持續而不放射【已知】

- **頻尿兩週**——【推論】可能是結石已下移至輸尿管下段刺激膀胱【已知＋推論】

**不支持之處（誠實列，本題要講清楚）**
- **32 歲女性不是結石的最典型族群**——結石在男性較常見。這個診斷排第一靠的是**疼痛放射的型態**，
  不是流行病學。
- 情境**完全沒有提到血尿**，也**沒有描述疼痛性質**（絞痛還是持續）。
- **沒有結石病史的資訊。**
- **最重要的一點：單純結石不發燒。** 這個診斷單獨無法解釋 T 38.0，

**確診依據**

## ② 次可能：急性腎盂腎炎（無阻塞）

**為什麼它還留在名單上——而且在這位病人身上，它的分量比男性版本重得多**

- **女性尿道短，泌尿道感染的機率遠高於男性**
- **她「平時常憋尿」**——尿液滯留愈久，細菌繁殖機會愈多。**這是明確的風險因子**
- 發燒 ＋ 右側腰痛 ＋ CVA 叩擊痛 ＋ 頻尿兩週，這四項單獨看**完全就是急性腎盂腎炎**
- **而且對一個 32 歲、有憋尿習慣的女性來說，這個診斷比結石常見得多**

換句話說：**這一題如果只看流行病學，② 應該排第一。它排第二，唯一的理由是「疼痛放射到下腹」這個型態。**

**要出現什麼證據，它才會翻上第一位**
1. **腎臟超音波沒有水腎（決定性）**
2. KUB 與非顯影 CT 看不到結石
3. 尿液見明顯膿尿與菌尿，**但沒有血尿**
4. 疼痛是持續鈍痛而非陣發絞痛，病人不會躁動換姿勢

**翻上來的臨床意義（本題最重要的一段）**
> **② 與 ③ 的差別，就是「抗生素治得好」與「抗生素治不好」的差別。**
>
> - **單純腎盂腎炎** → 靜脈抗生素、輸液、住院觀察，多數會好
> - **合併阻塞** → **抗生素單獨無效**，阻塞的上游是封閉腔室，藥物到不了
>
> 而分辨它們，只需要一台腎臟超音波，五分鐘。

## ③ 不能排除：阻塞性腎盂腎炎（膿腎）

**這一格放的是漏掉會死人的診斷。而在這一題，它不是理論上的可能——線索已經齊了。**

**為什麼必須主動排除**
- **① 的結石造成阻塞，② 的細菌造成感染。這兩件事同時發生，就是 ③。**
- **而這位病人同時具備兩邊的風險因子**：**愛喝茶**（結石）、**常憋尿**（感染）。
  情境給的兩條生活史，剛好一條指向阻塞、一條指向感染
- **膿液被封在腎盂裡出不來**，抗生素無法解決
- **她可能在數小時到一兩天內走向敗血性休克**
- **32 歲、代償能力好**——她今天還能自己走進來，**T 38.0 心跳只有 90**，
  這些都容易讓人低估嚴重度
- **最危險的處置錯誤是**：診斷為腎盂腎炎，給了抗生素，收住院觀察，明天再排超音波

**排除它的最低限度**
> **一台腎臟超音波（看有無水腎）＋ 一份尿液常規（看有無膿尿）。**
>
> 就這兩項，都不需要輻射，加起來不到十五分鐘。
>
> **若水腎 ＋ 膿尿 ＋ 發燒三者同時成立 → 這不是一般病房觀察的問題。**
> 處置是**緊急解除阻塞（輸尿管支架或經皮腎造廔）＋ 靜脈抗生素**，
> 而且要**在給抗生素之前先抽血液培養**。

**3. 血壓恢復正常 → 150/67 確實是疼痛引起的交感神經反應**，不是未診斷的高血壓。
文件第 2 節寫「最可能是疼痛引起的，但不能直接歸因於痛就算了，要追蹤」——**追蹤的結論是正常，
所以那個保留是對的，而且成本只是回診量一次血壓。**

### ① 和 ③ 要不要對調？——不完全是對調

**它們本來就不是兩個不同的診斷，是同一位病人的兩個描述層次：**

- **①** 描述**機械問題**：結石造成阻塞
- **③** 描述**阻塞加上感染之後變成什麼**

真實答案**兩層都包含**。所以這一題的標準答案應該寫成：

> **右側輸尿管結石併阻塞，合併感染（阻塞性腎盂腎炎）**

**A 的推理沒有錯，它只是把同一件事拆成兩格講。** 而拆開是對的——因為考生在門診當下
還不知道有沒有水腎，**必須先想到「這可能只是結石」也可能「已經變成膿腎」，才會去照那台超音波。**

### 這一題進題庫時要保留的重點

1. **考生任務不是認出結石，是認出「結石加發燒是另一回事」**
2. **決策點只有一個**：有沒有水腎 → 決定「抗生素治得好」還是「非引流不可」
3. **兩條生活史各指一邊**：愛喝茶（結石）、常憋尿（感染）
4. **衛教要具體**：不是「多喝水」，是「把茶換成白開水」

### 一點臨床上的不確定（請你判斷）

**教科書對嚴重膿腎的處理順序通常是「先引流、感染控制後再處理結石」**，
因為在感染的阻塞系統裡操作有引發敗血症的風險。
**但她是碎石與放支架一次完成**——這可能代表她**當時感染程度尚可控、沒有到敗血症**，
所以直接做了根本處置。

**這個推論我信心中等，台灣的實務與個案判斷以你為準。**
如果確實是「不夠嚴重才能一次做完」，那這一題還可以再多教一件事：
**同樣是膿腎，嚴重度決定的是「先引流還是一次解決」。** 要不要寫進考官指南由你決定。
