# A-23｜53 歲男性，吞嚥困難

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #23）

53 歲男性，近兩個星期感到逐漸吞嚥困難，因此到門診看病。
過去無特殊健康狀況，抽菸 25 年，一天一包。應酬時才喝酒。父親有高血壓 18 年，75 歲心臟病死亡。母親是糖尿病患者 15 年，目前 70 歲。

---

# 1. 情境事實清單

- 53 歲男性
- **近兩星期**感到**逐漸**吞嚥困難
- 門診就診（非急診）
- 過去無特殊健康狀況
- **抽菸 25 年，一天一包**（約 25 pack-year）
- 應酬時才喝酒
- 父親高血壓 18 年，75 歲心臟病死亡
- 母親糖尿病 15 年，現 70 歲

**情境未給**：體重變化、吞嚥困難是固體還是液體、有無疼痛、有無嘔吐或食物逆流、有無聲音沙啞、有無胸口灼熱、有無檳榔史、職業。

---

# 2. 第一印象與危險分流

**「逐漸」這兩個字是這一題的核心。**

吞嚥困難分兩大類，而分辨它們的關鍵是**病程形狀**：

| 型態 | 病程 | 常見原因 |
| :--- | :--- | :--- |
| **進行性（progressive）** | 從固體開始，**逐漸**連軟食、流質都吞不下 | **機械性阻塞——腫瘤、狹窄** |
| **間歇性（intermittent）** | 時好時壞，固體與液體**同時**有困難 | 動力學問題——食道弛緩不能症、食道痙攣 |

情境明確寫著**「逐漸」**，這指向**機械性阻塞**。
而 53 歲男性 ＋ **25 pack-year 的抽菸史** ＋ 短時間內進行性吞嚥困難，這個組合要先當成**食道癌**來查，直到證實不是。

**「應酬時才喝酒」不要輕易放過**【推論】：菸與酒對食道鱗狀細胞癌的風險是**相乘而非相加**。「應酬時才喝」聽起來輕描淡寫，但實際頻率與量必須問清楚，不能接受這個模糊的說法。

**這一題最容易被漏掉的一件事**：情境沒有提到檳榔。台灣的菸酒檳榔族群，**頭頸部與食道是同一個「場域癌化（field cancerization）」的區域**——同一批致癌物暴露整片黏膜，所以**可能同時或先後長出多顆腫瘤**。這決定了檢查範圍不能只看食道。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **食道癌** | 進行性吞嚥困難 ＋ 25 pack-year | 上消化道內視鏡併切片 |
| **下咽／咽喉癌** | 同一菸酒風險族群，症狀重疊 | **內視鏡必須含咽喉部檢查**；問聲音沙啞 |
| 誤嚥性肺炎 | 吞嚥困難的立即併發症 | 問有無嗆咳、發燒；聽診 |
| 已有轉移或侵犯 | 兩週的自述可能低估實際病程 | 頸部與鎖骨上淋巴結、聲音沙啞 |

# 3. 焦點式病史

## 把吞嚥困難問清楚（這是本題的主戰場）

**最關鍵的四題：**

1. **「是吞固體困難，還是連喝水也困難？」**
   → **先固體、後液體 = 機械性阻塞（腫瘤／狹窄）**；**固體與液體同時困難 = 動力學問題**
   → 這一題的答案幾乎決定了診斷方向

2. **「這兩個星期是越來越嚴重，還是時好時壞？」**
   → 已知「逐漸」，但要親口確認。**進行性惡化強烈支持腫瘤**

3. **「卡住的感覺在哪裡？請用手指出來。」**
   → 指在**頸部** → 口咽或上段食道；指在**胸骨後或劍突** → 中下段食道
   → 註：病人指的位置與實際病灶位置不一定一致，但仍有參考價值

4. **「有沒有東西吞下去又吐出來？吐出來的是還沒消化的食物嗎？」**
   → 未消化食物逆流 → 食道內滯留，支持阻塞或弛緩不能症

**其他必問**
- **吞的時候會痛嗎？**（odynophagia → 潰瘍、感染性食道炎、或腫瘤侵犯）
- 有沒有胸口灼熱、胃酸逆流？**多久了？**（長期逆流 → 巴瑞特食道 → 腺癌；也可能是良性消化性狹窄）
- 有沒有嗆到、咳嗽？**喝水會不會嗆？**（→ 誤嚥風險，或**氣管食道瘻管**）
- 晚上睡覺會不會被嗆醒？

## 紅旗症狀（全部必問，情境完全沒給）

| 問題 | 意義 |
| :--- | :--- |
| **「這兩個月體重掉了幾公斤？」** | **最重要的一題。** 不明體重減輕是惡性腫瘤最強的警訊 |
| **「聲音有沒有變沙啞？」** | **喉返神經受侵犯的徵象，代表腫瘤已侵犯縱膈** |
| 「有沒有解黑便、有沒有貧血的感覺？」 | 腫瘤慢性出血 |
| 「頸部有沒有摸到腫塊？」 | 淋巴轉移 |
| 「有沒有咳嗽、發燒？」 | 誤嚥性肺炎 |
| 「有沒有骨頭痛、背痛？」 | 遠端轉移 |

## 風險因子（本題必問）

- **抽菸**：已知 25 年一天一包。追問**有沒有戒過、實際總量**
- **喝酒**：**「應酬時才喝」是多久一次？一次喝多少？喝幾年？**（不能接受模糊回答）
- **檳榔**：**情境完全沒提，必問。** 台灣男性的重要風險因子
- **飲食習慣**：有沒有吃很燙的食物或熱湯的習慣？（高溫飲食與食道癌的關聯）
- 有沒有誤食過強酸強鹼？（腐蝕性狹窄，也是日後癌變的風險）
- 家族有沒有人得過食道癌或頭頸癌？
- 職業暴露

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| 沒有長期胃酸逆流病史 | 降低良性消化性狹窄與腺癌 |
| 沒有固體液體同時困難、沒有時好時壞 | 降低食道弛緩不能症與食道痙攣 |
| 沒有吞嚥疼痛、沒有免疫低下 | 降低感染性食道炎（念珠菌、疱疹） |
| 沒有誤食腐蝕性物質、沒有長期服用特定藥物 | 降低腐蝕性與藥物性狹窄 |
| 沒有聲音沙啞、沒有頸部腫塊 | 降低已侵犯縱膈或淋巴轉移（但不排除） |

# 4. 焦點式身體評估

**吞嚥困難的身體評估重點是：找轉移、評估營養、評估誤嚥風險。** 食道本身摸不到、聽不到，所以身評的價值在周邊，不在食道。

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| **營養狀態評估** | 全身、顳肌、鎖骨、上臂 | 「我先看您整體的狀況，特別是有沒有變瘦，還有量一下體重。目的是評估這兩個星期吃不下對營養的影響，這會影響後面能不能承受治療。」 | **可能消瘦、顳肌凹陷** | 惡病質 → 腫瘤已進展 |
| **口腔與咽喉視診** | 口腔黏膜、舌根、扁桃腺、咽後壁 | 「請您張開嘴巴、伸出舌頭並發『啊』。我要用壓舌板和燈光看您的口腔和喉嚨，目的是檢查有沒有潰瘍、白斑或腫塊，因為抽菸喝酒的人這些位置也可能有問題。」 | **正常**（但必須看，不能跳過） | **口腔白斑、紅斑、潰瘍、腫塊 → 頭頸癌** |
| **聲音品質評估** | — | 「請您說一句長一點的話，或者從一數到十。目的是聽您的聲音有沒有沙啞，因為聲帶的神經如果被壓到會影響聲音。」 | **聲音正常** | **沙啞 → 喉返神經受侵犯，腫瘤已侵犯縱膈，分期上升** |
| **頸部淋巴結觸診** | 頸部各區、頜下、頦下 | 「我要從後面摸您的脖子，請您稍微低頭放鬆。目的是檢查淋巴結有沒有腫大。」 | 無腫大 | 硬、固定的淋巴結 → 轉移 |
| **鎖骨上淋巴結觸診** | 雙側鎖骨上窩 | 「我要特別摸您兩邊鎖骨上方的位置，目的是檢查這裡的淋巴結，因為胸腔和腹腔的腫瘤會轉移到這裡。」 | **無腫大** | **摸到硬結 → 遠端轉移，治療方向完全改變** |
| **甲狀腺觸診** | 頸前 | 「請您吞一口口水，我摸您頸部前面，目的是確認甲狀腺有沒有腫大壓到食道。」 | 正常 | 巨大甲狀腺腫 → 外在壓迫 |
| 心肺聽診 | 雙肺各葉 | 「我要聽您的呼吸音，目的是確認有沒有因為嗆到造成的肺部感染。」 | **正常** | **右下肺囉音 → 誤嚥性肺炎** |
| 腹部觸診（含肝臟） | 腹部、右上腹 | 「我要摸您的肚子和肝臟的位置，目的是初步確認有沒有轉移到肝臟或腹腔。」 | 正常 | 肝腫大、表面不平 → 肝轉移 |
| 貧血徵象 | 眼瞼結膜、指甲 | 「我看一下您的下眼瞼和指甲，目的是檢查有沒有貧血。」 | 可能蒼白 | 蒼白 → 慢性失血或營養不良 |

> **本題最容易被漏掉的三項：口腔咽喉視診、聽聲音、鎖骨上淋巴結。**
> 這三項都不需要儀器，加起來不到三分鐘，卻分別回答「有沒有第二顆腫瘤」「有沒有侵犯縱膈」「有沒有遠端轉移」。
> 一個抽菸 25 年的吞嚥困難病人，**不看口腔就直接安排胃鏡，是很典型的漏診路徑**。

# 5. 需安排的檢查

## 階段一：門診當下可做

- 體重、BMI，**與病人自述的兩個月前體重比對**
- 口腔咽喉視診（上一節）
- 生命徵象

## 階段二：非侵入性

- **胸部 X 光**
  - 目的：初步看縱膈是否增寬、有無肺部病灶或誤嚥性肺炎
  - 預期發現：可能完全正常。**正常不能排除食道癌**
- **頸部超音波**（若摸到淋巴結）

## 階段三：內視鏡與影像

- **上消化道內視鏡（胃鏡）併切片** ← **本題的第一線檢查，不是第二線**
  - 目的：**直接看到病灶並取組織**
  - 預期發現：食道中段可見腫瘤性狹窄或潰瘍性病灶
  - **必須同時檢查咽喉部**（呼應場域癌化的風險）
  - 優點：**診斷與病理一次完成**

> **這一題的檢查順序和前面幾題的邏輯不一樣，值得講清楚。**
>
> 前面的原則是「能回答同一個問題時，選成本低的」。
> 但吞嚥困難這一題，**成本低的檢查回答不了關鍵問題**：
> - 胸部 X 光可能完全正常
> - 鋇劑食道攝影（barium swallow）可以看到狹窄的形狀，**但取不到組織，也看不到早期黏膜病變**
> - 超音波在這個部位幾乎沒有角色
>
> **而「這是不是癌」這個問題，只有病理能回答。**
> 所以本題**內視鏡是第一線而非第二線**——它是唯一能同時完成「看到」與「取樣」的檢查。
> 為了避免內視鏡的侵入性而先做鋇劑攝影，結果是多做一次檢查、延後兩週、然後還是要做內視鏡。
>
> **例外**：若高度懷疑**氣管食道瘻管**（喝水嗆咳嚴重），此時應先做**水溶性顯影劑攝影**再考慮內視鏡，因為鋇劑進入氣管會造成化學性肺炎。這是少數該把影像排在內視鏡前面的情況。

## 分期用（確診後才做）

- **胸腹部電腦斷層（含顯影劑）**：評估侵犯深度、淋巴結、遠端轉移
- **內視鏡超音波（EUS）**：評估腫瘤侵犯的層次與局部淋巴結
- **PET-CT**：偵測遠端轉移
- 支氣管鏡（若腫瘤位置靠近氣管）

> **CT 在這一題的角色是分期，不是診斷。** 順序不能顛倒：先內視鏡確定是什麼，再用 CT 決定能不能開刀。

# 6. 檢驗

**這一題的抽血不診斷疾病，是評估病人「撐不撐得住」。** 這一點要主動說明。

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| CBC/DC | **Hb ↓ 小球性貧血 → 腫瘤慢性出血或營養不良** |
| **Albumin、Prealbumin** | **↓ → 營養不良。這是本題最重要的一組**，直接影響手術與化放療的耐受度 |
| 電解質 | 兩週進食困難 → 低血鈉、低血鉀 |
| BUN/Cr | 脫水評估；顯影劑前必要值 |
| 肝功能、ALP | ↑ → 肝轉移 |
| 鈣、ALP | ↑ → 骨轉移（特異度低） |
| PT/INR、血型 | 切片與手術前準備 |
| CRP | 若懷疑誤嚥性肺炎 |

**腫瘤標記（如 SCC、CEA）**
> ⚠️ **不能用於診斷，也不能用於排除。** 角色僅為治療後追蹤的基準值。口試提到時務必主動說明限制。

# 7. 前三個鑑別診斷

## ① 主診斷：食道癌

**支持證據**
- **進行性（逐漸惡化）的吞嚥困難**——機械性阻塞的典型病程【已知】
- **抽菸 25 pack-year**——食道鱗狀細胞癌最強的風險因子之一【已知】
- **飲酒**（雖自述僅應酬）——與抽菸有**相乘**效果【已知】
- **53 歲男性**——好發族群【已知】
- 過去無特殊健康狀況 → 不像慢性逆流造成的良性狹窄【已知】
- 預期：內視鏡見腫瘤性病灶、切片病理確診【推論】

**不支持之處（誠實列）**
- **情境完全沒有提到體重減輕**。這是惡性腫瘤最重要的支持證據，沒問到就缺一大角。
- 情境未說明是固體還是液體吞嚥困難——**而這一題是分辨機械性與動力學的關鍵**。
- **兩星期的病程對食道癌來說偏短**。食道管腔要被塞到出現症狀，通常已經長了一段時間。這代表：要嘛病人低估了實際病程（很常見，早期只是「偶爾覺得卡卡的」被忽略），要嘛是別的原因。**這一點要在問診時往回推。**
- 情境未提供聲音沙啞、頸部腫塊等侵犯徵象。

**確診依據**
> **上消化道內視鏡直視病灶 ＋ 切片病理。只有病理能確診。**

---

## ② 次可能：良性食道狹窄（消化性狹窄）／食道弛緩不能症

**為什麼它們還留在名單上**

**良性消化性狹窄**：長期胃食道逆流造成下段食道慢性發炎與纖維化。它的吞嚥困難**也是進行性的、也是先固體後液體**，與腫瘤在症狀上高度重疊。

**食道弛緩不能症（achalasia）**：下食道括約肌無法放鬆。特點是**固體與液體同時困難、時好時壞、常有未消化食物逆流**，病程通常數月到數年。

**要出現什麼證據，它們才會翻上第一位**
1. 問出**長期（數年）的胸口灼熱與胃酸逆流病史** → 支持消化性狹窄
2. 問出**固體與液體同時困難、時好時壞、病程很長** → 支持弛緩不能症
3. **沒有體重減輕**、營養狀態良好
4. 內視鏡見**平滑、對稱的狹窄，黏膜完整無腫瘤**
5. 弛緩不能症：食道測壓（manometry）異常

**翻上來的臨床意義**：從「腫瘤分期、決定手術或化放療、告知癌症診斷」變成「**內視鏡擴張術、氫離子幫浦抑制劑、或氣球擴張／肌肉切開術**」。預後與談話內容天差地別。

> **但這裡有一個重要的原則**：**即使內視鏡看起來像良性狹窄，仍然要切片。**
> 因為腫瘤可以長在狹窄處，外觀不一定典型。**看起來良性 ≠ 良性。**

---

## ③ 不能排除：下咽／咽喉部惡性腫瘤

**這一格放的是最容易被整個跳過的診斷。**

**為什麼必須主動排除**
- **「場域癌化」**：菸與酒的致癌物會暴露**整片上呼吸消化道黏膜**——口腔、咽、喉、食道是同一個受害區域。所以這個族群**可能同時或先後長出多顆原發腫瘤**
- **症狀完全重疊**：下咽癌也表現為吞嚥困難、異物感、頸部腫塊
- **最危險的錯誤是：安排了胃鏡，只看食道到胃，沒有仔細看咽喉部，報告寫「食道未見異常」就結案。** 病人的腫瘤在更上面，而且從頭到尾沒有人看過那個位置
- 台灣的菸酒檳榔族群，頭頸癌極為常見

**排除它的最低限度**
> **一次口腔與咽喉的直視檢查（壓舌板 ＋ 光源）＋ 聽病人說話評估聲音 ＋ 摸頸部淋巴結。**
> **並在安排內視鏡時，明確要求檢查範圍包含咽喉部。**

這三項在門診當場就能做完，不到三分鐘，不需要任何儀器。
若發現口腔黏膜白斑、紅斑、潰瘍，或聲音沙啞、頸部淋巴結腫大 → **同時轉介耳鼻喉科**，不要只轉腸胃科。

# 8. 口試委員最可能追問的五題

**Q1「吞嚥困難，你第一個要問的是什麼？」**
> **「是吞固體困難，還是連喝水也困難？」**
> 因為這一題的答案幾乎決定方向：**先固體、後液體代表機械性阻塞**，也就是腫瘤或狹窄；**固體和液體同時困難、而且時好時壞，代表動力學問題**，像食道弛緩不能症。
> 加上情境已經寫了「逐漸」，兩者合起來讓我優先往機械性阻塞去查。

**Q2「兩個星期的病程，會不會太短，不像癌症？」**
> 我也覺得偏短，所以我會**往回推**。食道的管腔要被塞到出現症狀，通常已經長了一段時間。
> 很多病人早期只是「偶爾覺得卡卡的」「吃乾的東西要配水」，不會當成症狀，所以我會問「您上一次吃東西完全沒有感覺的時候是什麼時候？」而不是接受「兩個星期」這個數字。
> 如果往回推真的就是兩週而且完全沒有前驅，那我會重新考慮別的原因。

**Q3「你為什麼直接安排胃鏡，不先做食道鋇劑攝影？」**
> 因為這一題要回答的問題是「這是不是癌」，而**只有病理能回答**。
> 鋇劑攝影看得到狹窄的形狀，但取不到組織，也看不到早期的黏膜病變。做了之後我還是得做胃鏡，等於多一次檢查、多等兩週。
> 內視鏡是唯一能同時「看到」和「取樣」的檢查，所以在這一題它是第一線不是第二線。
> **但有一個例外**：如果病人喝水嗆得很厲害、懷疑氣管食道瘻管，那要先做水溶性顯影劑攝影，因為鋇劑跑進氣管會造成化學性肺炎。

**Q4「他抽菸 25 年，除了食道你還會看哪裡？」**
> **口腔和咽喉。** 菸和酒的致癌物暴露的是整片上呼吸消化道黏膜，我們叫場域癌化，所以這個族群可能同時長出好幾顆腫瘤。
> 我會用壓舌板加燈光看口腔、舌根、咽後壁，聽他說話評估有沒有聲音沙啞，再摸頸部和鎖骨上淋巴結。這三項不到三分鐘、不用任何儀器。
> 而且我在安排內視鏡的時候，會明確要求檢查範圍要包含咽喉部——**不然報告寫「食道未見異常」，腫瘤在更上面，就整個漏掉了。**

**Q5「請向病人解釋。」**
> 先生，您這兩個星期越來越難吞，而且是慢慢變嚴重的，這種型態通常代表食道有東西擋住了。
> 我剛才檢查了您的口腔和喉嚨、聽了您的聲音、也摸過頸部淋巴結。接下來我會安排一個胃鏡，從嘴巴放一根細的管子看食道，同時如果看到不正常的地方，會夾一小塊組織去化驗。**這是唯一能確定是什麼的方法**，照 X 光看不出來。
> 我也會請他們檢查的時候順便看一下喉嚨的部分，因為長期抽菸的人這幾個位置都要一起看。
> 這段時間請您吃軟一點、細嚼慢嚥，喝水如果會嗆到，一定要告訴我。**嗆到不是小事，會造成肺炎。**
> 另外，不管檢查結果是什麼，戒菸這件事我希望您現在就開始，我可以幫您轉介戒菸門診。

**SBAR 骨幹**
- **S**：53 歲男性，近兩星期**逐漸**加重的吞嚥困難。
- **B**：抽菸 25 年一天一包（約 25 pack-year），應酬飲酒（實際量待確認），檳榔史待確認。過去無特殊健康狀況。體重變化待確認。
- **A**：（依理學填）營養狀態 ___、體重變化 ___、口腔咽喉視診 ___、聲音 ___、頸部與鎖骨上淋巴結 ___、肺部聽診 ___。**最可能為食道癌**；因症狀與良性狹窄高度重疊，**良性消化性狹窄或食道弛緩不能症不能排除**；因病人屬菸酒族群且存在場域癌化風險，**須主動排除下咽或咽喉部惡性腫瘤**。
- **R**：建議安排**上消化道內視鏡併切片，且檢查範圍需包含咽喉部**；胸部 X 光；抽 CBC/DC、Albumin、電解質、BUN/Cr、肝功能、PT/INR。衛教軟質飲食與誤嚥風險。確診後再安排胸腹 CT 進行分期。轉介腸胃科，若口腔咽喉有異常則同時轉介耳鼻喉科。**併轉介戒菸門診。**

# 9. 我不確定的地方

1. **菸酒對食道癌風險的「相乘效果」**——我知道兩者合併風險遠高於單獨，但**確切的倍數不要在口試講**。
2. **食道癌在台灣的組織型態分布（鱗狀細胞癌 vs 腺癌）**——我推測台灣以鱗狀細胞癌為主（與菸酒檳榔相關），西方以腺癌為主（與逆流、肥胖相關），但確切比例請查證。
3. **「兩星期」對食道癌是否真的偏短**——這是我的臨床判斷，信心中等。若你認為兩週完全可能，第 7 節「不支持之處」那一條可以拿掉。
4. **鋇劑造成化學性肺炎的嚴重度**——我知道要避免，但實際風險程度我沒有把握。
5. **內視鏡超音波（EUS）在台灣的可及性與健保給付**——各院差異大，若被追問建議答「視醫院設備與腸胃科評估」。
6. **場域癌化（field cancerization）的正式定義與證據強度**——概念方向我有把握，但若被追問細節請保守。
7. **檳榔與食道癌的關聯**——我知道檳榔與口腔癌關聯極強，與食道癌的關聯強度我信心中等。情境沒提檳榔，但在台灣一定要問。
