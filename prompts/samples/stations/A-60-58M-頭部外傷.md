# A-60｜58 歲男性，頭部外傷

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #60）

58 歲男性，頭部外傷。
今天下午不慎於工地的二樓樓梯跌落（約半層樓高），曾短暫失去意識約 30 秒，現左側臉頰淤青，左眼熊貓眼，由同事送至醫院急診室。現在頭很痛、頭暈、很想吐。

# 2. 第一印象與危險分流

**這一題有三件事同時在跑，而且第三件最容易被漏掉。**

### 一、有明確的顱內出血風險指標

情境給了兩個：**短暫失去意識** ＋ **持續頭痛、頭暈、想吐**。
再加上 58 歲、**從高處跌落**這個受傷機轉。這幾項合起來，**頭部電腦斷層在這一題是有明確適應症的，不是可做可不做**。

### 二、「常喝維士比」不是背景資料，是風險因子

**慢性酒精使用者的顱內出血風險顯著較高**，原因有三：
- 腦部萎縮 → 橋靜脈被拉長 → **輕微外力就可能造成硬腦膜下出血**
- 肝功能受損 → **凝血功能可能異常**
- **酒精會混淆意識評估**——你以為的「意識不清是喝酒」，可能是出血

情境還寫了「一星期喝一次酒」，但又寫「**平常常喝維士比**」——**這兩句話互相矛盾，必須問清楚實際飲酒量**。病人低報飲酒量是常態。

### 三、**每一個從高處跌落的頭部外傷，在排除之前都必須當作頸椎損傷**

**這是本題最容易被整個跳過的一件事。** 情境特別寫了「**由同事送至醫院**」——這意味著**沒有頸圈、沒有脊椎板、沒有任何固定**，他可能已經被扶著走、被塞進車裡、坐著顛簸了一路。

**大家的注意力都在那顆頭上，而頸椎是漏掉會癱瘓的那一個。**

### 「左眼熊貓眼」怎麼解讀【推論，重要】

**熊貓眼（raccoon eyes）是顱底骨折的典型徵象，但它通常在受傷後數小時到數天才會出現。**
**受傷當天下午就出現的眼周瘀青，更可能是左臉頰直接撞擊造成的局部瘀血**，而不是顱底骨折。

**但這不代表可以放心**——它代表**左側顏面受到直接、明顯的撞擊力**，而這個力道足以傳導到顱底。所以仍要主動檢查顱底骨折的其他徵象。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **顱內出血（硬腦膜上／下出血）** | LOC ＋ 持續頭痛嘔吐 ＋ 慢性飲酒 | **GCS、瞳孔、頭部 CT** |
| **頸椎損傷** | 高處跌落 ＋ **未經固定送醫** | **立即上頸圈**，再依規則決定影像 |
| 顱底骨折 | 左臉直接撞擊 | Battle's sign、耳鼻漏液、鼓室積血 |
| 顏面骨折（眼眶、顴骨） | 左臉頰淤青 ＋ 眼周瘀血 | 眼球運動、複視、臉部感覺、咬合 |

# 3. 焦點式病史

> ⚠️ **這一題的順序和其他題不同：先固定頸椎、先評估 ABC 與 GCS，再問病史。**
> 不要一邊問 LQQOPERA 一邊讓病人自由轉頭。

## 受傷機轉（必須問到，最好問目擊的同事）

- **從幾樓、多高跌下來？落在什麼材質的地面？**
- **哪個部位先著地？頭有沒有直接撞到？**
- **是自己滑倒，還是先昏倒才跌下去？** ← **這一題極重要**
  → 若是**先昏倒才跌落**，那要找的是昏倒的原因（心律不整、癲癇、中風、低血糖），外傷只是結果
- 有沒有戴安全帽？
- **昏迷多久？中間有沒有清醒過？**
- **從受傷到現在，意識有沒有變差？** ← **「清醒期（lucid interval）後再度惡化」是硬腦膜上出血的典型病程**

## 目前症狀

- 頭痛的位置、程度？**是不是越來越痛？**
- **吐了幾次？**（反覆嘔吐是顱內壓上升的徵象）
- 有沒有複視、視力模糊？
- **有沒有頸部疼痛？** ← 必問
- **四肢有沒有麻、無力、刺痛感？** ← 必問
- 有沒有耳鳴、聽力變化？
- **耳朵或鼻子有沒有流血、流出清澈的液體？**（腦脊髓液漏）
- 記不記得受傷當下的事？受傷前的事記得嗎？（順行性／逆行性失憶）

## 用藥與病史（本題最關鍵的一問）

- **「您有沒有在吃阿斯匹靈、保栓通、可邁丁，或任何抗凝血、抗血小板的藥？」**
  → **這一題直接改變顱內出血的風險評估與處置急迫性。情境完全沒提，必問。**
- 有沒有高血壓、糖尿病、心律不整、肝病？
- 有沒有癲癇病史？
- **實際飲酒量：一天喝多少維士比？喝幾年？**（情境自相矛盾，必須釐清）
- 有沒有藥物過敏？
- 破傷風疫苗接種史（有開放性傷口時）

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| 沒有服用抗凝血或抗血小板藥物 | **大幅降低顱內出血風險，也影響是否需要重複 CT** |
| 沒有頸痛、沒有四肢麻木無力 | 降低頸椎損傷（但仍需依規則判斷） |
| 沒有耳鼻流出清澈液體、無 Battle's sign | 降低顱底骨折 |
| 沒有先昏倒才跌落、沒有胸悶心悸 | 降低內科事件導致的跌落 |
| 沒有複視、眼球運動正常 | 降低眼眶骨折併肌肉嵌頓 |

# 4. 焦點式身體評估

> **第一個動作不是問診也不是檢查，是「請您先不要動，我幫您戴上頸圈」。**

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| **頸椎固定（第一優先）** | 頸部 | 「先生，因為您是從樓梯上摔下來的，在確認頸椎沒有受傷之前，我要先幫您戴上頸圈固定。**請您先不要轉頭、不要點頭**。目的是保護您的脊髓。」 | 完成固定 | **這一步沒做 = 本題最重的失分** |
| **ABC 與生命徵象** | — | 「我先確認您的呼吸和血壓、脈搏，目的是評估整體狀況是否穩定。」 | 需取得 | **血壓上升 ＋ 心跳變慢 ＋ 呼吸型態改變 = Cushing reflex，顱內壓上升，緊急** |
| **GCS 評估（E／V／M 分開記錄）** | — | 「我要問您幾個問題也請您做幾個動作，目的是評估您的意識狀態，這個我等一下會重複做，用來比較有沒有變化。」 | 需取得基準值 | **GCS 下降 2 分以上 → 立即重新評估與影像** |
| **瞳孔大小、對稱、對光反射** | 雙眼 | 「我用手電筒照您的眼睛，目的是檢查瞳孔的反應，這反映腦部的壓力狀況。會有點刺眼。」 | 雙側等大、反應正常 | **單側瞳孔放大且反應遲鈍 → 腦疝脫，極度緊急** |
| **頭皮視診與觸診** | 整個頭皮，**含枕部** | 「我要摸您整個頭皮，包括後腦勺，目的是找出有沒有傷口、腫塊或凹陷。會痛請告訴我。」 | 左臉頰淤青 | 凹陷 → 凹陷性顱骨骨折 |
| **顱底骨折徵象** | 耳後乳突、外耳道、鼻孔、眼周 | 「我要看您耳朵後面、耳道裡面和鼻子，目的是檢查有沒有顱底骨折的跡象，例如流血或流出清澈的液體。」 | **左眼周瘀青（已知）；Battle's sign 陰性、無耳鼻漏液** | **Battle's sign、鼓室積血、耳鼻流清澈液 → 顱底骨折** |
| **顏面骨檢查** | 眼眶緣、顴骨、鼻骨、下顎 | 「我要摸您臉部的骨頭邊緣，也請您照著我的手指看，然後張嘴閉嘴。目的是檢查臉部骨頭有沒有骨折。」 | 左臉頰壓痛 | **眼球運動受限、複視、臉頰麻木、咬合不正 → 眼眶或顴骨骨折** |
| **眼球檢查** | 雙眼 | 「請您眼睛跟著我的手指走，目的是檢查眼球運動和有沒有複視。」 | 正常 | 上視受限 → 眼眶底骨折併下直肌嵌頓 |
| **頸椎觸診（頸圈下小心進行）** | 頸椎棘突中線 | 「我要輕壓您頸椎中線的位置，目的是確認有沒有壓痛。請不要自己轉頭，只要告訴我痛不痛。」 | **中線無壓痛**（若有 → 必須影像） | **中線壓痛 → 頸椎損傷高度懷疑** |
| **四肢神經學檢查** | 四肢 | 「我要測您手腳的力氣和感覺，請照我說的動作做。目的是確認脊髓和神經有沒有受影響。」 | **四肢肌力對稱正常、感覺正常** | 任何無力或感覺異常 → 脊髓損傷 |
| 小腦功能與步態 | — | 「如果您狀況允許，我會請您做指鼻動作。**但在頸椎排除之前我不會讓您下床走路。**」 | 需評估 | 共濟失調 → 小腦病灶 |
| 全身次級評估 | 胸、腹、骨盆、四肢 | 「我要快速檢查您的胸部、肚子、骨盆和四肢，目的是確認除了頭之外還有沒有其他地方受傷。」 | 需完成 | **高處跌落常合併胸腹或脊椎、跟骨骨折** |

> **本題的四個關鍵動作：頸圈、GCS、瞳孔、顱底骨折徵象。**
> 而**「重複評估」比「單次評估」更重要**——顱內出血的診斷往往不是靠第一次檢查，而是靠**第二次比第一次差**。
> 這一點要主動說出來：「我會每 15 到 30 分鐘重新評估 GCS 和瞳孔。」

# 5. 需安排的檢查

## 階段一：床邊立即

- **頸椎固定**（不是檢查，但排在所有檢查之前）
- **完整生命徵象、GCS、瞳孔**
- **POCT 血糖** ← **必做**。低血糖會造成意識改變，也可能是跌落的原因
- **12 導程 EKG** ← 若懷疑是「先昏倒才跌落」，這一張排除心律不整
- 血中酒精濃度（若意識評估受干擾）

## 階段二：影像

- **頭部電腦斷層（非顯影）** ← **本題有明確適應症，不能省**
  - 目的：rule out 顱內出血、顱骨骨折、腦水腫
  - **適應症依據**（本例符合多項）：**高處跌落的受傷機轉、意識喪失、持續頭痛、嘔吐、年齡 ≥ 55–65（依規則版本）**
  - 預期發現：依實際而定
  - **⚠️ 首次 CT 正常不能高枕無憂**——**硬腦膜下出血可能延遲出現**，尤其慢性飲酒者與服用抗凝血劑者。需臨床觀察並考慮重複影像
- **頸椎電腦斷層**
  - **適應症判斷**：使用 **NEXUS 準則**或**加拿大頸椎規則**（Canadian C-Spine Rule）
  - **本例的關鍵在於「危險機轉」**——從高處跌落通常已符合需要影像的條件
  - **注意：頸椎 X 光對頸椎骨折的敏感度不足，成人外傷首選為 CT**

> **這一題和前面幾題的邏輯完全相反，必須講清楚，否則會被誤以為前後矛盾。**
>
> 前面幾題我一再強調「能用超音波回答就不要開 CT」。**但那個原則的前提是「有更便宜的檢查能回答同一個問題」。**
> **在頭部外傷這一題，沒有替代品**：
> - 超音波看不到顱內
> - 頭顱 X 光只能看骨折，**看不到出血，而出血才是會死人的那一個**
> - 觀察等待的代價是**不可逆的腦損傷**
>
> **所以檢查排序的原則從來不是「少做 CT」，而是「用最低成本回答關鍵問題」。**
> **在這一題，CT 就是最低成本的答案。**
>
> **同時也要注意反過來的浪費**：如果病人完全清醒、GCS 15、沒有 LOC、沒有嘔吐、沒有危險機轉、沒有服抗凝血劑，那**不做 CT 才是正確的**——這正是 Canadian CT Head Rule 之類的準則存在的理由。**本例符合適應症，所以做；不是因為「頭部外傷都要做」。**

## 階段三：視情況

- 胸部 X 光、骨盆 X 光（高處跌落的次級評估）
- 顏面骨 CT（若懷疑眼眶或顴骨骨折）

# 6. 檢驗

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| **血糖** | **↓ → 可能是跌落的原因而非結果**。必驗 |
| CBC/DC | Hb ↓ → 其他部位出血 |
| **PT/INR、APTT、血小板** | **↑／異常 → 出血風險大增。慢性飲酒者的肝功能可能已受損，本題必驗** |
| 肝功能、Albumin | 評估慢性酒精性肝病 |
| BUN/Cr、電解質 | 基礎評估；**低血鈉也會造成意識改變** |
| **血中酒精濃度** | 若意識評估受干擾，需知道有多少是酒精造成的 |
| 血型與交叉配血 | 若可能需手術 |
| 尿液毒物篩檢 | 視情況 |

# 7. 前三個鑑別診斷

## ① 主診斷：創傷性顱內出血（硬腦膜下或硬腦膜上出血）

**支持證據**
- **高處跌落的受傷機轉**（工地二樓樓梯）【已知】
- **短暫意識喪失約 30 秒**【已知】
- **持續且明顯的頭痛、頭暈、想吐**——顱內壓上升的症狀【已知】
- **左臉頰淤青、眼周瘀血**——證明有明確的直接撞擊力【已知】
- **58 歲 ＋ 慢性飲酒（維士比）**——腦萎縮使橋靜脈易斷裂，且凝血可能異常，**硬腦膜下出血風險顯著升高**【已知＋推論】
- 每天一包菸【已知】

**不支持之處（誠實列）**
- 情境**完全沒有提供生命徵象、GCS、瞳孔**——而這三項是本題判斷嚴重度的核心，全部空白。
- **意識喪失只有 30 秒且目前意識清楚**，這偏向較輕的損傷。
- **未提供是否服用抗凝血劑**——這是最關鍵的風險修飾因子。
- 未提供症狀是否進行性惡化。

**確診依據**
**非顯影頭部電腦斷層。** 並在首次正常時**持續臨床觀察，必要時重複影像**。

---

## ② 次可能：腦震盪（輕度創傷性腦損傷）

**為什麼它還留在名單上**
**短暫（30 秒）意識喪失 ＋ 頭痛、頭暈、噁心 ＋ 意識目前清楚**，這一組完全符合腦震盪的定義。
而且**腦震盪的定義是「影像正常」**——它是功能性而非結構性的損傷。

**要出現什麼證據，它才會翻上第一位**
1. **頭部 CT 完全正常**
2. **GCS 15 分且穩定不下降**
3. 神經學檢查完全正常、瞳孔正常
4. 症狀**逐漸緩解**而非惡化
5. 未服用抗凝血劑

**翻上來的臨床意義**：從「住院觀察、可能手術」變成「**離院前完整衛教 ＋ 明確的返診紅旗指示 ＋ 需有人陪同觀察**」。

> ⚠️ **但即使診斷為腦震盪，離院衛教也不能省略。**
> 必須明確告訴家屬：**頭痛加劇、反覆嘔吐、意識變差、講話不清、單側無力、瞳孔不等大、抽搐，任一出現立刻回來。**
> **慢性飲酒者更要強調延遲性硬腦膜下出血的可能，觀察期要拉長。**

## ③ 不能排除：頸椎損傷

**這一格放的是漏掉會癱瘓的診斷，而且它是本題最容易被整個跳過的一個。**

**為什麼必須主動排除**
- **從高處跌落是頸椎損傷的高危險機轉**
- **他是被同事送來的**——沒有頸圈、沒有脊椎板，可能已經被扶著走、坐車顛簸一路。**傷害可能已經在路上發生，也可能還沒發生但隨時會**
- **所有人的注意力都在那顆頭上**——臉頰瘀青、熊貓眼、頭痛嘔吐，這些都很吸睛，而頸椎沒有任何外觀線索
- **一個不穩定的頸椎骨折，可能因為一次不當的轉頭而造成完全性脊髓損傷**
- 病人現在頭很痛，**劇烈的頭痛會掩蓋頸部的疼痛**（疼痛分散效應）

**排除它的最低限度**
> **第一步：先上頸圈，再說其他。** 這一步不需要任何判斷，只需要知道受傷機轉。
>
> **第二步：用 NEXUS 準則或加拿大頸椎規則判斷是否需要影像。**
> 本例存在**危險受傷機轉（高處跌落）**，通常已符合需要影像的條件。
>
> **第三步：影像選擇為頸椎 CT，不是 X 光**——X 光對頸椎骨折的敏感度不足。

**同時要記住：頸椎清空之前，不讓病人下床走路、不讓他自己轉頭。**

# 8. 口試委員最可能追問的五題

**Q1「這個病人一進來，你第一個動作是什麼？」**
> **上頸圈。**
> 他是從二樓樓梯跌下來的，這是頸椎損傷的高危險機轉，而且他是**同事送來的，一路上完全沒有固定**。
> 所有人的注意力都會被那個熊貓眼和臉頰瘀青吸走，但頸椎是沒有任何外觀線索的，而且他現在頭很痛，**劇烈頭痛會掩蓋頸部的疼痛**。
> 在頸椎被排除之前，我不會讓他轉頭，也不會讓他下床走路。

**Q2「他有熊貓眼，是不是代表顱底骨折？」**
> 不一定，而且我認為在這一題比較可能不是。
> **熊貓眼確實是顱底骨折的典型徵象，但它通常在受傷後數小時到數天才會出現。** 這位病人今天下午受傷、現在就有眼周瘀青，**更可能是左臉頰直接撞擊造成的局部瘀血**。
> 不過這不代表可以放心——它證明左側顏面受到明顯的直接撞擊，力道足以傳到顱底。所以我還是會主動檢查其他顱底骨折的徵象：耳後的 Battle's sign、鼓室有沒有積血、耳朵或鼻子有沒有流出清澈的液體。

**Q3「情境說他常喝維士比，這對你的判斷有影響嗎？」**
> 影響很大，有三個層面。
> 第一，**慢性飲酒會造成腦萎縮，橋靜脈被拉長，比較輕的外力就可能造成硬腦膜下出血**。
> 第二，**肝功能可能受損，凝血功能異常會讓出血更難停**，所以我一定會驗 PT/INR。
> 第三，**酒精會混淆意識評估**——我不能把意識不清直接歸因於喝酒，那是很危險的假設。
> 另外情境自己寫得矛盾，一邊說一星期喝一次，一邊說平常常喝維士比，**實際飲酒量必須問清楚**，病人低報是常態。

**Q4「你前面幾題都說能不做 CT 就不做，這一題為什麼直接開頭部 CT？」**
> 因為原則從來不是「少做 CT」，是「**用最低成本回答關鍵問題**」。
> 前面那些題有更便宜的替代品——超音波看得到膽囊、看得到水腎。**但顱內沒有替代品**：超音波看不進去，頭顱 X 光只能看骨折，看不到出血，而出血才是會死人的那一個。**觀察等待的代價是不可逆的腦損傷。**
> 所以在這一題，CT 就是最低成本的答案。
> **反過來說也一樣重要**：如果病人完全清醒、沒有意識喪失、沒有嘔吐、沒有危險機轉、沒吃抗凝血劑，那不做 CT 才是對的。這位病人符合適應症所以做，不是因為「頭部外傷都要做」。

**Q5「如果頭部 CT 正常，你就讓他回家嗎？」**
> 不會直接讓他回家。有兩個理由。
> 第一，**他是慢性飲酒者，硬腦膜下出血可能延遲出現**，第一次 CT 正常不代表之後不會有。
> 第二，我還沒確認他有沒有在吃抗凝血劑，那會大幅改變風險。
> 所以我會**留觀並每 15 到 30 分鐘重複評估 GCS 和瞳孔**——**顱內出血的診斷往往不是靠第一次檢查，而是靠第二次比第一次差。**
> 真的要離院的話，我會確保有家人陪同，並且明確交代紅旗症狀：頭痛加劇、反覆嘔吐、意識變差、講話不清、單側手腳無力、抽搐，任何一個出現就要立刻回來。
