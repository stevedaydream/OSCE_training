# A-13｜48 歲男性，血尿

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #13）

48 歲男性，小型鐵工廠老闆。今天早上工作時，發現血尿而到門診就醫。
20 年前因急性盲腸炎開過刀，五年前曾因泌尿道結石(左側輸尿管結石)住院接受內視鏡手術，之後沒持續追蹤。平時無特殊用藥習慣。約一星期前有覺得右腰有點酸痛，後來好了也不以為意。今天早上工作時突然覺得一陣腰酸，開始一直想上廁所，想解又解不太出來，解的時候下腹部會痛，幾次後突然發現尿是紅色的，而且有一些血絲。腰痛也越來越明顯，站都站不直，好了沒多久又開始痛，肚子也會有點悶悶脹脹的，而且會噁心想吐。跟以前結石的情形很像。

---

# 1. 情境事實清單

- 48 歲男性，**小型鐵工廠老闆**
- 今晨工作時發現**血尿**，來門診
- 20 年前急性闌尾炎開刀
- **五年前左側輸尿管結石**，接受內視鏡手術，**之後沒有持續追蹤**
- 平時無特殊用藥
- **約一週前右腰酸痛，自行緩解，未在意**
- 今晨突然一陣腰酸
- **頻尿感、想解又解不太出來、解尿時下腹痛**
- 數次後發現**尿呈紅色並有血絲**
- **腰痛越來越明顯，站都站不直**
- 疼痛**好一陣又痛一陣**（間歇性）
- 腹部悶脹、噁心想吐
- 病人自述「**跟以前結石的情形很像**」

**情境未給**：生命徵象、**體溫**、疼痛是否放射至鼠蹊或睪丸、尿量、體重變化、抽菸史、詳細職業暴露。

---

# 2. 第一印象與危險分流

這一題有三個層次，愈往下愈容易被漏掉：

**第一層（表面）**：症狀完全符合右側輸尿管結石——腰痛、間歇性、站不直、噁心、血尿，加上五年前的結石病史。

**第二層（陷阱）**：病人自己說「**跟以前結石的情形很像**」。這句話和 #17 那位「以為是吃壞肚子」的病人是同一類問題——**病人用過去經驗替現在的症狀下了診斷，而你很容易跟著他走。** 五年前的結石是**左側**，這次痛的是**右側**，這已經不是同一件事。

**第三層（真正的危險）**：**48 歲成人的血尿，不論有沒有結石病史，都必須排除泌尿上皮癌。** 而這位病人有兩個額外的紅旗：
- **五年前結石手術後沒有持續追蹤**——這五年泌尿系統沒有人看過
- **鐵工廠老闆**——金屬加工業可能接觸切削油、金屬加工液與相關化學品，這類職業暴露與膀胱癌有關聯【推論，需查證】

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **阻塞性腎盂腎炎（膿腎）** | 結石 ＋ 感染 = 泌尿科急症，會迅速走向敗血症 | **量體溫**、尿液常規看膿尿、CBC |
| **泌尿上皮癌** | 48 歲血尿 ＋ 五年未追蹤 ＋ 職業暴露 | 尿液細胞學、影像、必要時膀胱鏡 |
| 結石併急性腎損傷 | 若為孤立腎或雙側阻塞 | BUN/Cr、尿量 |

**「站都站不直」怎麼解讀【推論】**：這通常是絞痛發作時的姿勢，但要和腹膜炎的「不敢動」分開——結石病人是**動來動去找不到舒服的姿勢**，腹膜炎病人是**完全不敢動**。這一點理學檢查時要親自看。

# 3. 焦點式病史

## 把主訴問完整

**L 部位**——痛在右腰還是右側腹？**會不會往下跑到鼠蹊部或睪丸？**（往下放射 → 輸尿管中下段結石；固定在腰 → 上段或腎臟本身）

**Q 性質**——**是一陣一陣的絞痛，還是持續的鈍痛？**（已知「好了沒多久又開始痛」，符合間歇性絞痛）

**Q 程度**——最痛幾分？

**O 時序**——今早幾點開始？**一週前那次右腰酸痛，痛多久、怎麼好的？**（一週前那次很可能是同一顆結石的第一次發作）

**P 誘發**——工作時搬重物？脫水？（鐵工廠環境高溫、流汗多、水喝得少，是結石的重要成因）

**E 緩解**——什麼姿勢比較舒服？**痛起來是躺著不動比較好，還是一直想動？**

**R 相關症狀（本題最關鍵的一組）**
- **有沒有發燒、畏寒發抖？**（情境完全沒提，**這是本題最必須問到的一題**——結石併感染是會死人的組合）
- 血尿是**整泡都紅**，還是**剛開始紅／最後才紅**？（全程血尿 → 來自腎或輸尿管；末段血尿 → 膀胱或攝護腺；起始血尿 → 尿道）
- 有沒有**血塊**？（有血塊比較偏腫瘤或明顯出血，單純結石通常是血絲）
- 尿量有沒有變少？
- 解尿會不會灼熱刺痛？（已知解尿時下腹痛）
- 有沒有噁心嘔吐？（已知）

## 本題特有、必須主動問的

- **「五年前那次是左邊，這次痛的是右邊。這五年有沒有再檢查過？有沒有追蹤過腎臟？」**
  → 直指「未追蹤」這個紅旗
- **「您這次的血尿，是痛了才發現的，還是不痛的時候就有過？」**
  → **無痛性血尿是泌尿上皮癌的典型表現。** 這一題直接分開良性與惡性
- **「鐵工廠平常會接觸到什麼？切削油、金屬加工液、有機溶劑、染料？做幾年了？」**
  → 職業暴露史，本題埋得最深的一條線索
- **「有沒有抽菸？抽多久？」**（抽菸是膀胱癌最強的風險因子，情境完全沒提，**必問**）
- 這幾個月體重有沒有減輕？
- 平常一天喝多少水？（結石成因，也是衛教切入點）
- 家族有沒有結石或泌尿道腫瘤？

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| **沒有發燒、沒有畏寒發抖** | **降低阻塞性腎盂腎炎**——這是本題最重要的否定 |
| 沒有無痛性血尿的病史、沒有血塊 | 降低泌尿上皮癌（但不排除） |
| 沒有抽菸、無染料橡膠皮革暴露 | 降低膀胱癌 |
| 沒有體重減輕 | 降低惡性腫瘤 |
| 沒有服用抗凝血劑、NSAID | 降低藥物相關血尿 |
| 沒有劇烈運動、沒有外傷 | 降低運動性或外傷性血尿 |

# 4. 焦點式身體評估

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| **生命徵象含體溫** | — | 「我先幫您量血壓、脈搏和體溫，目的是確認有沒有合併感染。」 | **無發燒**（若發燒，處置立刻升級） | **發燒 ＋ 心搏過速 → 阻塞性腎盂腎炎** |
| 一般外觀與姿勢 | 全身 | 「我先看您現在的姿勢，目的是判斷疼痛的型態。」 | **躁動、一直換姿勢、坐立難安** | 腹膜炎：完全不敢動 |
| 鞏膜與結膜 | 雙眼 | 「看一下您的眼白和下眼瞼，目的是檢查有沒有黃疸或貧血。」 | 正常 | 蒼白 → 慢性失血 |
| 腹部視診 | 腹部、腹股溝 | 「我要看您的肚子，目的是看有沒有脹起來、有沒有以前開刀的疤痕。」 | 可見**右下腹闌尾切除疤痕**、腹部平坦 | — |
| 腸蠕動音聽診 | 四象限 | 「我用聽診器聽腸子聲音，目的是判斷腸道蠕動，因為腎臟的痛也會讓腸子變慢。」 | 正常或略減弱 | 腸阻塞：高亢金屬音 |
| 腹部觸診 | 四象限、下腹 | 「我要輕壓您的肚子，目的是找出壓痛的位置，也摸摸看膀胱有沒有脹起來。」 | 右側腹深部壓痛、**無腹膜刺激徵** | 膀胱脹大 → 尿滯留 |
| **右側肋脊角叩擊痛** | 右後腰肋脊角 | 「請您坐起來稍微前傾，我要輕敲您右後腰的位置，目的是檢查右邊腎臟和輸尿管有沒有阻塞或發炎。」 | **陽性** | 陰性則需重新考慮診斷 |
| 左側肋脊角叩擊痛 | 左後腰 | 「另一邊我也敲一下做比較，目的是確認是不是只有右邊有問題。」 | 陰性（對照用） | 雙側陽性 → 雙側病變 |
| 反彈壓痛 | 全腹 | 「我要壓下去再快速放開，目的是確認腹膜有沒有發炎。」 | **陰性** | 陽性 → 不是單純結石，要重想 |
| **陰囊與睪丸視觸診** | 陰囊 | 「因為輸尿管的痛常會傳到陰囊，我需要檢查一下這個部位，目的是排除睪丸本身的問題。我會拉上簾子，也可以請男性同仁在旁邊。您同意嗎？」 | 正常，無壓痛 | **睪丸扭轉：睪丸高位橫置、劇痛**——會被誤認為結石 |
| 攝護腺（肛門指診） | 直腸 | 「我需要做肛門指診檢查攝護腺，目的是確認攝護腺有沒有腫大或發炎，也會一併確認直腸的狀況。會不舒服但很快，我會拉簾並請同仁陪同。」 | 正常 | 攝護腺腫大或壓痛 → 攝護腺來源 |

> **本題最容易被漏掉的兩項：量體溫、檢查陰囊。**
> 體溫決定這是門診處理還是泌尿科急症；陰囊檢查排除的是另一個時間敏感的急症（睪丸扭轉），而它的表現可以和輸尿管結石一模一樣。

# 5. 需安排的檢查

## 階段一：床邊立即

- **尿液常規 ＋ 尿沉渣** ← **本題的第一線檢查**
  - 目的：確認血尿（紅血球）、**確認有無感染（白血球、亞硝酸鹽、細菌）**
  - 預期發現：紅血球明顯上升；**白血球與亞硝酸鹽陰性**
  - **若白血球與亞硝酸鹽陽性 ＋ 發燒 → 立即改走阻塞性腎盂腎炎的緊急路線**
- **尿液培養**（若懷疑感染，抗生素前先送）
- **尿液細胞學（urine cytology）**：目的是初步篩檢泌尿上皮癌。非侵入，本題該送
- 生命徵象含體溫

## 階段二：非侵入性、無輻射

- **腎臟及膀胱超音波** ← **關鍵檢查**
  - 目的：看**右側有無水腎（阻塞的間接證據）**、腎臟有無腫瘤、膀胱有無腫瘤或結石、殘尿量
  - 預期發現：**右側輕至中度水腎**
  - 陰性時下一步：無水腎不能完全排除結石（早期或已排出），需結合 KUB 與臨床
  - 升級條件：見腎臟腫塊、膀胱內佔位 → 立即安排 CT 與泌尿科
- **KUB（腹部平片）**：目的是看不透射線的結石（鈣質結石約八成以上可見【推論，數字需查證】）。低成本、低輻射

## 階段三：有輻射／侵入性

- **非顯影低劑量電腦斷層（結石 protocol）**
- **電腦斷層尿路攝影（CT urography）**
- **膀胱鏡**

> **這一題的檢查順序要分兩條線走，這是本題最重要的臨床決策。**
>
> **線一（結石）**：超音波 ＋ KUB 通常足以確認阻塞與結石。
> **本題我不會為了找結石而立刻開 CT**——超音波看到水腎、KUB 看到結石，這兩項合起來已經回答了「有沒有阻塞、要不要處理」。
> 只有在超音波與 KUB 都看不到、但病人持續劇痛，才用**非顯影低劑量 CT**（找結石不需要顯影劑）。
>
> **線二（腫瘤）——這條線不能因為線一有答案就關掉。**
> 這是本題最大的陷阱：**找到結石不等於排除腫瘤。** 一個 48 歲、五年沒追蹤、有職業暴露的男性血尿病人，
> 即使這次確實是結石，**上泌尿道與膀胱的評估仍然必須完成**（CT urography 或膀胱鏡，由泌尿科決定）。
>
> 我會這樣跟委員說明：**急性期先解決阻塞與疼痛，但轉診泌尿科時必須明確寫上「48 歲成人血尿，需完成上下泌尿道腫瘤評估」，不能只寫「結石」。**

# 7. 前三個鑑別診斷

## ① 主診斷：右側輸尿管結石併阻塞

**支持證據**
- **間歇性腰痛，痛起來站不直**——典型腎絞痛【已知】
- **肉眼血尿**【已知】
- 頻尿感、想解解不出來、解尿時下腹痛——輸尿管下段結石刺激膀胱的典型表現【已知】
- 噁心想吐、腹部悶脹（腎絞痛引起的反射性腸蠕動減慢）【已知】
- **五年前有輸尿管結石病史**——結石復發率高【已知】
- **一週前右腰酸痛自行緩解**——很可能是同一顆結石的第一次發作【已知】
- 職業環境（鐵工廠，高溫、易脫水）是結石的成因之一【推論，需問診確認】
- 預期：右側 CVA 叩擊痛陽性、超音波見右側水腎【推論】

**不支持之處**
- **五年前是左側，這次是右側**。復發完全合理，但這不是「同一件事再來一次」，不能用舊病史直接套。
- 情境**完全沒有提供體溫**。結石本身不發燒，若有發燒就不是單純結石。
- 情境未提到疼痛放射到鼠蹊或睪丸，這是輸尿管結石的重要特徵，需問診補上。

**確診依據**
超音波見右側水腎 ＋ KUB 或非顯影 CT 見輸尿管結石，併尿液常規血尿。

## ② 次可能：泌尿道感染／阻塞性腎盂腎炎

**為什麼它還留在名單上**
病人已經有**頻尿、解尿困難、解尿時下腹痛**這一組膀胱刺激症狀，這些單獨看也完全符合泌尿道感染。而且結石與感染經常同時存在——**結石造成的阻塞正是感染的溫床**。

**要出現什麼證據，它才會翻上第一位**
1. **發燒（尤其伴畏寒發抖）**
2. **尿液常規見膿尿、亞硝酸鹽陽性**
3. WBC ↑ 併 left shift、CRP ↑
4. 心搏過速、低血壓（走向敗血症）

**翻上來的臨床意義（本題最重要的一段）**
> **結石 ＋ 阻塞 ＋ 感染 = 阻塞性腎盂腎炎（膿腎），這是泌尿科急症，不是門診疾病。**
> 它的處置不是「多喝水等結石排出」，而是**緊急解除阻塞（輸尿管支架或經皮腎造廔）＋ 靜脈抗生素**。
> 因為阻塞不解除，抗生素到不了感染的地方，病人會在幾小時內走向敗血性休克。
>
> 換句話說：**這一題只要量到發燒，整個處置方向就翻掉。而量體溫是零成本的。**

---

## ③ 不能排除：泌尿上皮癌（膀胱／上泌尿道移行細胞癌）

**這一格放的是漏掉會出大事的診斷。它不是最可能的，但它是最不能省的。**

**為什麼即使結石診斷成立，仍必須主動排除**
- **48 歲成人的肉眼血尿，本身就是需要完整泌尿道評估的指標**，不論有沒有找到其他解釋
- **五年前結石手術後完全沒有追蹤**——這五年他的泌尿系統沒有任何人看過
- **鐵工廠職業暴露**：金屬加工可能接觸切削油與相關化學品，與膀胱癌有關聯【推論，需查證】
- 情境**完全沒有提到抽菸**——而抽菸是膀胱癌最強的風險因子，這一題必須主動問
- **最危險的錯誤是：超音波看到結石，就結案了。** 結石與腫瘤可以並存，而且結石造成的血尿會完美地掩蓋腫瘤造成的血尿。
- 病人自己那句「跟以前結石的情形很像」，會強化這個錯誤

**排除它的最低限度**
> **一份尿液細胞學 ＋ 影像時同時評估上泌尿道與膀胱（超音波看膀胱，必要時 CT urography），並在轉診單上明確註明「成人血尿，需完成腫瘤評估」。**

急診或門診當下不必立刻做膀胱鏡，但**不能讓這條線在「找到結石」的時候被關掉**。追蹤的責任要交代清楚並記錄。

# 8. 口試委員最可能追問的五題

**Q1「病人自己說跟以前結石一樣，你接受嗎？」**
> 我會參考，但不會接受它當結論。有兩個理由：第一，**五年前是左側，這次是右側**，不是同一件事。第二，他五年來完全沒有追蹤過。
> 病人用過去經驗替現在的症狀下診斷，這是很自然的事，但如果我跟著他走，就會漏掉這五年可能發生的任何變化。

**Q2「這一題你最先想確認的是什麼？」**
> **體溫。** 情境完全沒給體溫，而它決定了這是門診處理還是泌尿科急症。
> 如果結石併阻塞又合併感染，那是膿腎，處置不是止痛加多喝水，而是**緊急解除阻塞加靜脈抗生素**。因為阻塞不解除，抗生素進不去，病人可能在幾小時內走向敗血性休克。
> 量體溫是零成本的，但它翻掉整個處置方向。

**Q3「如果超音波看到右側水腎，X 光也看到結石，你就結案了嗎？」**
> 不結案。這是這一題我覺得最危險的地方——**找到結石不等於排除腫瘤**，而且結石造成的血尿會完全掩蓋腫瘤造成的血尿。
> 這位病人 48 歲、肉眼血尿、五年沒追蹤、又在金屬加工業工作，這幾項合起來讓我一定要把上下泌尿道的腫瘤評估做完。
> 急性期我會先處理阻塞和疼痛，但轉診泌尿科時我會明確寫「成人血尿需完成腫瘤評估」，不會只寫「結石」。

**Q4「情境沒提抽菸，你為什麼特別要問？」**
> 因為抽菸是膀胱癌最強的風險因子。這一題情境給了職業（鐵工廠）卻沒給抽菸史，而血尿的病人不問抽菸，等於少了最重要的一個風險評估。

**Q5「請向病人解釋。」**
> 老闆，您這個症狀確實很像結石，跟您五年前那次類似，但這次是右邊，不是同一邊，所以我會當成新的一次來查。
> 我等一下先驗尿，看看有沒有出血和有沒有感染，然後照一張腹部 X 光和做腎臟超音波，看看右邊的腎臟有沒有積水、結石卡在哪裡。這兩個都不會痛，超音波也沒有輻射。
> 另外有一件事我想跟您說清楚：**只要是您這個年紀出現肉眼看得到的血尿，不管最後是不是結石，泌尿道都要整個檢查過一次**。這不是嚇您，是因為結石跟其他問題可以同時存在，我不希望因為找到結石就漏掉別的。所以我會幫您轉泌尿科做完整的追蹤。
> 這段時間請多喝水。如果開始發燒、發冷發抖，或者痛到受不了、完全解不出尿，請立刻回來急診，不要等。

**SBAR 骨幹**

- **B**：五年前左側輸尿管結石接受內視鏡手術，**術後未追蹤**；20 年前闌尾切除；一週前曾有右腰酸痛自行緩解；職業為鐵工廠老闆；抽菸史待確認。

# 9. 我不確定的地方

1. **KUB 能看到的結石比例**——我寫「鈣質結石約八成以上」，這個數字信心不足，**口試不要講百分比**。
2. **鐵工廠／金屬加工業與膀胱癌的關聯強度**——我知道切削油與某些工業化學品有關聯，但這個職業別的證據強度我沒有把握。口試建議說「有職業暴露的可能，需要問清楚接觸什麼」，不要斷言。
3. **成人無症狀或有症狀血尿的標準評估流程**——各國指引不同（要不要一律做膀胱鏡、CT urography 的適應症），台灣泌尿科實務請以你的經驗或問泌尿科同仁為準。
4. **尿液細胞學的敏感度**——我知道對低惡性度腫瘤敏感度不佳，但數字沒有把握。
5. **阻塞性腎盂腎炎的緊急引流時間窗**——我知道要「盡快」，但是否有明確的小時數建議，我不確定。
6. **睪丸扭轉列入本題身評是否必要**——我放進去是因為它與輸尿管結石表現可重疊且時間敏感，但 48 歲的睪丸扭轉相對少見（好發於青少年）。若你認為在 15 分鐘裡這一項不划算，可以降級為口頭提及。
