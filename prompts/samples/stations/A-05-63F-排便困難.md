# A-05｜63 歲女性，排便困難

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #5）

63 歲女性，排便困難。
兩週前得知自己初期大腸癌，當時建議手術切除，但患者仍未決定。近日來雖有排氣，但排便困難已五天，前來急診就醫。病患教育程度：中學，已婚，職業是務農，但目前已退休。

---

# 1. 情境事實清單

- 63 歲女性
- **兩週前確診初期大腸癌**，當時**已建議手術切除**
- **患者仍未決定是否手術**
- **近日仍有排氣**
- **排便困難已五天**
- 自行前來急診
- 教育程度中學、已婚、務農已退休

**情境未給**：生命徵象、腹痛與否、腹脹、噁心嘔吐、腫瘤位置與分期、有無血便、體重變化、過去手術史、未決定手術的**原因**。

---

# 2. 第一印象與危險分流

這一題有兩條線同時在跑，缺一不可：

**臨床線**：已知大腸癌的病人排便困難五天，第一個要問的是**腫瘤是不是已經把腸子塞住了**。
**溝通線**：她**兩週前就被建議手術，到現在還沒決定**。她今天出現在急診，不只是因為排不出來，也因為那個決定還懸在那裡。**如果只處理阻塞而不碰那個決定，這一題只做了一半。**

**「還有排氣」這一句是本題最重要的一個字。**【推論】完全性腸阻塞會停止排氣排便；她**還在排氣**，代表目前是**部分阻塞**而非完全阻塞。這改變的是急迫性——不是「現在推進開刀房」，而是「有時間把事情做對，但不能拖」。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **大腸癌併完全阻塞** | 已知腫瘤 ＋ 排便困難五天 | 問排氣（已知仍有）、腹脹程度、腹部 X 光 |
| **阻塞近端穿孔** | 阻塞最致命的併發症，尤其閉環型 | 腹膜刺激徵、發燒、立姿 CXR |
| 糞便嵌塞 | 老年、活動量下降、飲食改變 | **肛門指診**——一項就分得出來 |
| 腫瘤進展／腹膜轉移 | 兩週前說「初期」，但那是兩週前的說法 | 腹部理學、影像 |

**「初期」這兩個字要保留懷疑【推論】**：情境寫的是病人**自述**兩週前被告知初期。臨床分期是否確實、當時做了什麼檢查、有沒有完成分期，都不知道。**不要把病人轉述的分期當成事實往下推理。**

---

# 3. 焦點式病史

本題的病史要同時走臨床與決策兩條線。

## 臨床線

**排便**
- 五天完全沒有解便，還是解得出來但很費力、量很少？
- **最後一次解便是什麼時候？形狀？有沒有變細？**
- 有沒有血便、黏液便、裡急後重（想解解不乾淨）？
- 以前排便習慣如何？這五天前有沒有已經在改變？

**排氣**——已知仍有。追問：**排氣的量和頻率有沒有比以前少？**（從有到少是往完全阻塞走的過程）

**腹痛與腹脹**
- 肚子會不會痛？痛的位置、性質（陣發絞痛 → 阻塞）
- 肚子有沒有脹起來？脹的程度這幾天有沒有變化？

**噁心嘔吐**——有沒有吐？吐什麼顏色？（吐膽汁 → 阻塞位置較高或已惡化）

**全身**
- 有沒有發燒、畏寒？
- 這兩個月體重掉了多少？
- 食慾如何？這五天有沒有正常進食？

**腫瘤病史（必須問清楚）**
- 兩週前是在哪裡做的檢查？做了什麼？（大腸鏡？切片？電腦斷層？）
- **有沒有拿到報告？腫瘤在哪一段？**
- 除了手術，醫師還說了什麼？

## 決策線（本題不可省略）

- **「兩週前醫師建議手術，您到現在還沒決定，可以告訴我是什麼讓您猶豫嗎？」**（開放式，不評價）
- 家人知道嗎？誰會一起做這個決定？
- 對手術最擔心的是什麼？（怕開了就好不了、怕做人工肛門、怕花錢、怕沒人照顧田或家人、怕麻醉）
- 有沒有聽到什麼說法讓您考慮別的方法？（民俗療法、草藥、親友經驗）

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| 沒有完全停止排氣 | **降低完全性阻塞**（情境已明示仍有排氣） |
| 沒有嘔吐、沒有明顯腹脹 | 降低高位或完全阻塞 |
| 沒有發燒、沒有劇烈腹痛 | 降低穿孔與腹膜炎 |
| 沒有服用鴉片類止痛藥、鐵劑、鈣片 | 降低藥物性便祕 |

**其他必問**：過去手術史（尤其腹部）、慢性病與用藥、水分與纖維攝取、活動量、最近有沒有因為擔心而吃不下。

# 4. 焦點式身體評估

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| 一般外觀與營養狀態 | 全身、顳肌、鎖骨上窩 | 「我先看您整體的狀況和有沒有變瘦，目的是評估營養情形，這對後面能不能開刀很重要。」 | 可能消瘦 | 惡病質 → 腫瘤已進展 |
| 鞏膜與結膜 | 雙眼 | 「我看一下您的眼白和下眼瞼，目的是檢查有沒有黃疸和貧血。」 | 結膜可能蒼白（慢性失血） | 黃疸 → 肝轉移或膽道阻塞 |
| **鎖骨上淋巴結觸診** | 左側鎖骨上窩 | 「我要摸您左邊鎖骨上方，目的是檢查淋巴結有沒有腫大，因為腹部的腫瘤可能會轉移到這裡。」 | 陰性 | **摸到硬結 → 遠端轉移，分期完全改變** |
| 腹部視診 | 腹部、腹股溝、疤痕 | 「我要看您的肚子，目的是看有沒有脹起來、有沒有以前開刀的疤痕、有沒有局部凸起。我會注意隱私。」 | 輕度膨脹或正常 | 明顯膨脹 → 完全阻塞 |
| 腸蠕動音聽診 | 四象限 | 「我用聽診器聽腸子的聲音，目的是判斷腸道是不是塞住了。我會先聽再壓。」 | **仍有腸音，可能亢進**（部分阻塞） | 消失 → 麻痺或壞死 |
| 腹部叩診 | 四象限 | 「我輕敲您的肚子，目的是判斷脹的是氣還是水。」 | 局部鼓音 | 移動性濁音 → 腹水／腹膜轉移 |
| 腹部觸診 | 四象限 | 「我要輕壓您的肚子，目的是找出有沒有壓痛，也摸摸看有沒有摸得到的腫塊。」 | 可能觸及腫塊或局部壓痛 | **局部固定壓痛併 guarding → 該處可能已穿孔** |
| 反彈壓痛 | 全腹 | 「我要壓下去再快速放開，目的是確認腹膜有沒有發炎。」 | **陰性**（若陽性代表已穿孔） | 陽性 → 緊急 |
| **肛門指診** | 肛門直腸 | 「我需要做肛門指診，目的是確認直腸裡有沒有塞住的大便、能不能摸到腫瘤、有沒有出血。這個檢查會不舒服但很快，我會拉上簾子並請同仁陪同，也會全程告訴您我在做什麼。您同意嗎？」 | **直腸空虛 → 阻塞在上游，支持腫瘤性阻塞** | **摸到大量硬便 → 糞便嵌塞**；摸到硬塊 → 直腸腫瘤 |

> **本題的肛門指診是決定性的一項，不可省略。** 它一次分開「腫瘤把上游塞住」與「單純大便卡在直腸」這兩個處置完全不同的情況，而且不需要任何儀器、五分鐘內有答案。

# 5. 需安排的檢查

## 階段一：床邊立即

- **生命徵象（含體溫）**
- **肛門指診**（列在檢查而非只在理學，因為它就是本題的第一線診斷工具）
- **POCT 血糖**

## 階段二：非侵入性、無輻射

- **腹部 X 光（立姿＋臥姿）**
  - 目的：判斷阻塞程度與位置、看有無游離氣體
  - 預期發現：**近端大腸擴張、可見糞便滯留，但仍有遠端氣體**（符合部分阻塞）
  - 陰性時下一步：X 光正常不能排除，仍需 CT 做分期與定位
- **立姿胸部 X 光**：橫膈下游離氣體 ＋ 肺部轉移初步篩檢（一張片子兩個目的）
- **腹部超音波**：看有無腹水、肝臟有無轉移性病灶

## 階段三：有輻射／顯影劑

- **腹部骨盆電腦斷層（含顯影劑）**

> **這一題 CT 我一定會開，而且理由和急性腹症不同。**
> 前面幾題的原則是「能回答同一個問題時選便宜的」。但這一題 CT 要回答的**不只是急性問題**：
> 1. 阻塞在哪一段、程度多嚴重（急性問題）
> 2. **腫瘤到底是不是「初期」——有沒有侵犯周邊、有沒有淋巴結、有沒有肝或肺轉移**（分期問題）
>
> 第二點沒有任何便宜的替代方案，而且它直接決定接下來要跟病人談什麼。
> 更重要的是：**病人猶豫兩週的原因，很可能就是資訊不足。** 一份完整的分期資料，是把「要不要開刀」這個決定還給她的前提。
> 所以本題的 CT 不只是診斷工具，它是**支持病人做決定的工具**。

# 6. 檢驗

**即時（< 15 分）**：血糖、電解質（便祕與嘔吐可致低血鉀，低血鉀又會加重腸蠕動不良，這是個惡性循環）

**常規（1 小時內）**

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| CBC/DC | **Hb ↓（小球性貧血）→ 支持腫瘤慢性失血**；WBC ↑ → 感染或已穿孔 |
| CRP | ↑ 支持發炎或穿孔 |
| BUN/Cr/電解質 | 脫水、低血鉀評估；顯影劑前必要值 |
| **Albumin** | ↓ → 營養不良，**直接影響手術風險與傷口癒合，是術前評估的關鍵值** |
| AST/ALT/ALP/T-Bil | 肝轉移的初步篩檢 |
| PT/INR、血型 | 術前準備 |
| **CEA** | **不能用來診斷**，但作為術前基準值與日後追蹤依據 |

# 7. 前三個鑑別診斷

## ① 主診斷：大腸癌併部分性大腸阻塞

**支持證據**
- **已知診斷為大腸癌，且兩週前即建議手術**【已知】
- 排便困難已五天【已知】
- **仍有排氣** → 部分而非完全阻塞【已知】
- 預期：腹部 X 光見近端擴張但遠端仍有氣體；肛門指診直腸空虛【推論】

**不支持之處（誠實列）**
- 情境**完全沒有提供腹痛、腹脹、嘔吐**任何一項。腸阻塞的四大症狀只出現了一個（排便困難），這讓「阻塞」這個診斷目前只站得住一隻腳。**必須靠問診把另外三項補齊。**
- **「初期大腸癌」是病人兩週前的轉述，未經證實。** 若真的是初期，兩週內就進展到阻塞並不尋常——這意味著要嘛分期不準，要嘛還有別的原因。
- 情境未提供腫瘤位置。左側大腸（乙狀結腸、直腸）腔徑小、糞便已成形，容易阻塞；右側大腸腔徑大、內容物是液狀，較晚才阻塞。**位置未知，就無法解釋為什麼「初期」會塞。**

**確診依據**
腹部 X 光見阻塞徵象 ＋ CT 見腫瘤性狹窄併近端腸管擴張，並同時完成分期。

---

## ② 次可能：糞便嵌塞／單純便祕

**為什麼它還留在名單上**
這是本題最容易被忽略的可能，因為**「已知大腸癌」這個標籤會綁架思考**。但一個 63 歲、剛得知癌症、正在猶豫要不要手術的病人，這兩週很可能：食慾下降、水分攝取減少、活動量下降、焦慮失眠——**這些全部都會造成便祕**，而且完全不需要腫瘤阻塞來解釋。

**要出現什麼證據，它才會翻上第一位**
1. **肛門指診摸到大量硬便**（決定性，一項就翻）
2. 腹部 X 光見廣泛糞便滯留而**無明顯近端擴張與氣液平面**
3. 問出這兩週水分、飲食、活動量明顯減少
4. 問出有服用鴉片類止痛藥、鐵劑或鈣片

**翻上來的臨床意義**：處置從「緊急處理阻塞、可能急診手術」變成「**灌腸或挖便、補水、軟便劑**」，然後把重點完全移到那個懸而未決的手術決定上。
**這個翻盤的代價很低但價值很高**——省下一次不必要的急診手術，而且讓病人不會在恐慌中被推進開刀房。

---

## ③ 不能排除：阻塞近端穿孔／閉環型阻塞併腸缺血

**這一格放的是漏掉會死人的診斷。**

**為什麼即使目前還有排氣、看起來還好，仍必須主動排除**
- **大腸阻塞有一個特殊的危險**：若迴盲瓣功能正常，氣體與內容物**只能進不能退**，形成**閉環（closed loop）**。壓力會集中在盲腸——盲腸腔徑最大，依 Laplace 定律承受的張力也最大，**所以最先破的往往不是腫瘤本身，而是離腫瘤很遠的盲腸。**
- 這代表：**病人可以「還有排氣」、看起來還好，同時盲腸已經瀕臨破裂。**
- 63 歲、務農、教育程度中學、又剛得知癌症——她可能會忍痛，也可能把不適歸因於「癌症本來就會不舒服」。

**排除它的最低限度**
> **腹部理學（有無局部固定壓痛與反彈痛）＋ 一組生命徵象含體溫 ＋ 腹部立姿 X 光看盲腸直徑與有無游離氣體。**

若出現右下腹（盲腸位置）固定壓痛、發燒、心搏過速，或 X 光見盲腸明顯擴張 → **不能再等，立即通知外科**。

# 8. 口試委員最可能追問的五題

**Q1「病人說還有排氣，這件事對你的判斷有什麼意義？」**
> 它告訴我目前是部分阻塞而不是完全阻塞，所以我有時間把檢查做完整、也有時間跟病人談，不必立刻推進開刀房。
> 但我不會因此放心。大腸阻塞如果迴盲瓣還有功能，會形成閉環，壓力集中在盲腸，**病人可以還在排氣、同時盲腸已經快破了**。所以「還有排氣」讓我調整節奏，不會讓我降低警覺。

**Q2「病人已經確診大腸癌，你為什麼還把便祕列進鑑別診斷？」**
> 因為「已知癌症」這個標籤最容易綁架判斷。她這兩週剛得知診斷、又在猶豫手術，吃得少、喝得少、動得少、睡不好，這些本身就足以造成便祕。
> 而且這兩個的處置差非常多——一個是緊急手術，一個是灌腸加軟便劑。分辨它們只需要一次肛門指診。**用一個五分鐘、不用儀器的檢查，去避免一次不必要的急診手術，這個投報率很高。**

**Q3「她兩週前就被建議開刀，到現在還沒決定。你會怎麼處理？」**
> 我會先問，而且用開放式的問法：「是什麼讓您猶豫？」不預設她是不配合或不理解。
> 63 歲、務農、教育程度中學，她的顧慮可能是很具體的事——怕做人工肛門、怕沒人照顧家裡、怕花錢、或是聽了親友的說法。**這些顧慮如果沒有被問出來，任何衛教都是在對空氣講話。**
> 而且她今天會出現在急診，本身就是一個訊號：問題沒有因為她不決定而消失。這是一個很自然的切入點。

**Q4「你為什麼要開電腦斷層？她不是已經診斷了嗎？」**
> 有兩個理由。第一是急性的：確認阻塞在哪一段、有多嚴重。
> 第二個理由更重要——**「初期」是她兩週前轉述的，我沒有看到報告。** 分期到底完整不完整、有沒有淋巴結、有沒有肝或肺轉移，這些會決定手術的方式和預後。
> 而且她猶豫的原因很可能就是資訊不足。**一份完整的分期資料是把決定權真正還給她的前提**，不然她是在資訊不完整的情況下被要求做決定。

**Q5「請向病人解釋。」**
> 阿姨，您這五天大便解不出來，但還會排氣，這代表腸子還沒有完全塞住，我們還有時間把事情弄清楚。
> 我等一下會做一個肛門指診，看看大便是不是卡在最下面那一段，這個檢查會有點不舒服但很快。然後照張肚子的 X 光，抽血看營養和發炎的狀況，再安排一次電腦斷層。
> 電腦斷層除了看哪裡塞住，也可以把腫瘤的範圍看清楚，這樣醫師才能告訴您如果要開刀，會是怎麼樣的一個刀。
> 另外我想跟您聊一下——兩個星期前醫師建議您開刀，您到現在還沒決定，是有什麼讓您比較擔心的嗎？您說出來，我們可以一起想辦法。

# 9. 我不確定的地方

1. **閉環型大腸阻塞與盲腸破裂的直徑閾值**——我知道有一個常被引用的盲腸直徑數值，但確切數字與其可靠度我沒有把握，**口試不要講數字**，講「盲腸明顯擴張」即可。
2. **「初期大腸癌」兩週內進展到阻塞的合理性**——我判斷不尋常，但這個判斷有多強，我信心中等。
3. **大腸癌併阻塞的處置選擇（直接手術 vs 支架 bridge to surgery vs 造口）**——台灣的實務與健保給付狀況我不確定，若被追問建議答「依外科醫師與腫瘤團隊評估」。
4. **CEA 在術前的角色**——我寫的是「不能診斷、只作基準」，這個說法我信心較高，但它是否為台灣常規術前必驗項目我不確定。
5. **肛門指診在 OSCE 考場的呈現方式**——通常用模型或只口頭說明，實際做法請依你們考場慣例。
6. **醫病共享決策（SDM）在專科護理師甄審的評分權重**——這一題的溝通線我寫得很重，但 NP 口試委員是否期待考生主動處理「病人拒絕手術」這個議題，我無法判斷。**這一點你比我清楚，若委員只想聽臨床推理，第 8 節 Q3 那段可以精簡。**
