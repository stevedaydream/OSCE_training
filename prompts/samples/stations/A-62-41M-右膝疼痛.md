# A-62｜41 歲男性，右膝疼痛

> Prompt A 輸出（**新版十節格式：委員不提問；先對病人收尾再向委員報告；權責邊界已校正**）。
> 臨床內容未經人工審核，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #62）

41 歲男性，右膝疼痛。
半夜一點左右，因突然感覺右膝疼痛而醒過來就無法再入睡，持續性的疼痛如同撕筋裂骨，走站時更痛而且根本沒辦法蹲下。吃了一顆普拿疼，痛稍為好一點，但還是持續沒有停止，感覺體溫有點熱，因為痛到沒辦法上班，早上請假趕快前來門診就醫。

---

# 1. 情境事實清單

- 41 歲男性
- **半夜一點左右突然**右膝疼痛**而痛醒**，無法再入睡
- **持續性疼痛，形容「如同撕筋裂骨」**
- **走、站時更痛，完全無法蹲下**
- 吃一顆普拿疼**只稍微好一點，疼痛持續未停**
- **自覺體溫有點熱**
- 痛到無法上班，早上請假來門診

**情境未給**：**實際體溫與生命徵象**、膝關節有無紅腫、**有無外傷史**、**有無痛風或高尿酸病史**、飲酒與飲食習慣、用藥（尤其利尿劑）、其他關節有無症狀、**有無皮膚傷口**、有無性接觸史、有無最近的關節注射或手術。

---

# 2. 第一印象與危險分流

**41 歲男性、半夜突發、單一關節、劇痛到痛醒、走不動蹲不下、還自覺有點熱。**

這是**急性單一關節炎（acute monoarthritis）**，而急性單關節炎有一條鐵律：

> **在證明不是之前，先當作化膿性關節炎（septic arthritis）。**

原因是它是這一組裡**唯一會在幾天內不可逆地破壞關節軟骨、而且可能走向敗血症**的診斷，
而它在臨床上**看起來和痛風幾乎一模一樣**——都是紅、腫、熱、劇痛、動不了、可能發燒。

**「半夜痛醒」很有意義**【推論】：痛風的發作有明顯的**夜間與清晨傾向**，典型描述就是「半夜痛醒、連被子蓋上去都受不了」。這一點支持痛風。

**「感覺體溫有點熱」是本題最不能放過的一句**：
- 痛風**本身就會引起發燒**（結晶引發的強烈發炎反應），所以**發燒不能用來區分痛風與感染**
- 但**沒有量體溫，就連這個模糊的敘述都無法評估**
- **情境沒給體溫，這是必須第一個補上的資料**

**「普拿疼只稍微好一點」也有意義**【推論】：普拿疼（acetaminophen）**沒有抗發炎作用**，
對結晶引發的強烈發炎反應效果本來就有限。**所以「止痛藥無效」在這一題不代表病更重，只代表他吃錯了藥。**
這一點在問診時要釐清——**若他吃的是消炎止痛藥（NSAID）也完全無效，那才值得警覺。**

**41 歲第一次發作要問一件事**：痛風的典型首發部位是**大腳趾**（第一蹠趾關節）。
**直接以膝關節為首發**雖然可能，但相對不那麼典型——**所以必須問「以前有沒有其他關節痛過」。**

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **化膿性關節炎** | 急性單關節炎的鐵律；數日內破壞軟骨、可敗血 | **量體溫、看有無皮膚破口、抽血、關節液分析** |
| 關節周圍軟組織感染（蜂窩性組織炎） | 表淺感染，處置不同**且會影響能不能穿刺** | **看紅腫的範圍與界線、關節能否被動活動** |
| 出血性關節積血 | 若有外傷或使用抗凝血劑 | 問外傷史與用藥 |

# 3. 焦點式病史（5 分鐘，優先順序由上而下）

## 最優先的五題

1. **「以前有沒有這樣痛過？其他關節呢，尤其大腳趾？」**
   → **痛風的典型首發是大腳趾。有過類似發作會大幅提高痛風的機率**
2. **「有沒有發燒、發冷發抖？有量過體溫嗎？」**
   → 情境只說「感覺有點熱」，**必須具體化**。畏寒發抖（rigor）偏菌血症
3. **「膝蓋這邊皮膚有沒有破皮、傷口、被蟲咬、或最近打過針、抽過關節液？」**
   → **細菌進入關節的門戶。這一題直接問到化膿性關節炎的機轉**
4. **「最近有沒有撞到、扭到、或運動傷害？」**
   → 排除外傷性關節積血與半月板／韌帶損傷
5. **「您吃的止痛藥是普拿疼還是消炎止痛藥？有沒有吃過別的？」**
   → **釐清「止痛無效」的意義**（見第 2 節）

## 痛風相關（必問，情境完全沒給）

- **有沒有被驗出過尿酸高？有沒有在吃降尿酸的藥？**
- **喝酒嗎？尤其啤酒？喝多少？多久一次？**
- 常吃海鮮、內臟、火鍋湯、含糖飲料嗎？
- **有沒有在吃利尿劑或阿斯匹靈？**（會影響尿酸排泄）
- 有沒有高血壓、糖尿病、高血脂、腎臟病？（代謝症候群與痛風高度相關）
- **家族有沒有人有痛風？**
- 最近有沒有脫水、劇烈運動、或飲食大幅改變？（誘發因子）

## 感染與其他風險（必問）

- **有沒有糖尿病、有沒有在吃類固醇或免疫抑制劑？**（化膿性關節炎的風險因子）
- 有沒有靜脈注射毒品？
- **最近有沒有其他部位的感染**（皮膚、泌尿道、肺部、牙齒）？
- 有沒有性接觸史？有沒有尿道分泌物或結膜炎？（淋球菌性關節炎；問法要有分寸）
- 有沒有其他關節同時腫痛？（多關節 → 往反應性或自體免疫方向）
- 有沒有乾癬、腹瀉、下背痛？（脊椎關節病變）
- 有沒有人工關節？

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| **沒有皮膚破口、沒有近期關節注射或手術、無人工關節** | **降低化膿性關節炎**（但**血行性播種仍可能，不能完全排除**） |
| 沒有糖尿病、未使用類固醇或免疫抑制劑 | 降低化膿性關節炎風險 |
| 沒有外傷、沒有使用抗凝血劑 | 降低關節積血 |
| 沒有其他關節同時腫痛 | 降低多關節炎（類風濕、反應性關節炎） |
| 沒有畏寒發抖 | 降低菌血症（但不排除） |

# 4. 焦點式身體評估（5 分鐘，最多 8 項）

| 必做？ | 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **必做** | **生命徵象含體溫** | — | 「我先幫您量體溫、血壓和脈搏，目的是確認您說的『有點熱』實際是幾度，還有有沒有全身性的感染反應。」 | **需取得。可能低度發燒** | **高燒 ＋ 心搏過速 ＋ 低血壓 → 敗血症，立即通報** |
| **必做** | **雙膝視診（一定要露出兩腳比較）** | 雙膝、大腿至小腿 | 「請您把兩邊褲管拉高，我要比較兩隻腳的膝蓋。目的是看腫脹、發紅的範圍和程度。我會注意隱私。」 | **右膝腫脹、發紅、皮膚緊繃發亮** | 紅腫**超出關節範圍往上下延伸且界線模糊 → 蜂窩性組織炎** |
| **必做** | **皮膚完整性檢查（找感染入口）** | 右膝周圍、小腿、足部、趾縫 | 「我要仔細看您膝蓋周圍和整隻腳，包括腳趾縫。目的是找有沒有傷口、破皮或蟲咬，那可能是細菌跑進去的入口。」 | **無破口** | **有傷口或膿 → 化膿性關節炎風險大增，且影響穿刺路徑** |
| **必做** | **皮膚溫度（雙側對比）** | 雙膝 | 「我用手背摸您兩邊膝蓋，比較溫度。目的是確認發炎的程度。」 | **右膝明顯較熱** | — |
| **必做** | **關節積液評估（浮髕試驗）** | 右膝 | 「我要把您膝蓋上方的液體往下推，再輕壓髕骨。目的是確認關節腔裡面有沒有積水，這關係到要不要抽關節液。」 | **陽性：關節腔內有積液** | 陰性 → 積液少或病灶在關節外 |
| **必做** | **關節活動度（主動與被動）** | 右膝 | 「請您自己慢慢彎曲伸直膝蓋，能到哪裡就停。然後放輕鬆，讓我幫您動。目的是分辨疼痛是來自關節裡面還是外面——**關節內發炎的話，連我幫您動都會很痛**。」 | **主動與被動皆嚴重受限且劇痛** | **被動活動相對不痛 → 病灶在關節外（蜂窩性組織炎、滑囊炎）** |
| 有時間 | **其他關節快速掃視** | 大腳趾、足踝、手指、手腕 | 「我快速看一下您其他關節，特別是大腳趾。目的是確認是只有膝蓋還是多個關節，也看有沒有痛風石。」 | 其他關節正常 | **多關節受影響 → 往反應性或自體免疫方向**；耳廓或關節旁結節 → 痛風石 |
| 有時間 | 腹股溝淋巴結 ＋ 全身感染源掃視 | 右鼠蹊、全身 | 「我摸一下您右邊鼠蹊部的淋巴結，也快速看一下有沒有其他地方在發炎。目的是找感染的來源。」 | 正常 | 淋巴結腫大 → 下肢感染 |

**這一題的檢查順序為什麼這樣排**：**先量體溫，因為情境只給了「感覺有點熱」這個模糊敘述，而它是分辨嚴重度的起點。**
接著**視診一定要兩腳一起看**——單看患側判斷不出腫脹程度。
**主動與被動活動度放在最後**，因為那是最痛的動作，做完病人會很難再配合其他檢查。

> **第 6 項（被動活動）值得特別記住**：這是**分辨「關節內」與「關節外」最便宜的一個動作**。
> 關節腔內發炎的病人，**別人幫他動也會劇痛**；蜂窩性組織炎或滑囊炎的病人，
> **被動活動相對可以忍受**。這個差別直接決定要不要抽關節液。

# 5. 需安排的檢查

## 階段一：床邊立即

- **完整生命徵象含體溫**
- **POCT 血糖**（糖尿病是化膿性關節炎的風險因子）

## 階段二：關節液分析（**本題的關鍵，且優先於所有影像**）

- **關節穿刺併關節液分析（arthrocentesis）** ← **這一題唯一能給答案的檢查**
  - **由醫師執行**
  - 送驗四項：
    1. **細胞數與分類**（白血球數 ＋ 嗜中性球比例）
    2. **革蘭氏染色與細菌培養** ← **排除化膿性關節炎**
    3. **偏光顯微鏡看結晶** ← **診斷痛風（尿酸鈉針狀負雙折射結晶）或假性痛風**
    4. 外觀（清澈／混濁／膿樣／血性）
  - **⚠️ 若穿刺路徑上的皮膚有蜂窩性組織炎，不可穿過感染區穿刺**——會把細菌帶進原本無菌的關節腔

## 階段三：影像（本題價值有限）

- **膝關節 X 光**
  - 目的：排除骨折、看有無慢性痛風的骨侵蝕、或假性痛風的軟骨鈣化
  - **⚠️ 急性期的 X 光通常只看到軟組織腫脹，對診斷幫助有限**
- 關節超音波：可看積液、導引穿刺，部分院所使用
- MRI：**急性期不需要**，僅在懷疑骨髓炎或內部結構損傷時

> **這一題的檢查排序，是整組題目裡最違反直覺的一個，所以要講清楚。**
>
> 前面幾題的原則是「**先做非侵入的，能回答就不要做侵入的**」。
> **但這一題最該優先做的，反而是侵入性的關節穿刺。**
>
> 理由是：**這一題的關鍵問題是「這關節裡面有沒有細菌」，而沒有任何非侵入的檢查答得出來。**
> - X 光急性期只看得到軟組織腫脹
> - 抽血的白血球與 CRP **痛風和感染都會上升，分不開**
> - 超音波看得到積液，**但看不出積液裡面是結晶還是細菌**
>
> **而且關節液一抽出來，它同時回答了兩個問題**——結晶鏡檢確認痛風、革蘭氏染色與培養排除感染。
> **一次穿刺，兩個答案。**
>
> **所以原則沒有改變，原則一直是「用最低成本回答關鍵問題」。**
> 在這一題，唯一答得出關鍵問題的就是關節穿刺，那它就是最低成本。
> **為了避免侵入性而先做一堆影像和抽血，結果是延誤了化膿性關節炎的診斷——那個代價高得多。**

# 6. 檢驗

**即時／常規（1 小時內）**

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| **關節液細胞數 ＋ 分類** | **白血球數愈高、嗜中性球比例愈高，愈偏化膿性關節炎。** 但**痛風也可以很高，兩者的範圍會重疊** |
| **關節液革蘭氏染色** | **陽性 → 化膿性關節炎確立。⚠️ 陰性不能排除**（敏感度不足） |
| **關節液偏光顯微鏡** | **見尿酸鈉結晶 → 支持痛風**；焦磷酸鈣結晶 → 假性痛風 |
| CBC/DC | WBC ↑ 併 left shift → 發炎。**痛風與感染都會上升，不能用來區分** |
| CRP、ESR | ↑ → 發炎。**同上，不能區分** |
| **血液培養 ×2** | **若懷疑感染，抗生素前務必抽** |
| **血糖、HbA1c** | 糖尿病是化膿性關節炎風險因子 |
| BUN/Cr、eGFR | **腎功能會影響用藥選擇（NSAID、秋水仙素、降尿酸藥都受影響）** |
| 肝功能 | 用藥前基準 |

**血中尿酸（uric acid）**
> ⚠️ **這一項要特別講清楚，因為它是最常見的誤用。**
> **血中尿酸不能用來診斷痛風，也不能用來排除痛風。**
> - **急性發作期的尿酸值可能是正常的，甚至偏低**
> - 尿酸高的人**大多數一輩子不會發作**
>
> 它的角色是**發作緩解後評估與長期治療的追蹤依據**，不是急性期的診斷工具。
> **口試若提到尿酸，一定要主動說出這個限制。**

# 7. 前三個鑑別診斷

## ① 主診斷：急性痛風性關節炎

**支持證據**
- **半夜突然發作、痛到醒過來**——痛風典型的夜間／清晨發作模式【已知】
- **疼痛極為劇烈**（「如同撕筋裂骨」）——結晶引發的強烈發炎反應【已知】
- **單一關節**【已知】
- **41 歲男性**——好發族群【已知】
- **自覺發熱**——痛風本身即可引起發燒【已知】
- **走站更痛、完全無法蹲下**——關節腔內張力升高【已知】
- 預期：右膝紅、腫、熱、浮髕試驗陽性、主動與被動活動皆劇痛【推論】

**不支持之處（誠實列）**
- **痛風的典型首發部位是大腳趾（第一蹠趾關節），直接以膝關節首發相對不典型。** 必須問「以前有沒有其他關節痛過」。
- 情境**完全沒有提供高尿酸病史、飲酒史、飲食習慣、用藥或家族史**——痛風的風險因子全部缺席，必須問診補上。
- 情境**沒有給實際體溫**，只有「感覺有點熱」。
- 情境未描述關節外觀（紅腫程度）。
- **「普拿疼只稍微好一點」不能當作支持證據**——普拿疼沒有抗發炎作用，本來就對痛風效果有限。

**確診依據**
> **關節液偏光顯微鏡見尿酸鈉結晶（針狀、負雙折射），且革蘭氏染色與培養陰性。**
> **臨床表現再典型也不能取代關節液分析**，因為痛風與感染可以並存。

---

## ② 次可能：關節周圍軟組織感染（蜂窩性組織炎／髕前滑囊炎）

**為什麼它還留在名單上——而且它會改變操作決策**

膝蓋前方的紅、腫、熱、痛，**不一定來自關節腔裡面**。**髕前滑囊炎**（常見於長期跪姿工作者）與**蜂窩性組織炎**都會造成一模一樣的外觀，而它們是**關節外**的問題。

**這一格的重要性不只是診斷，而是它直接影響能不能做關節穿刺：**
> ⚠️ **如果穿刺路徑上的皮膚有蜂窩性組織炎，穿刺針會把皮膚上的細菌帶進原本無菌的關節腔，
> 把一個關節外的感染變成一個關節內的感染。**

**要出現什麼證據，它才會翻上第一位**
1. **被動活動關節時相對不痛**（決定性——**關節腔內發炎的病人，別人幫他動也會劇痛**）
2. **紅腫的範圍超出關節、往大腿或小腿延伸，且界線模糊**
3. **浮髕試驗陰性**（關節腔內沒有積液）
4. 腫脹侷限在髕骨正前方、可摸到界線清楚的囊狀腫塊（滑囊炎）
5. 有明確的皮膚破口或跪姿相關的職業史

**翻上來的臨床意義**：從「關節穿刺 ＋ 可能住院打抗生素」變成「**抗生素治療軟組織感染、患肢抬高、且不可貿然穿刺**」。
**這是本題唯一會改變「要不要做那個侵入性動作」的鑑別。**

---

## ③ 不能排除：化膿性關節炎（septic arthritis）

**這一格放的是漏掉會毀掉關節、甚至致命的診斷。**

**為什麼即使痛風的表現很典型，仍必須主動排除**
- **化膿性關節炎與痛風在臨床上幾乎無法區分**——都是急性、單關節、紅腫熱痛、活動受限、可能發燒
- **抽血分不開**：WBC、CRP、ESR 在兩者都會上升
- **細菌會在數日內不可逆地破壞關節軟骨**，延誤的代價是永久的功能損失
- **可進展為敗血症**
- **最危險的認知錯誤是：「他看起來就是痛風，先給消炎藥觀察」**
- **而且痛風與化膿性關節炎可以並存**——找到尿酸結晶**不等於排除了感染**

**排除它的最低限度**
> **一次關節穿刺，送革蘭氏染色、細菌培養與細胞數。**
>
> 沒有任何替代方案。X 光、抽血、超音波都答不了這個問題。
> **在關節液培養結果出來之前，這個診斷不能被排除。**
>
> 若同時有**高燒、畏寒發抖、心搏過速或低血壓** → 這不只是關節的問題，
> **要當作敗血症處理，並在給抗生素前先抽血液培養。**

> **一句要記住的話**：**急性單一關節炎，在證明不是之前，先當作化膿性關節炎。**

---

# 8. 兩段逐字稿（注意順序：先對病人，再向委員）

> 專科護理師甄審口試中**委員不提問**。實際流程是：
> **身體評估做完 →〔8a〕先跟病人收尾並去通知醫師 →〔8b〕才向委員報告鑑別診斷。**

## 8a. 身體評估結束後，對病人說明（約 1 分鐘）

> 先生，我需要的檢查都做完了，謝謝您配合。
>
> 從我剛才的評估來看，**您的右膝關節有明顯的發炎反應——紅、腫、熱，而且我幫您動的時候也很痛，這代表問題是在關節裡面**。這種半夜突然痛醒的劇烈關節痛，有幾個常見的原因，我需要進一步確認。
>
> 我現在會先請您**這隻腳不要用力、不要走動，我幫您把腳墊高，也會先冰敷**，這樣可以減輕一點腫脹和疼痛。**在還沒確認之前，請先不要自己再吃止痛藥**，也**先不要吃東西喝水**，等一下有需要處置的話會比較方便。
>
> **我現在就會去向您的主治醫師報告您的狀況和我評估到的結果，由醫師來決定接下來要怎麼處理，醫師也會再過來跟您說明。**
>
> **如果這段時間您開始發冷發抖、發高燒、或覺得整個人很不舒服、頭暈，請立刻按鈴叫我，我會馬上再通知醫師。**

## 8b. 向口試委員報告鑑別診斷（約 3 分鐘）

> 報告委員。這位是 41 歲男性，主訴是**今天凌晨一點突然右膝劇痛而痛醒，無法再入睡**，形容疼痛「如同撕筋裂骨」，走站更痛、完全無法蹲下，並自覺體溫有點熱。
>
> 病史方面，他吃了一顆普拿疼只稍微緩解。**我特別釐清了他吃的是普拿疼而不是消炎止痛藥，因為普拿疼沒有抗發炎作用，對這類發炎本來就效果有限——所以「止痛無效」在這一題不代表病情更重。**
> 我另外追問了幾項情境沒有提供的：**以前有沒有其他關節痛過，尤其大腳趾**、**有沒有量過體溫、有沒有畏寒發抖**、**膝蓋周圍有沒有傷口或最近打過針**、**有沒有外傷**、以及**高尿酸病史、飲酒、利尿劑使用與家族史**，答案分別是 ___。
>
> 身體評估方面，**體溫為 ___**；雙膝比較下右膝腫脹發紅、皮膚溫度明顯較高；**皮膚完整性檢查未見破口**；**浮髕試驗 ___**；**主動與被動活動皆嚴重受限且劇痛**。
>
> 綜合以上，**我認為最可能的健康問題是急性痛風性關節炎**。理由是半夜突發、單一關節、疼痛極為劇烈、41 歲男性屬好發族群，而且痛風本身就會引起發燒。
> **不過我要誠實指出一點：痛風的典型首發是大腳趾，直接以膝關節首發相對不典型**，所以「以前有沒有發作過」這一題對我的判斷很重要。
>
> **第二個可能是關節周圍的軟組織感染，也就是蜂窩性組織炎或髕前滑囊炎。** 它還在名單上是因為膝前的紅腫熱痛不一定來自關節腔裡面。
> **如果被動活動關節時相對不痛、紅腫範圍超出關節往上下延伸且界線模糊、浮髕試驗陰性，它就會翻上第一位。**
> **而這個鑑別特別重要，因為它會改變操作決策——如果穿刺路徑上的皮膚有蜂窩性組織炎，穿刺針會把皮膚的細菌帶進原本無菌的關節腔，把一個關節外的感染變成關節內的感染。**
>
> **另外我認為必須主動排除的是化膿性關節炎。** 它的機率不一定最高，但**漏掉的後果是細菌在幾天內不可逆地破壞關節軟骨，而且可能走向敗血症**。
> 最麻煩的是**它和痛風在臨床上幾乎無法區分**——都是急性、單關節、紅腫熱痛、可能發燒，而**抽血也分不開，白血球和 CRP 兩者都會上升**。
> **而且痛風和化膿性關節炎可以並存，找到尿酸結晶不等於排除了感染。**
>
> **關於檢查，我的建議是關節穿刺與關節液分析，而且它應該優先於所有影像。**
> 我知道這違反「先做非侵入的」這個原則，但**這一題的關鍵問題是「關節裡面有沒有細菌」，而沒有任何非侵入的檢查答得出來**——X 光急性期只看得到軟組織腫脹，抽血分不開兩者，超音波看得到積液但看不出裡面是結晶還是細菌。
> **而關節液一抽出來就同時回答兩個問題：偏光顯微鏡看結晶確認痛風，革蘭氏染色與培養排除感染。一次穿刺，兩個答案。**
> 所以原則沒有改變，原則一直是用最低成本回答關鍵問題，只是在這一題，唯一答得出來的就是穿刺。
>
> 另外我會建議抽 CBC、CRP、腎功能與血糖，若懷疑感染則在抗生素前先抽血液培養。
> **關於血中尿酸我要特別說明：它不能用來診斷痛風，也不能用來排除痛風。急性發作期的尿酸值可能是正常甚至偏低的，而尿酸高的人大多數一輩子不會發作。它的角色是發作緩解後長期治療的追蹤依據。**
>
> 這些發現與建議我已經向主治醫師報告，關節穿刺與後續處置由醫師評估決定。報告完畢。

# 9. 我不確定的地方

1. **關節液白血球數區分痛風與化膿性關節炎的切點**——**我刻意沒有寫任何數字，因為兩者範圍重疊且切點各家不同。口試不要講數字，講「愈高愈偏感染，但會重疊」即可。**
2. **關節液革蘭氏染色的敏感度**——我知道不足以排除，數字沒有把握。
3. **痛風以膝關節為首發的實際比例**——我判斷「相對不典型」，比例不確定。
4. **急性期使用降尿酸藥物的原則**——一般認為急性期不宜開始或停用，但細節與現行建議請查證，**我不提供藥名與劑量**。
5. **秋水仙素與 NSAID 在腎功能不佳者的使用限制**——方向我有把握，具體限制請以藥師或醫師指引為準。
6. **髕前滑囊炎的職業關聯**（跪姿工作）——方向應該對，強度不確定。
7. **關節穿刺是否為專科護理師的執行範圍**——**我全篇都寫成「由醫師執行、我向醫師報告與建議」**。若你們醫院的實務不同，或 NP 在督導下可執行，這一點請依實際情況調整。**這是本題最需要你確認的一項。**
8. **8a 裡「先不要吃東西喝水」是否恰當**——我寫進去是考量可能需要處置，但若你認為門診的膝關節穿刺不需要禁食，這一句可以拿掉。

| :--- | :--- | :--- |
| 0:00–1:00 | 自我介紹、確認身分、複述主訴 | — |
| 1:00–6:00 | 焦點式病史 | 第 3 節「最優先的五題」＋ 痛風與感染風險因子 |
| 6:00–11:00 | 焦點式身體評估 | 第 4 節 6 項必做：**體溫 → 雙膝視診 → 皮膚完整性 → 溫度 → 浮髕試驗 → 主被動活動度** |
| 11:00–12:00 | **對病人說明、權限內處置（抬高冰敷、限制活動）、告知會去通知醫師** | 第 8a 節逐字稿 |
| 12:00–15:00 | **向委員報告鑑別診斷**（單向，委員不會問） | 第 8b 節逐字稿 |

**如果只剩 5 分鐘，我會先放掉這三項：**

1. **其他關節快速掃視**——找痛風石與多關節侵犯有幫助，但**這一題是急性單關節炎，主要決策不靠它**。改成問一句「其他關節有沒有也在痛」。
2. **腹股溝淋巴結與全身感染源掃視**——同樣改成問診（「最近其他地方有沒有在發炎」），省下觸診時間。
3. **皮膚溫度的雙側對比**——這一項可以**併進視診時順手用手背摸一下**，不另外算一個步驟。

**放掉它們最不傷的理由**：這三項都是**補強或可以用問診替代**的。
**我保留的核心是四件事：體溫（分辨嚴重度的起點）、皮膚完整性（感染的入口，也決定能不能穿刺）、浮髕試驗（有沒有積液可抽）、以及主動與被動活動度。**
其中**被動活動度絕對不能放掉**——它是**分辨「關節內」與「關節外」最便宜的一個動作**，而那個答案直接決定要不要建議醫師做關節穿刺。
