# A-17｜55 歲男性/女性，腹痛三天

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #17）

55 歲男性/女性，腹痛三天。
病患三天前參加朋友兒子的婚禮，返家之後覺得腹痛，同時有噁心嘔吐的情況。以為是急性腸胃炎，在診所拿藥吃，但是情況沒有改善，反而疼痛加劇，被家人送到急診。早上在家吐出大量墨綠色液體。

---

# 1. 情境事實清單

- 55 歲，性別可男可女
- 腹痛三天，起於參加婚宴返家後
- 伴噁心、嘔吐
- 自認急性腸胃炎，診所拿藥吃，**無改善且疼痛加劇**
- **今早吐出大量墨綠色液體**
- 由家人送急診

**情境未給**：生命徵象、有無排氣排便、腹脹程度、過去手術史、體重變化、排便習慣改變。

---

# 2. 第一印象與危險分流

**「大量墨綠色嘔吐物」是整題的核心。** 墨綠色代表膽汁，甚至是更遠端的腸內容物逆流回來。這不是腸胃炎會有的表現——腸胃炎吐的是胃內容物，而且會伴隨腹瀉、通常 24–48 小時緩解。

**三天不緩解 ＋ 疼痛加劇 ＋ 吐膽汁**，這三個一起出現，方向已經很明確：**腸道阻塞**。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **絞窄性腸阻塞／腸缺血壞死** | 已三天且持續惡化，是本題最致命的走向 | 看有無持續性劇痛（非陣發）、發燒、心搏過速、腹膜刺激徵、lactate |
| 絞窄性疝氣 | 中年病人腸阻塞的常見原因之一 | **視診加觸診腹股溝與陰囊、腹壁疤痕處** |
| 大腸癌併阻塞 | 55 歲，要主動想到 | 問排便習慣改變、血便、體重減輕 |
| 消化道穿孔 | 阻塞的併發症 | 立姿 CXR、腹部有無板硬 |

**婚宴這個線索怎麼看【推論】**：病人自己把它當成「吃壞肚子」的解釋，這是典型的**歸因偏誤**——一個貌似合理的解釋讓他延誤了三天。口試時要指出這一點：**發病時間點的巧合不等於病因**。

# 3. 焦點式病史

**L 部位**——痛的位置在哪？是整片還是一點？（瀰漫性絞痛偏阻塞；固定一點偏局部病灶）

**Q 性質**——**是一陣一陣的絞痛，還是一直持續的痛？**（這是本題最關鍵的一題：陣發性絞痛 = 單純阻塞；**轉為持續性劇痛 = 可能已絞窄壞死**）

**Q 程度**——三天來是持續加重嗎？【已知：加劇】

**O 時序**——婚宴後多久開始？吐了幾次？**墨綠色是今天才出現，還是一開始就是？**（顏色隨阻塞時間變深，代表阻塞位置與病程）

**P/E 誘發緩解**——吐完會不會比較舒服？（阻塞病人吐完常暫時緩解）；吃東西會不會更痛？

**R 相關症狀（本題最重要的一組）**
- **這三天有沒有放屁？有沒有解大便？**（完全不排氣不解便 = 完全阻塞；還有排氣 = 部分阻塞。這一題的答案直接改變處置急迫性）
- 肚子有沒有脹起來？脹的程度有沒有變化？
- 有沒有發燒、畏寒？
- 有沒有解血便或黑便？

**A 伴隨表現**
- 尿量有沒有變少？（三天嘔吐 ＋ 腸道積液 = 嚴重脫水）
- 頭暈、站起來會不會黑矇？（血容積不足）

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| 沒有腹瀉、同桌沒有人一起不舒服 | **降低急性腸胃炎與食物中毒**（這是本題最該問到的否定） |
| 沒有腹股溝腫塊 | 降低絞窄性疝氣 |
| 沒有解黑便、體重無明顯減輕 | 降低大腸癌 |

**其他必問（本題成敗關鍵）**
- **有沒有開過腹部的刀？任何刀都算，包括剖腹產、闌尾切除。**（術後沾黏是成人小腸阻塞最常見的原因。這一題沒問到，等於整個診斷少了最重要的一根柱子）
- 過去有沒有類似發作？
- 最近排便習慣有沒有改變？大便形狀有沒有變細？
- 過去病史、用藥（尤其鴉片類止痛藥可致麻痺性腸阻塞）、體重變化

# 4. 焦點式身體評估

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| 一般外觀與脫水評估 | 全身、口腔黏膜、皮膚張力 | 「我先看您的嘴唇和皮膚，目的是評估您這三天吐下來有沒有嚴重脫水。」 | 口乾、黏膜乾燥、皮膚張力差、心搏偏快 | — |
| 腹部視診 **含所有疤痕與腹股溝** | 腹部、雙側腹股溝、陰囊、臍部 | 「我要看您的肚子跟鼠蹊部，目的是看肚子脹的程度、有沒有以前開刀的疤痕，還要確認鼠蹊部有沒有腫塊，因為疝氣卡住也會造成腸阻塞。我會注意隱私。」 | **腹部膨脹**、可見**手術疤痕**、瘦的病人可見腸型蠕動波 | 疝氣：腹股溝可觸及壓痛硬塊 |
| **腸蠕動音聽診** | 四象限，聽足 1 分鐘 | 「我要用聽診器聽您肚子的腸子聲音，會聽久一點大約一分鐘，目的是判斷是腸子塞住了還是完全不動了。我會先聽再壓。」 | **高亢、金屬音、陣發性亢進**（early） | **腸音完全消失 → 已進展為麻痺或壞死，是壞消息不是好消息** |
| 腹部叩診 | 四象限 | 「我要輕敲您的肚子，目的是判斷脹起來的是氣還是水。」 | 廣泛鼓音（tympanic） | 大量腹水：移動性濁音 |
| 腹部觸診 | 四象限，痛處最後 | 「我要輕壓您的肚子找出最痛的位置，會痛請馬上告訴我。」 | 瀰漫性壓痛、腹部脹而軟 | **局部固定壓痛併 guarding → 高度懷疑該處已絞窄** |
| 反彈壓痛與肌肉防衛 | 全腹 | 「我要壓下去再快速放開，目的是看腹膜有沒有發炎。」 | 早期陰性 | **陽性 → 絞窄或穿孔，不能再等** |
| **疝氣孔觸診** | 雙側腹股溝、股三角、臍、疤痕 | 「我要摸您的鼠蹊部兩側和肚臍，目的是檢查有沒有腸子卡在這些位置。」 | 無腫塊 | 硬、壓痛、推不回去 = 嵌頓 |
| **肛門指診** | 肛門直腸 | 「我需要做肛門指診，目的是確認直腸裡有沒有大便、有沒有摸到腫瘤、有沒有血。這個檢查會不舒服但很快，我會拉上簾子並請同仁在旁陪同，您同意嗎？」 | 直腸空虛（阻塞在上游） | **摸到硬塊 → 直腸癌**；摸到大量硬便 → 糞便嵌塞 |

> 必做全部 8 項。本題的肛門指診**不可省略**——它同時回答「是不是大腸癌」和「是不是糞便嵌塞」兩個問題，而且不需要任何儀器。

# 5. 需安排的檢查

## 階段一：床邊立即

- **生命徵象與尿量**：三天嘔吐必須評估休克程度
- **靜脈血氣 ＋ lactate**：目的是 rule out 腸缺血。**Lactate ↑ 是本題最重要的紅旗**
- **POCT 血糖**
- **放置鼻胃管**：既是治療（減壓）也是診斷（引流出大量墨綠色液體即佐證阻塞）

## 階段二：非侵入性、無輻射

- **腹部 X 光（立姿＋臥姿，或臥姿＋左側臥）**
  - 目的：確認阻塞、初步判斷小腸或大腸、看有無游離氣體
  - 預期發現：**多個氣液平面（air-fluid levels）、腸管擴張**；小腸阻塞可見階梯狀排列
  - 陰性時下一步：X 光正常不能排除，仍需 CT
- **立姿胸部 X 光**：橫膈下游離氣體 → 穿孔

## 階段三：有輻射／顯影劑

- **腹部電腦斷層（含顯影劑）**

> **這一題 CT 是必要的，我不會為了省而不開。**
> 因為 X 光只能告訴我「塞住了」，回答不了決定處置的三個問題：
> **(1) 塞在哪一段（transition point）、(2) 為什麼塞（沾黏？腫瘤？疝氣？）、(3) 有沒有已經缺血壞死。**
> 這三個問題只有 CT 答得出來，而第三個直接決定是「先保守治療」還是「現在就進開刀房」。
> 超音波在充滿腸氣的腹部幫助有限，本題不是它的適應症。
>
> 這正好說明檢查排序的原則不是「永遠選便宜的」，而是「**能回答同一個問題時選便宜的**」。這裡便宜的那個回答不了問題。

# 6. 檢驗

**即時（< 15 分）**

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| **靜脈血氣 ＋ lactate** | **Lactate ↑ → 腸缺血壞死，最重要的紅旗** |
| 電解質（Na/K/Cl） | 大量嘔吐 → 低血鉀、低血氯、代謝性鹼中毒 |
| 血糖 | — |

**常規（1 小時內）**

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| CBC/DC | WBC ↑ 併 left shift → 發炎或已絞窄 |
| BUN/Cr | ↑ 且 BUN/Cr 比例升高 → 脫水（本例預期異常） |

| **CEA** | 若懷疑大腸癌可加驗，但**不能用來診斷**，只作日後追蹤基準 |

# 7. 前三個鑑別診斷

## ① 主診斷：機械性腸阻塞

**支持證據**
- **吐出大量墨綠色液體**——膽汁性嘔吐，指向幽門以下的阻塞【已知】
- 腹痛三天**持續加劇而非緩解**，不符合腸胃炎的自限病程【已知】
- 診所用藥（推測為腸胃炎的對症治療）完全無效【已知】
- 噁心嘔吐反覆【已知】
- 預期：腹脹、高亢金屬腸音、X 光多個氣液平面【推論】

**不支持之處**
- 情境**完全沒有提到排氣排便狀況**，而這是判斷完全或部分阻塞的關鍵。沒問到，這個診斷就停在「像」而不是「是」。
- 情境未提供手術史。成人小腸阻塞最常見原因是術後沾黏，沒有手術史的話病因要重新想（腫瘤、疝氣、腸扭轉）。
- 情境未提供腹脹描述。

**確診依據**
臨床（腹脹 ＋ 嘔吐 ＋ 停止排氣排便 ＋ 腹痛）＋ 影像（X 光氣液平面；CT 見擴張腸管與轉折點）。

---

## ② 次可能：大腸癌併阻塞

**為什麼它還留在名單上**
病人 55 歲，正是大腸癌需要主動排除的年齡。若他沒有腹部手術史，沾黏這個最常見原因就不成立，腫瘤的順位立刻往上跳。而且大腸癌造成的阻塞常有**數週到數月的前驅症狀**，病人自己不會主動聯想。

**要出現什麼證據，它才會翻上第一位**
1. 問出**近幾個月排便習慣改變、大便變細、間歇血便或不明體重減輕**
2. **肛門指診摸到腫塊**
3. **沒有任何腹部手術史**（沾黏被排除）
4. CT 見大腸有腫瘤性狹窄併近端腸管擴張

**翻上來的臨床意義**：處置從「鼻胃管減壓、輸液、保守觀察」變成「**腫瘤分期評估 ＋ 手術或支架介入的決策**」，而且要開始談癌症診斷。整個溝通內容完全不同。

---

## ③ 不能排除：絞窄性腸阻塞併腸缺血壞死

**這一格放的是漏掉會死人的診斷。**

**為什麼必須主動排除**
- 病程已三天且**持續惡化**——單純阻塞與已絞窄的病人，外觀可以很像
- 一旦腸壁缺血壞死，死亡率大幅上升，而且**時間就是腸子**
- 最危險的情境是：X 光看到氣液平面，就安心地掛上鼻胃管觀察，錯過已經壞死的腸段

**排除它的最低限度**
> **持續性劇痛（而非陣發性絞痛）＋ 發燒 ＋ 心搏過速 ＋ 局部固定壓痛與腹膜刺激徵，再加一個 lactate。**

臨床加一管血就能篩。若這幾項有任何一項成立 → **不要再等 CT 排隊，直接通知外科**。

> 有一個容易被誤讀的陷阱：**腸音從高亢金屬音轉為完全消失，不是好轉，是惡化。** 病人可能同時「感覺沒那麼絞痛了」，那是腸壁已經失去蠕動能力。

# 8. 口試委員最可能追問的五題

**Q1「病人自己說是吃壞肚子，你怎麼判斷不是？」**
> 三點對不上。第一，腸胃炎通常伴腹瀉，而且 24 到 48 小時會緩解，這位病人三天反而加劇。第二，腸胃炎吐的是胃內容物，這位病人吐的是大量墨綠色的膽汁。第三，對症治療完全無效。
> 婚宴只是時間上的巧合，病人拿它當解釋，反而延誤了三天。我不會接受病人自己給的歸因。

**Q2「你怎麼分小腸阻塞和大腸阻塞？」**
> 從三個方向：嘔吐出現得早而且量大偏小腸，腹脹明顯而嘔吐晚出現偏大腸；X 光上小腸的擴張在腹部中央、有環狀皺襞，大腸在周邊、有結腸袋；最後由 CT 確認轉折點。

**Q3「什麼情況你會說這個病人不能等，要馬上開刀？」**
> 疼痛從一陣一陣變成持續劇痛、發燒、心搏過速、腹部出現局部固定壓痛或腹膜刺激徵、lactate 上升、白血球明顯上升。這幾項代表可能已經絞窄壞死。另外如果 X 光看到橫膈下游離氣體，那就是已經穿孔，不必再等其他檢查。

**Q4「你為什麼一定要做肛門指診？」**
> 因為它不用任何儀器就同時回答兩個問題：直腸裡有沒有摸得到的腫瘤，以及是不是單純的糞便嵌塞。這兩個答案會直接改變後面的處置方向。省下這一項省不到三分鐘，卻可能漏掉一個摸得到的直腸癌。

**Q5「請向家屬解釋。」**
> 從症狀看，病人的腸子很可能塞住了。吐出來的墨綠色液體是膽汁，代表食物下不去、逆流回來，這不是一般的吃壞肚子。
> 我們現在會先放一條鼻胃管把胃裡的東西引流出來讓腸子減壓，同時打點滴補充這三天流失的水分，並安排 X 光和電腦斷層確認塞在哪一段、為什麼塞。
> 接下來要不要開刀，要看檢查結果和腸子的血流狀況，外科醫師會一起評估。
> 這段期間請不要讓他吃東西喝水。如果他的肚子越來越痛、開始發燒，請立刻告訴我們。

**SBAR 骨幹**
- **S**：55 歲病人，腹痛三天併噁心嘔吐，今晨吐出大量墨綠色液體。
- **B**：（依問診補）三天前婚宴後發病，自認腸胃炎，診所治療無效；有／無腹部手術史；排氣排便狀況。
- **A**：腹部膨脹、腸音高亢金屬音、瀰漫性壓痛、腹股溝無腫塊、肛門指診直腸空虛。**最可能為機械性腸阻塞**；因病人 55 歲，**大腸癌併阻塞不能排除**；因病程三天且持續惡化，**須主動排除絞窄性腸阻塞併腸缺血**。
- **R**：建議放置鼻胃管減壓、禁食、大量靜脈輸液矯正脫水與電解質，安排腹部立臥位 X 光、立姿 CXR、腹部 CT，抽 CBC/DC、電解質、BUN/Cr、CRP、lactate，通知外科評估。

# 9. 我不確定的地方

1. **墨綠色嘔吐物對應的阻塞位置**——我寫的是「幽門以下」，但顏色與阻塞高低的對應關係有多可靠，我信心中等，不要在口試講得太肯定。
2. **成人腸阻塞病因的排序（沾黏 > 疝氣 > 腫瘤）**——我知道大方向，但台灣的實際比例可能不同，具體百分比不要講。
3. **鼻胃管是否為現行常規**——近年有些指引對單純沾黏性阻塞不主張常規放置，台灣實務我不確定，請以你們醫院做法為準。
4. **大腸癌併阻塞是否直接手術或先放支架（stent as bridge to surgery）**——台灣的實務與健保給付狀況我沒有把握。
5. **肛門指診在 15 分鐘 OSCE 的操作方式**——考場通常用模型或只要求口頭說明，實際怎麼呈現、要不要真的做，請依你們考場的慣例。
6. **本題病人性別為「男性/女性」**——原題刻意不指定。若考場給的是女性，鑑別診斷需再加入婦科來源（卵巢腫瘤、扭轉）與懷孕可能，第 7 節要調整。
