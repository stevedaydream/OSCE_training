# A-47｜22 歲男性，胸痛

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #47）

22 歲男性，胸痛。
昨天晚上突然覺得右側胸痛，今天雖然有比較好，但還是覺得胸悶不舒服，感覺是尖銳的刺痛，痛會擴散到背後。今天早上覺得有點胸悶，深呼吸有些不順。這幾天因為要準備報告，都忙到很晚，心理壓力也很大，覺得很疲倦。胸痛發作的時候同時有點感到呼吸困難，休息了一個晚上，胸痛有好一點，但早上起來還是有些不舒服，還是蠻擔心的，因為以前沒有痛過，怕會不會再發生。過去身體都很好，沒有住過院、開過刀，沒有明顯外傷病史、平時沒有服用藥物、也沒有藥物過敏史。

**情境未給**：生命徵象、**血氧濃度**、身高體重與體型、抽菸史、有無咳嗽發燒、有無下肢腫痛、有無久坐或長途旅行、家族史。

# 2. 第一印象與危險分流

**22 歲男性、突發、單側、尖銳、與呼吸有關的胸痛，合併呼吸困難。** 這個組合在年輕人身上有一個排在最前面的答案：**自發性氣胸**。

三個支持它的特徵，情境全部給了：
1. **突然發生**（不是慢慢來的）
2. **單側、尖銳刺痛、會傳到背後**（肋膜性疼痛的典型描述）
3. **深呼吸不順 ＋ 同時有呼吸困難**（不只是痛，還有換氣的問題）

**「休息一晚有好一點」怎麼解讀【推論】**——這**不代表沒事**。小量氣胸的疼痛確實會在最初幾小時後減輕（急性肋膜刺激緩解），但**氣體還在裡面，肺還是塌的**。病人覺得「好一點」而延遲就醫，是氣胸很常見的模式。**痛減輕不等於氣體被吸收。**

**「壓力大、忙到很晚」是本題最大的陷阱**：這種敘述很容易把診斷帶往「焦慮」「肌肉緊繃」「胃食道逆流」。
**但一個 22 歲男性、突發單側胸痛加呼吸困難，在排除氣胸和肺栓塞之前，不能歸因於壓力。**

同時，「這幾天忙到很晚、久坐」也是**靜脈栓塞的風險因子**，所以這句話其實同時往兩個方向指。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **自發性氣胸** | 年輕男性 ＋ 突發單側肋膜性胸痛 ＋ 呼吸困難 | 生命徵象、**SpO2**、聽診、**肺部超音波或 CXR** |
| **張力性氣胸** | 氣胸最致命的形式，會迅速休克 | **氣管偏移、頸靜脈怒張、血壓下降**——臨床診斷，不等影像 |
| **肺栓塞** | 症狀重疊；久坐熬夜是風險因子 | 問下肢腫痛、久坐、家族史；SpO2、EKG |
| 主動脈剝離 | 22 歲極罕見，**除非有結締組織疾病** | **看體型（Marfan 特徵）**、量雙上肢血壓 |

# 3. 焦點式病史

## 把胸痛問完整

**L 部位**——**請用一根手指指出最痛的位置。**（能用一指定位 → 偏肋膜性或肌肉骨骼；用整個手掌壓胸口 → 偏心因性）

**Q 性質**——已知：尖銳刺痛，擴散到背後。追問：是不是像被刺到的感覺？**有沒有壓迫感、像被大石頭壓住？**（後者偏心因性）
**有沒有撕裂感？**（主動脈剝離）

**Q 程度**——昨晚最痛幾分？現在幾分？

**O 時序**——**昨晚幾點、在做什麼的時候突然開始？**（用力？咳嗽？搬東西？還是完全靜止時？）
**是瞬間到最痛，還是慢慢加重？**（瞬間到頂 → 氣胸、栓塞、剝離）

**P 誘發（本題關鍵）**
- **深呼吸會不會更痛？咳嗽呢？**（→ 肋膜性疼痛）
- **改變姿勢會不會影響？躺下、坐起、前傾？**（前傾緩解 → 心包炎）
- **按壓胸壁會不會痛？**（→ 肌肉骨骼；但**氣胸病人胸壁按壓通常不痛**，這是重要的區分）

**E 緩解**——什麼姿勢比較舒服？休息有沒有幫助？（已知：有好一點）

**R 相關症狀（情境給了呼吸困難，其餘要問）**
- **現在還會不會喘？走路、上樓會不會更喘？**
- **有沒有咳嗽？有痰嗎？有沒有咳血？**
- 有沒有發燒、畏寒？（肺炎、膿胸）
- 有沒有心悸、頭暈、快昏倒的感覺？（血行動力學受影響）
- 有沒有冒冷汗、噁心？

## 風險因子（本題必問，情境完全沒給）

**氣胸**
- **有沒有抽菸？抽多久？**（**抽菸大幅提高原發性自發氣胸的風險，情境完全沒提，必問**）
- **您的身高體重是多少？**（**高瘦體型是原發性自發氣胸的典型體型**）
- 家族有沒有人得過氣胸？
- 最近有沒有搭飛機、潛水、爬高山？（氣壓變化）
- 有沒有氣喘、肺部疾病？
- 有沒有使用電子煙或吸食任何東西？

**肺栓塞**
- **這幾天忙到很晚，是不是都坐著不太動？坐多久？**（情境已暗示，要具體化）
- **最近有沒有長途旅行、搭長程飛機？**
- **小腿有沒有腫、痛、變紅？**（深部靜脈栓塞）
- 最近有沒有骨折、打石膏、開刀、久臥？
- **家族有沒有人年輕就得過血栓或肺栓塞？**（遺傳性易栓症）
- 有沒有服用任何荷爾蒙類藥物？

**主動脈剝離（機率極低但成本低）**
- 家族有沒有人主動脈剝離、動脈瘤、或猝死？
- 有沒有被說過馬凡氏症候群或結締組織疾病？

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| 沒有發燒、沒有咳嗽有痰 | 降低肺炎與肋膜炎 |
| 沒有小腿腫痛、沒有長途旅行或久臥 | **降低肺栓塞**（但不排除） |
| 按壓胸壁不會痛、沒有搬重物或運動傷害 | 降低肌肉骨骼疼痛與肋軟骨炎 |
| 沒有撕裂痛、無家族動脈疾病史 | 降低主動脈剝離 |
| 沒有胃酸逆流、與進食無關 | 降低胃食道逆流 |
| 情境已給：無外傷史 | 排除外傷性氣胸與肋骨骨折 |

# 4. 焦點式身體評估

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| **生命徵象含 SpO2 與呼吸速率** | — | 「我先量血壓、心跳、呼吸和血氧濃度，目的是評估您的呼吸和循環有沒有受到影響。」 | **可能心搏稍快、SpO2 正常或略低** | **SpO2 明顯下降 ＋ 血壓下降 ＋ 心搏過速 → 張力性氣胸或大量肺栓塞** |
| **雙上肢血壓** | 雙側上臂 | 「我兩隻手都量，目的是比較左右差異，排除大血管的問題。」 | 兩側對稱 | 差距大 → 主動脈剝離 |
| **體型觀察（Marfan 特徵）** | 全身、四肢、手指 | 「我看一下您的身高體型和手指，目的是因為某些體型的人比較容易發生氣胸，也和血管的問題有關。」 | **可能高瘦**（原發性自發氣胸的典型體型） | 蜘蛛指、手臂展長大於身高、高顎弓 → 馬凡氏症候群 |
| **氣管位置觸診** | 胸骨上窩 | 「我輕輕摸您脖子下方氣管的位置，目的是確認氣管有沒有偏向一邊。」 | **置中** | ⚠️ **偏向健側 ＋ 頸靜脈怒張 ＋ 血壓下降 = 張力性氣胸，這是臨床診斷，必須立即減壓，不能等 X 光** |
| **頸靜脈** | 頸部 | 「我看一下您脖子的血管，目的是評估心臟回流的壓力。」 | 正常 | 怒張 → 張力性氣胸或心包填塞 |
| **胸廓視診（呼吸動作對稱性）** | 雙側胸廓 | 「請您深呼吸幾次，我從前面和側面觀察兩邊胸部起伏的對稱性，目的是看有沒有一邊動得比較少。」 | **右側胸廓起伏減少** | — |
| **胸壁觸診壓痛** | 肋骨、肋軟骨交界 | 「我要按壓您的胸壁和肋骨，目的是確認疼痛是不是來自胸壁的肌肉或軟骨。會痛請告訴我。」 | **按壓不痛**（重要的陰性） | **按壓會誘發完全相同的疼痛 → 肋軟骨炎／肌肉骨骼** |
| **觸覺震顫（tactile fremitus）** | 雙側胸壁 | 「請您重複說『一、二、三』，我把手放在您背上兩側比較振動的強弱，目的是判斷肺和胸壁之間有沒有空氣或積水。」 | **右側減弱** | 實變（肺炎）：增強 |
| **胸部叩診（雙側對稱比較）** | 雙側前胸與後背 | 「我要輕敲您的胸部和背部，兩邊對稱地比較，目的是分辨裡面是空氣還是實心的組織。」 | **右側過度反響（hyperresonance）** | 積液：濁音；肺炎實變：濁音 |
| **雙肺聽診（上中下、前後、對稱比較）** | 雙肺各區 | 「我要用聽診器聽您兩邊肺部的呼吸音，會從上到下、前面和背面都聽，兩邊對照。請您用嘴巴深呼吸。」 | **右側呼吸音減弱或消失，尤其肺尖** | 肺炎：局部囉音；氣喘：喘鳴 |
| 心臟聽診 | 心尖區、各瓣膜區 | 「我聽一下您的心音，目的是確認心律和有沒有雜音或心包摩擦音。」 | 正常 | 心包摩擦音 → 心包炎 |
| **雙下肢視診與觸診** | 雙側小腿、足踝 | 「我要看並摸您兩隻小腿，比較粗細、有沒有腫脹或壓痛，目的是檢查有沒有靜脈血栓，因為血栓跑到肺部也會造成胸痛和喘。」 | **對稱、無腫脹壓痛** | **單側小腿腫脹壓痛 → 深部靜脈栓塞 → 支持肺栓塞** |

> **本題的四個關鍵動作：SpO2、氣管位置、雙側叩診比較、雙側聽診比較。**
> 前兩項是為了**不漏掉張力性氣胸**（那是不能等影像的臨床診斷），後兩項是氣胸的核心理學徵象。
> **而「按壓胸壁不痛」這個陰性發現也很重要**——它把最常見的競爭診斷（肌肉骨骼疼痛）壓下去。

# 5. 需安排的檢查

## 階段一：床邊立即

- **SpO2 與生命徵象**
- **12 導程 EKG**
  - 目的：**rule out 心因性**，並看有無肺栓塞的間接徵象（竇性心搏過速最常見；右心負荷的變化較少見）
  - 預期發現：**竇性心搏過速或正常**
  - 30 秒、幾乎零成本
- **肺部超音波（POCUS）** ← **本題值得特別提出的一項**
  - 目的：看**肺滑動徵象（lung sliding）**是否消失
  - **優點：對氣胸的敏感度高於仰臥位胸部 X 光，床邊即時、零輻射**
  - **這對 22 歲病人特別有價值——能不讓他吃輻射就不要**

## 階段二：非侵入性、低輻射

- **胸部 X 光（立姿、吸氣相）** ← **標準診斷工具**
  - 目的：確認氣胸並**估計氣胸的量**（決定觀察、抽氣、還是放胸管）
  - 預期發現：**右側可見肺緣線，其外側無肺紋理**
  - ⚠️ **重要限制**：**小量氣胸在仰臥位 X 光上可能看不到**。所以要拍**立姿**。若病人躺著拍而報告正常，不能排除氣胸
  - 陰性時下一步：若臨床高度懷疑而立姿 CXR 正常 → 肺部超音波或低劑量 CT

## 階段三：有輻射／顯影劑

- **胸部電腦斷層**
- **電腦斷層肺動脈攝影（CTPA）**——診斷肺栓塞

> **這一題的檢查排序特別值得講，因為病人只有 22 歲，輻射劑量是真的要考慮的事。**
>
> **本題我不排電腦斷層。** 理由是：
> **一張立姿吸氣相的胸部 X 光，加上床邊肺部超音波，已經足以回答「有沒有氣胸、有多大」這個問題**，而這正是決定處置（觀察／抽氣／胸管）所需要的全部資訊。
> 胸部 X 光的輻射量遠低於 CT，肺部超音波則完全沒有輻射，而且**超音波對氣胸的敏感度比仰臥位 X 光還高**。
>
> **升級到 CT 的條件：**
> 1. 立姿 CXR 與超音波結果**互相矛盾**，或臨床高度懷疑但影像正常
> 2. 懷疑**續發性氣胸**（有潛在肺病，需評估肺大泡）
> 3. **反覆發作**，需評估是否手術
> 4. **懷疑肺栓塞 → 此時需要的是 CTPA，而不是一般胸部 CT**（兩者的顯影時相不同，開錯單答不了問題）
>
> **關於肺栓塞的檢查決策**：不是所有胸痛都要做 CTPA。應**先用臨床機率評估工具（如 Wells score）分層**，低機率者可用 **D-dimer** 排除（陰性即可排除），只有中高機率或 D-dimer 陽性才做 CTPA。
> **對 22 歲男性直接開 CTPA，是不必要的輻射與顯影劑暴露。**

# 6. 檢驗

**這一題的抽血很少，而且要說明為什麼少。**

| 項目 | 說明 |
| :--- | :--- |
| **D-dimer** | ⚠️ **只在肺栓塞臨床機率為低至中度時才有意義。**<br>**陰性可用來排除；陽性不能診斷**（感染、發炎、外傷、術後都會上升）。<br>若臨床機率高，**不論 D-dimer 結果都應直接做影像** |
| CBC/DC | WBC ↑ → 若懷疑感染 |
| CRP | 若懷疑肺炎或肋膜炎 |
| **Troponin** | 22 歲、無心血管風險因子，**非常規**。僅在 EKG 異常或臨床懷疑心肌炎／心包炎時加驗 |
| 動脈血氣 | 僅在 SpO2 明顯下降或呼吸窘迫時才需要 |
| 電解質、腎功能 | 若需使用顯影劑 |

> **主動說明「我不驗什麼」也是臨床推理的一部分。**
> 對一個 22 歲、沒有心血管風險因子的病人常規開 Troponin，看起來很周全，實際上是製造偽陽性的機會，並延長留觀時間。

# 7. 前三個鑑別診斷

## ① 主診斷：原發性自發性氣胸（右側）

**支持證據**
- **22 歲男性**——原發性自發氣胸最典型的族群【已知】
- **突然發生**的胸痛【已知】
- **單側（右側）**【已知】
- **尖銳刺痛、擴散到背後、深呼吸不順**——典型的肋膜性疼痛【已知】
- **同時有呼吸困難**——不只是痛，還有換氣問題【已知】
- **過去身體很好、無外傷、無服藥**——符合「原發性」（無潛在肺病）【已知】
- 預期：右側呼吸音減弱、叩診過度反響、觸覺震顫減弱、胸壁按壓不痛【推論】

**不支持之處（誠實列）**
- 情境**完全沒有提供 SpO2 與生命徵象**——而這決定嚴重度與急迫性。
- 情境**沒有提到抽菸與體型**——這兩項是原發性自發氣胸最重要的風險因子，缺席讓診斷的支持度打折。
- **「休息一晚有好一點」**——這符合小量氣胸（疼痛減輕但氣體仍在），但也符合肌肉骨骼疼痛。單看這一句無法分辨。
- 情境未提到咳嗽或用力等誘發動作。

**確診依據**
> **立姿吸氣相胸部 X 光見肺緣線且其外無肺紋理**，或**肺部超音波見肺滑動徵象消失**。

## ② 次可能：肌肉骨骼疼痛／肋軟骨炎

**為什麼它還留在名單上**
情境給了很強的背景暗示：**「這幾天準備報告都忙到很晚，心理壓力大，覺得很疲倦。」**
長時間伏案、姿勢不良、睡眠不足、壓力大——這些完全可以造成胸壁肌肉或肋軟骨的疼痛，而且**也會是尖銳的、與呼吸有關的、單側的**。加上「休息一晚有好一點」，這條路線說得通。

而且這是急診與門診中**最常見**的胸痛原因。

**要出現什麼證據，它才會翻上第一位**
1. **按壓胸壁能誘發出完全相同的疼痛**（決定性——這是最關鍵的一個動作）
2. 特定姿勢或轉身動作會誘發
3. **SpO2 正常、呼吸音兩側對稱、叩診無異常**
4. **立姿胸部 X 光完全正常**
5. 問出近期有搬重物、運動、或長時間維持同一姿勢

**翻上來的臨床意義**：從「可能需要抽氣或放胸管、住院觀察」變成「**消炎止痛、姿勢衛教、門診追蹤**」。

> ⚠️ **但這裡有一個順序不能顛倒的原則**：
> **必須先排除氣胸與肺栓塞，才能診斷肌肉骨骼疼痛。**
> 它是**排除性診斷**，不是因為「病人壓力大所以應該是這個」。
> **「壓力大加上疲倦」是本題最誘人的陷阱**——它給了一個聽起來很合理的解釋，讓人不去照那張 X 光。

## ③ 不能排除：肺栓塞

**這一格放的是漏掉會死人的診斷。**

**為什麼即使 22 歲、機率低，仍必須主動排除**
- **症狀與氣胸幾乎完全重疊**：突發、單側、肋膜性胸痛、呼吸困難
- **情境給了風險因子而且很容易被忽略**：**「這幾天準備報告都忙到很晚」= 長時間久坐不動**，這是靜脈栓塞的風險因子
- 年輕人的肺栓塞常被延誤，正是因為**「他才 22 歲，不可能」**這個假設
- 年輕族群仍可能有**遺傳性易栓症**，而且他們的第一次發作往往就是這樣被漏掉的
- **一旦是大量肺栓塞，可以在數小時內致死**

**排除它的最低限度**
> **一組完整生命徵象含 SpO2 ＋ 一張 EKG ＋ 病史問三題（小腿有沒有腫痛、有沒有長途旅行或久臥、家族有沒有人年輕得過血栓）＋ 雙下肢視診觸診。**
>
> 全部零成本，五分鐘內完成。
>
> **接下來用臨床機率分層決定**：
> - **低至中機率 → 驗 D-dimer，陰性即可排除**，不必做 CT
> - **高機率 → 直接做 CTPA**，不必等 D-dimer
>
> **重點是：不要對每一個年輕胸痛病人都開 CTPA，但也不要因為他年輕就完全不想這件事。**

# 8. 口試委員最可能追問的五題

**Q1「病人說壓力大、忙到很晚，這會不會就是原因？」**
> 這是這一題最誘人的陷阱。壓力大、伏案久坐確實可以造成胸壁疼痛，而且那是門診最常見的胸痛原因。
> **但肌肉骨骼疼痛是排除性診斷，不是預設診斷。** 一個 22 歲男性、突發、單側、合併呼吸困難的胸痛，我必須先排除氣胸和肺栓塞才能歸因於壓力。
> 而且「忙到很晚」這句話其實同時指向另一個方向——**長時間久坐是靜脈栓塞的風險因子**。同一句話可以支持良性診斷，也可以支持致命診斷，看你怎麼用。

**Q2「病人說休息一晚有好一點，這算好轉嗎？」**
> 不能這樣解讀。**小量氣胸的疼痛確實會在最初幾小時後減輕**，因為急性的肋膜刺激緩解了，**但氣體還在裡面，肺還是塌的**。
> 病人覺得「好一點」而延遲就醫，是氣胸很典型的模式。**痛減輕不等於氣體被吸收。**

**Q3「你會怎麼分辨是氣胸還是胸壁的問題？」**
> 最有價值的單一動作是**按壓胸壁**。如果按下去能誘發出完全一樣的疼痛，那強烈支持肌肉骨骼；**氣胸病人按壓胸壁通常不會痛**。
> 然後是**雙側對稱比較的叩診和聽診**——氣胸那側會是過度反響、呼吸音減弱、觸覺震顫減弱。
> 這三項加起來不到三分鐘，而且不需要任何儀器。

**Q4「你為什麼不做電腦斷層？他不是有呼吸困難嗎？」**
> 因為**一張立姿吸氣相的胸部 X 光加上床邊肺部超音波，已經足以回答我需要的問題**——有沒有氣胸、有多大，而那就是決定要觀察、抽氣、還是放胸管的全部依據。
> 而且他才 22 歲，輻射劑量是真的要考慮的事。**肺部超音波完全沒有輻射，而且對氣胸的敏感度比躺著拍的 X 光還高。**
> 如果是為了排除肺栓塞，我需要的是 CTPA 而不是一般胸部 CT，**而且我會先做臨床機率分層**。低到中機率的話驗 D-dimer，陰性就可以排除，不必做 CT。只有中高機率或 D-dimer 陽性才做。
> **對一個 22 歲的人直接開 CTPA，是不必要的輻射和顯影劑暴露。**

**Q5「什麼情況你不會等 X 光就要處理？」**
> **張力性氣胸。** 如果病人出現**氣管偏向健側、頸靜脈怒張、血壓下降、血氧急速掉**，那是臨床診斷，必須立刻減壓，**不能等影像**。
> 這也是我為什麼一開始就要摸氣管位置、看頸靜脈——這兩個動作不到十秒，但它們決定的是「有沒有時間照 X 光」。

**SBAR 骨幹**
- **S**：22 歲男性，昨晚突發右側尖銳胸痛併呼吸困難，深呼吸加劇，痛擴散至背部。
- **B**：過去健康良好，無住院、手術、外傷史，未服藥，無過敏。近日熬夜久坐、壓力大。**抽菸史與體型待確認**。
- **A**：（依理學填）**SpO2 ___、生命徵象 ___**、氣管位置 ___、頸靜脈 ___、右側呼吸音 ___、叩診 ___、觸覺震顫 ___、**胸壁按壓 ___**、雙下肢 ___。**最可能為右側原發性自發性氣胸**；因近日久坐伏案且症狀高度重疊，**肌肉骨骼疼痛為可能的競爭診斷，但屬排除性診斷**；因久坐為靜脈栓塞風險因子且年輕族群易被延誤，**須主動評估肺栓塞之臨床機率**。
- **R**：建議立即取得 SpO2 與完整生命徵象、12 導程 EKG、**立姿吸氣相胸部 X 光**，並考慮床邊肺部超音波。依 Wells 等臨床機率工具分層決定是否驗 D-dimer 或安排 CTPA。**若出現氣管偏移、頸靜脈怒張、血壓下降，立即針刺減壓，不待影像。** 依氣胸量決定觀察、抽氣或置放胸管，通知胸腔外科。衛教戒菸與復發風險。

# 9. 我不確定的地方

1. **肺部超音波對氣胸的敏感度是否確實高於仰臥位 CXR**——這個說法我信心中等偏高，方向應該正確，但**不要講具體數字**。
2. **氣胸大小的測量方法與處置切點（觀察／抽氣／胸管）**——**各國指引不同且近年有更新**，我刻意沒有寫任何百分比或公分數。**這是很容易被追問而且講錯很明顯的地方，請務必查證你們醫院或現行指引的標準。**
3. **Wells score 的項目與切點**——我提到用它分層，但**細項與分數請查證**，不要憑記憶講。
4. **D-dimer 的年齡校正切點**——有這個概念，但對 22 歲病人是否適用、切點怎麼算，我不確定。
5. **原發性自發氣胸的復發率**——我知道復發率不低，**但確切百分比沒有把握，不要講**。
6. **抽菸提高自發氣胸風險的倍數**——關聯確定存在，倍數不確定。
7. **針刺減壓的位置**（第二肋間鎖骨中線 vs 第四、五肋間腋前線）——**近年指引有調整過，請查證現行建議**。
8. **本題的 SP 是否會提供 SpO2**——考場若只給主訴不給生命徵象，第 5 節的「先量 SpO2」就變成你必須主動要求的動作，這一點在演練時要留意。
