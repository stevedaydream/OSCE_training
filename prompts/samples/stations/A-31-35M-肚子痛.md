# A-31｜35 歲男性，肚子痛

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #31）

35 歲男性，肚子痛。
已婚，國小老師，育有一子一女，未與父母同住。肚子痛 2 天了，都沒好，越來越痛。昨天早上吃完早飯覺得胃有點不舒服，悶悶的。一整天都不想吃東西。還有點噁心的感覺，但沒有吐。直到昨晚整個肚子開始覺得悶痛，覺得和平常吃壞東西的痛不一樣。今天早上請假在家休息，看會不會好點，可是一點也沒改善，走路更痛。連來醫院路上車子震動都會更痛。這幾天生活及飲食都和平常一樣，沒什麼特別的。平常偶而會因太忙飲食不正常，覺得胃悶及胃口不好，但都是一下子就好了。以前都沒有這樣肚子痛過。在貿易公司上班。有時工作較忙，偶爾要加班。工作很忙時便沒有運動，有空時則會跟家人去郊外走走。以前沒有特殊疾病，沒有吃任何藥物，沒有藥物及過敏史，不抽菸，不喝酒，無外傷病史。父親有高血壓但有吃藥控制。無家族遺傳疾病。

> 註：原題職業前後不一致（「國小老師」與「在貿易公司上班」並存），這是原文的瑕疵，考場遇到以 SP 當下說法為準。

# 1. 情境事實清單

- 35 歲男性，已婚，育有一子一女
- 腹痛 **2 天**，持續未緩解且**越來越痛**
- 昨早飯後**上腹（胃）悶悶不舒服**
- **一整天不想吃東西**（食慾不振）
- 有噁心感，**但沒有吐**
- 昨晚起**整個肚子悶痛**，病人自述「和平常吃壞東西的痛不一樣」
- 今早休息完全無改善
- **走路更痛；車子震動更痛**
- 這幾天飲食生活如常，無特殊改變
- 平常偶有胃悶、胃口不好，但短暫即好
- **以前沒有這樣痛過**
- 無特殊疾病、**未服任何藥物**、無藥物過敏、不菸不酒、無外傷史
- 父親高血壓；無家族遺傳疾病

**情境未給**：生命徵象、發燒、排便排氣、小便狀況、疼痛是否已定位到某一點。

# 2. 第一印象與危險分流

這一題的病人已經**自己把最重要的三句話說出來了**，只是他不知道那是什麼意思：

1. **「和平常吃壞東西的痛不一樣」**——病人有腸胃不適的經驗基準，而他明確表示這次不同。這種主觀比較的鑑別力比任何單一症狀都高。
2. **「走路更痛，車子震動也更痛」**——這就是間接反彈痛。**病人在替你做腹膜刺激徵的檢查**，而且已經是陽性。
3. **「食慾完全消失」出現在腹痛惡化之前**——anorexia 先行是外科腹症的經典順序。

再加上**痛從上腹（臍周）開始，兩天後變成整片**，這個從內臟痛擴散成瀰漫性的過程，指向的是**已經有一段時間、可能已經開始波及腹膜**的病程。

**與 #12 的關鍵差別**：#12 的痛明確「轉移並固定到右下腹」，是教科書式的闌尾炎；本題兩天了卻是「整個肚子悶痛」而**沒有明確定位**，這反而更令人擔心——它可能代表**炎症已經擴散開來，而不是還侷限在一個器官**。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **闌尾炎已穿孔併腹膜炎** | 病程 2 天 ＋ 瀰漫性痛 ＋ 間接反彈痛 | 全腹板硬？發燒？心搏過速？ |
| **消化性潰瘍穿孔** | 上腹痛起始 ＋ 平常就有胃悶 | 立姿 CXR、肝濁音界 |
| 急性胰臟炎 | 上腹痛起始、持續加重 | Lipase、有無前傾緩解 |
| 腸繫膜缺血 | 疼痛程度與理學不成比例時 | Lactate |

# 3. 焦點式病史

情境的敘述已經很完整，所以病史的重點是**補洞**，不是重複。

**L 部位（最該補的一格）**
- **現在最痛的是哪一點？請用一根手指指出來。**（兩天的病程，若已能定位到右下腹 → 闌尾；定位在上腹 → 潰瘍或胰臟）
- 一開始的「胃悶」是在肚臍上面還是肚臍周圍？

**Q 性質**——現在是悶痛、絞痛，還是持續的鈍痛加劇？昨晚到現在有沒有變成「一直痛不會停」？

**Q 程度**——0 到 10 給幾分？兩天來的變化曲線是穩定加重還是有起伏？

**O 時序**——已知。追問：**昨晚有沒有某一刻突然變得特別痛？**（穿孔的時間點常常是可以問出來的）

**P 誘發**——已知：走路、震動。追問：咳嗽、深呼吸會不會痛？

**E 緩解**——**什麼姿勢比較舒服？**（蜷曲、屈膝 → 腹膜刺激；前傾抱膝 → 胰臟炎）

**R 相關症狀（情境完全沒給，全部必問）**
- **有沒有發燒、畏寒？**
- **這兩天有沒有排氣、有沒有解大便？**（腹膜炎會造成腸麻痺）
- 有沒有拉肚子？（沒有腹瀉是重要的否定）
- 小便會不會痛、頻尿、血尿？
- 有沒有解黑便？（潰瘍出血）

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| **沒有腹瀉、家人同事沒有人一起不舒服** | **降低急性腸胃炎**——這是本題最該問到的否定 |
| 沒有服用任何止痛藥或胃藥 | 情境已明示「沒有吃任何藥物」，**降低 NSAID 相關潰瘍**，也代表症狀沒有被藥物掩蓋 |
| 沒有血尿、痛不會放射到鼠蹊 | 降低泌尿道結石 |
| 沒有外傷史 | 情境已明示，降低外傷性臟器損傷 |

**其他必問**
- **有沒有開過腹部的刀？闌尾切除過嗎？**
- 過去有沒有胃鏡檢查、有沒有幽門螺旋桿菌病史？（「平常偶而胃悶」這條線索的延伸）
- 有沒有出國旅遊史？

> **情境給的「沒有吃任何藥物」很有價值**：它同時排除了 NSAID 引起的潰瘍，也代表這兩天的疼痛**沒有被止痛藥掩蓋過**——病人描述的疼痛強度是真實的自然病程。

# 4. 焦點式身體評估

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| 一般外觀與姿勢 | 全身 | 「我先看您的姿勢和表情，目的是判斷疼痛的型態。請照您最舒服的姿勢躺。」 | **平躺屈膝、不敢動、翻身時明顯痛苦** | 結石：躁動換姿勢；胰臟炎：前傾抱膝 |
| 腹部視診 **含腹股溝** | 腹部、雙側腹股溝 | 「我要看您的肚子跟鼠蹊部，目的是看有沒有脹起來、有沒有疤痕或腫塊，也要確認鼠蹊部。我會注意隱私。」 | **腹部不隨呼吸起伏**（腹式呼吸消失是腹膜炎的早期視診徵象）、無疤痕、腹股溝無腫塊 | 腸阻塞：明顯膨脹 |
| 腸蠕動音聽診 | 四象限 | 「我用聽診器聽腸子聲音，目的是判斷腸道蠕動狀況。我會先聽再壓。」 | **減弱或消失**（腹膜炎致腸麻痺） | 腸阻塞：高亢金屬音 |
| 腹部叩診 **含肝濁音界** | 四象限、右上腹肋緣 | 「我要輕敲您的肚子，包括右上腹肝臟的位置，目的是判斷脹的是氣還是水，也確認肝臟的位置。」 | 廣泛叩痛 | **肝濁音界消失 → 游離氣體 → 穿孔** |
| 腹部觸診（由遠而近） | 四象限 | 「我要從離痛最遠的地方開始輕壓，目的是找出壓痛最厲害的位置。會痛請馬上說，我就停。」 | **瀰漫性壓痛，右下腹可能最明顯** | 上腹中央深壓痛 → 胰臟炎 |
| **反彈壓痛與肌肉防衛** | 全腹 | 「我要壓下去再快速放開，目的是確認腹膜有沒有發炎。這個會比較不舒服，我盡量輕，不行請說。」 | **陽性**，可能已有 **guarding／rigidity** | 全腹板硬 = 瀰漫性腹膜炎 |
| **咳嗽測試（替代反彈痛）** | — | 「請您用力咳一聲，然後告訴我哪裡最痛。目的是用比較不痛的方式確認腹膜有沒有發炎。」 | 咳嗽引發特定位置疼痛 | — |
| Rovsing's sign | 左下腹加壓 | 「我現在壓的是左邊，請告訴我右邊會不會痛，目的是確認右下腹的發炎。」 | 可陽性 | — |
| Psoas sign | 右髖伸展 | 「請左側躺，我把您的右大腿往後伸，目的是檢查發炎位置是否靠近後腹壁肌肉。」 | 可陽性 | — |
| 右側 CVA 叩擊痛 | 右後腰 | 「我輕敲您右後腰，目的是檢查腎臟和輸尿管。」 | 陰性 | 結石／腎盂腎炎：陽性 |

> **咳嗽測試值得優先用**：病人已經痛兩天且腹膜受刺激，用力壓下去再放開會非常痛。請他咳一聲能得到幾乎一樣的資訊，卻對病人友善得多。口試講出這個考量，會顯示你有在顧病人。

# 5. 需安排的檢查

## 階段一：床邊立即

- **生命徵象（含體溫）**——情境沒給，這是第一件要拿到的資料
- **尿液常規**——rule out 泌尿道來源。預期陰性
- **POCT 血糖**
- **靜脈血氣 ＋ lactate**——目的是評估是否已進入敗血症或腸缺血。病程兩天且瀰漫性腹痛，這一管值得抽

## 階段二：非侵入性、無輻射

- **立姿胸部 X 光** ← **本題優先度僅次於生命徵象**
  - 目的：rule out 橫膈下游離氣體（穿孔）
  - 預期發現：無游離氣體
  - **陽性即終止其他檢查，直接通知外科**
  - 病人若痛到站不起來，改左側臥位
- **腹部超音波**
  - 目的：看腹腔有無游離液、能否直接看到腫脹闌尾、順帶排除膽道與泌尿道
  - 陰性時下一步：看不到闌尾不等於沒有闌尾炎（見下）

## 階段三：有輻射／顯影劑

- **腹部電腦斷層（含顯影劑）**

> **這一題我會開 CT，而且理由和前面幾題不同。**
> 前面的原則是「能回答同一個問題時選便宜的」。但本題要回答的問題是：
> **「這兩天的瀰漫性腹痛，病灶在哪一個器官，而且有沒有已經穿孔或形成膿瘍。」**
> 超音波在已經腹脹、腸氣多、又有瀰漫性壓痛（病人不讓你壓）的腹部，回答不了這個問題。
>
> 所以本題的順序是：**先用立姿 CXR 花三分鐘排掉游離氣體**（因為若是陽性就不必再做任何影像，直接手術），
> **CXR 陰性再開 CT 找病灶**。超音波做不做都可以，做了是加分不是關鍵。

# 6. 檢驗

**即時（< 15 分）**：尿液常規、血糖、**血氣 ＋ lactate**

**常規（1 小時內）**

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| CBC/DC | **WBC ↑ 併明顯 left shift → 支持已進展的細菌性發炎**。病程兩天，WBC 若仍完全正常反而要重新想診斷 |
| CRP | **↑↑ 支持病程已兩天的發炎**。CRP 在發病 48 小時後最有參考價值，正合本題時序 |
| **Lipase** | **> 正常上限 3 倍 → 急性胰臟炎**，另立路線 |
| AST/ALT/ALP/T-Bil | 排除肝膽來源 |
| BUN/Cr/電解質 | 兩天未進食的脫水評估、顯影劑前必要值 |
| **Lactate** | ↑ → 腸缺血或敗血症，紅旗 |
| PT/INR、血型 | 術前準備 |

# 7. 前三個鑑別診斷

## ① 主診斷：急性闌尾炎（已進展，可能已局部穿孔）

**支持證據**
- **痛從上腹／臍周開始，兩天後變成整片**——內臟痛擴散的典型過程【已知】
- **食慾完全消失出現在腹痛惡化之前**——anorexia 先行是闌尾炎的經典順序【已知】
- **噁心但沒有嘔吐**，不符合腸胃炎【已知】
- **走路更痛、車震更痛** = 間接反彈痛陽性【已知】
- 病人主觀認定「和吃壞東西不一樣」【已知】
- **完全沒有腹瀉**【已知：情境未提及腹瀉，需問診確認】
- 休息兩天完全無改善、持續惡化【已知】

**不支持之處（誠實列）**
- **疼痛沒有明確定位到右下腹**，這是本題與教科書描述最大的落差。兩天了還是「整個肚子」，有兩種解釋：一是炎症已經擴散（壞消息），二是闌尾位置特殊（後位、骨盆位、盲腸後位）導致定位不典型。**這一點必須靠理學檢查與影像去分辨，不能用猜的。**
- 情境完全沒有提供體溫，發燒與否未知。
- 情境未提供排氣排便狀況。

**確診依據**
臨床（食慾不振先行 ＋ 疼痛遷移 ＋ 反彈痛）＋ WBC/CRP 上升 ＋ **CT 見闌尾腫脹併周圍脂肪炎症**（本題超音波多半答不了）。

---

## ② 次可能：消化性潰瘍穿孔

**為什麼它還留在名單上**
情境給了兩條伏筆，很容易被跳過：

1. **「昨天早上吃完早飯覺得胃有點不舒服，悶悶的」**——起始位置在上腹（胃），不是臍周。
2. **「平常偶而會因太忙飲食不正常，覺得胃悶及胃口不好」**——**病人已經有慢性上腹症狀的基礎**。這句話等於在說：他很可能有未診斷的消化性潰瘍。

一個有潛在潰瘍的人，症狀從上腹悶痛開始，兩天後變成瀰漫性腹痛併腹膜刺激徵——這條路線完全說得通。

**要出現什麼證據，它才會翻上第一位**
1. **立姿胸部 X 光見橫膈下游離氣體**（決定性）
2. **肝濁音界消失**
3. 問出**昨晚某一刻突然爆痛**的時間點
4. 腹部**板硬如木板**（rigidity 比 guarding 更嚴重）
5. 問出過去胃鏡異常或幽門螺旋桿菌病史

**翻上來的臨床意義**：從「安排闌尾切除」變成「**緊急剖腹修補**」，而且延誤的每一小時都在增加腹腔汙染與死亡率。

> **有利的線索**：情境明確寫「沒有吃任何藥物」，代表**不是 NSAID 引起的潰瘍**。這降低但不排除這個診斷——幽門螺旋桿菌與壓力性潰瘍不需要吃藥也會發生。

---

## ③ 不能排除：瀰漫性腹膜炎併敗血症（無論來源為何）

**這一格放的不是一個新器官，而是一個階段。** 漏掉它會死人。

**為什麼必須主動排除**
- 病程已**兩天**且持續惡化，是已經進展的時間尺度
- **疼痛從局部變成瀰漫**，正是腹膜炎擴散的表現
- 35 歲男性代償能力好，**生命徵象可能到很晚才崩**——他今天早上還請假在家休息、還自己坐車來醫院，這反而讓人低估嚴重度
- 最危險的情境是：把他當成單純闌尾炎排常規刀，等一個晚上

**排除它的最低限度**
> **一組完整生命徵象（含體溫）＋ 腹部理學（有無板硬、腸音消失）＋ CBC/DC ＋ 一個 lactate。**

不需要額外影像。只要出現發燒、心搏過速、低血壓、全腹板硬、腸音消失、lactate 上升其中數項 → **不是「安排檢查」，是立刻通知外科並啟動敗血症處置**。

# 8. 口試委員最可能追問的五題

**Q1「這個病人和一般腸胃炎怎麼分？」**
> 有四點對不上。第一，腸胃炎會拉肚子，這位病人沒有。第二，腸胃炎的病程通常一兩天會緩解，他兩天反而越來越痛。第三，他噁心但完全沒有吐。第四，也是最重要的一點——**他自己說「和平常吃壞東西的痛不一樣」**。病人有自己的經驗基準，這句話的鑑別力比任何單一症狀都高，我不會忽略它。

**Q2「病人說走路和車子震動會更痛，這代表什麼？」**
> 這是間接反彈痛，代表腹膜已經受到刺激。換句話說，**病人在來醫院的路上已經替我做完了腹膜刺激徵的檢查，而且是陽性的**。這一句話讓我在還沒碰到他的肚子之前，就知道這不是功能性的腹痛。

**Q3「痛了兩天還是整片，沒有跑到右下腹，你為什麼還是把闌尾炎放第一？」**
> 因為其他線索都指向它：食慾不振先出現、噁心不吐、疼痛從臍周開始。定位不典型有兩種解釋——一種是闌尾位置特殊，像後位或骨盆位闌尾，本來就不會痛在 McBurney point；另一種是炎症已經擴散開來。
> **這兩種解釋的處置急迫性差很多，所以我不會用猜的，我會用影像去分辨。** 這也是本題我會開電腦斷層的理由。

**Q4「你為什麼先照胸部 X 光，而不是先做超音波或電腦斷層？」**
> 因為立姿胸部 X 光只要三分鐘，而它回答的是一個會終止其他所有檢查的問題：有沒有橫膈下游離氣體。
> 如果有，就是消化道穿孔，不必再排電腦斷層，直接通知外科準備手術。如果沒有，我再往下做影像找病灶。
> 至於超音波，這位病人腹脹、腸氣多、又痛到不讓人壓，超音波在他身上答不出我要的問題，所以我不會把它當關鍵檢查。

**Q5「請向病人解釋。」**
> 先生，您這兩天的痛從胃的位置變成整個肚子，而且走路和車子震動都會更痛。這代表發炎可能已經刺激到肚子裡面包覆器官的那層膜，不是單純的腸胃不舒服。
> 我會先幫您照一張站著的胸部 X 光，看看有沒有破洞漏氣，這個很快；再抽血看發炎的程度，然後安排電腦斷層確認是哪一個器官在發炎。
> 從現在開始請不要吃東西喝水，因為如果需要開刀，空腹是必要的。
> 如果痛得更厲害、整個肚子硬起來、或者開始發燒發抖，請立刻按鈴告訴我們。

# 9. 我不確定的地方

1. **「兩天瀰漫性腹痛」的闌尾炎穿孔率**——我知道病程越長穿孔率越高，但 48 小時對應的實際比例沒有把握，不要在口試講數字。

3. **咳嗽測試（cough test）的正式名稱與敏感度**——我用的是臨床操作描述，正式名稱與數據我不確定。
4. **本題是否應該先做超音波再做 CT**——我把超音波降級為「加分不是關鍵」，這個取捨我信心中等。若你們醫院急診習慣一律先做 FAST 或腹部超音波，以實務為準。

6. **35 歲男性瀰漫性腹痛是否應把大腸憩室炎列入前三**——台灣的憩室好發於右側大腸，年輕人也可能發生，我把它放在第二層。這個順位請以你的臨床經驗校正。
