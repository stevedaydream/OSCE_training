# A-26｜39 歲男性，右上腹痛

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #26）

39 歲男性，右上腹痛。
三個月前開始右側腰部感到隱隱作痛，昨天夜間突然感到右腰及右上腹劇烈疼痛、冒冷汗及噁心想吐，因此前來求診。過去一般健康狀況良好，除了偶爾感冒發燒外，沒有任何疾病，未曾住過院。無心血管疾病、糖尿病、中風，也沒有骨盆腔、泌尿道或是脊椎外傷病史。沒有藥物或食物過敏，也沒有開刀、住院等疾病相關經驗。

# 1. 情境事實清單

- 39 歲男性
- **三個月前開始右側腰部隱隱作痛**（慢性前驅期）
- **昨夜突然**右腰及右上腹**劇烈疼痛**
- 伴**冒冷汗**及噁心想吐
- 過去健康良好，僅偶爾感冒發燒

- **無心血管疾病、糖尿病、中風**
- **無骨盆腔、泌尿道或脊椎外傷病史**
- 無藥物或食物過敏

**情境未給**：生命徵象、**體溫**、血尿與否、疼痛是否放射至鼠蹊或睪丸、排尿狀況、飲水習慣、職業、抽菸飲酒、體重變化。

# 2. 第一印象與危險分流

**這一題的時序是重點：三個月的隱隱作痛 ＋ 昨夜突然劇痛。**

這個「慢性前驅 ＋ 急性爆發」的兩段式病程，比單純的急性發作更值得注意。它通常代表：**有一個東西已經存在一段時間，昨晚它移動了、塞住了、或破了。**

對 39 歲男性、右腰 ＋ 右上腹、冒冷汗、噁心，最直接的解釋是**輸尿管結石往下移動造成急性阻塞**——三個月的隱隱作痛是結石在腎盂裡慢慢長大、間歇造成輕微阻塞；昨夜的劇痛是它掉進輸尿管。

**「冒冷汗」值得單獨拿出來看【推論】**：冒冷汗代表自主神經被強烈激發，這通常出現在幾類情況——極度疼痛（腎絞痛是出了名的痛）、內出血、心血管事件、或敗血症。前兩者在這一題都要想到。

情境刻意寫了一整串「沒有」：無心血管疾病、無糖尿病、無中風、無外傷史、無手術史。**這些不是廢話，它們在替你關掉幾條路**——沒有心血管風險因子，降低了主動脈事件與腎梗塞的機率；沒有外傷史，排除了創傷性血尿與腎損傷。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **阻塞性腎盂腎炎（膿腎）** | 結石 ＋ 感染，會迅速敗血 | **量體溫**、尿液常規看膿尿 |
| 急性膽囊炎／膽道急症 | 主訴含右上腹 | Murphy's sign、腹部超音波 |
| 腎梗塞 | 表現像結石但尿液可能只有微量血尿 | 情境已排除心血管疾病，機率降低 |
| 腹主動脈瘤 | 39 歲極少見，但冒冷汗＋腰痛的經典 can't-miss | 摸有無搏動性腫塊、量雙側血壓 |

# 3. 焦點式病史

## 把主訴問完整

**L 部位**——**現在最痛的是右腰還是右上腹？請指出來。**（這一題主訴同時寫了兩處，必須分清主次）
**痛會不會往下跑到右鼠蹊部或睪丸？**（→ 輸尿管中下段）
會不會往右肩胛骨跑？（→ 膽道）

**Q 性質**——**是一陣一陣的絞痛還是持續劇痛？**（絞痛且坐立難安 → 結石；持續加重不敢動 → 腹膜炎或膽囊炎）

**Q 程度**——最痛幾分？痛到什麼程度？有沒有痛到吐？

**O 時序**——昨夜幾點開始？是瞬間到最痛還是慢慢加重？
**三個月前那個隱隱作痛，是每天都有還是偶爾？有沒有慢慢變嚴重？**（本題最有價值的追問——它決定那三個月是結石在長大，還是別的東西）

**P 誘發**——昨晚發作前在做什麼？有沒有搬重物、劇烈運動、脫水？
**平常一天喝多少水？工作環境會不會流很多汗？**（結石的成因與衛教切入點）

**E 緩解**——**痛起來是想躺著不動，還是一直翻來翻去找姿勢？**（這一題的答案本身就有鑑別力）

**R 相關症狀（情境完全沒給，全部必問）**
- **有沒有發燒、畏寒發抖？**（**本題最必須問到的一題**）
- **小便有沒有變紅或有血絲？**（血尿是結石的關鍵支持證據）
- 解尿會不會痛、頻尿、急尿？
- 尿量有沒有變少？
- 有沒有嘔吐？吐幾次？
- 眼白有沒有變黃、小便有沒有變茶色？（膽道）
- 有沒有排氣排便？

**A 伴隨表現**——有沒有胸悶、喘、心悸？（冒冷汗要排除心因性）；有沒有咳嗽？（右下肺炎）

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| **沒有發燒、沒有畏寒發抖** | **降低阻塞性腎盂腎炎**——最重要的否定 |
| 沒有胸悶、喘、心悸 | 降低心因性冒冷汗 |
| 沒有吃油膩後加重、沒有往右肩放射 | 降低膽道疾病 |
| 沒有黃疸、茶色尿 | 降低膽管阻塞 |
| 情境已給：無心血管疾病、無糖尿病 | **降低腎梗塞與血管事件** |
| 情境已給：無外傷史 | 排除創傷性腎損傷 |

**其他必問（情境完全沒給）**
- **職業是什麼？工作環境熱不熱、流汗多不多？**（結石成因）
- **抽菸、喝酒嗎？**
- 家族有沒有人有結石？
- 這三個月體重有沒有變化？
- 平常有沒有服用任何保健食品或高劑量維他命 C、鈣片？（結石成因）

# 5. 需安排的檢查

## 階段一：床邊立即

- **尿液常規 ＋ 尿沉渣** ← **本題 CP 值最高的一項**
  - 目的：確認血尿（支持結石）、**確認有無膿尿（感染）**
  - 預期發現：**紅血球上升；白血球與亞硝酸鹽陰性**
  - **若膿尿 ＋ 發燒 → 立即改走阻塞性腎盂腎炎的緊急路線**
  - 註：**結石完全阻塞時，尿液可以沒有血**——尿液正常不能排除結石
- 尿液培養（若疑感染，抗生素前送）
- **生命徵象含體溫**
- 血糖

## 階段二：非侵入性、無輻射

- **腎臟及膀胱超音波** ← **本題的關鍵檢查**
  - 目的：**一次回答兩條線**——右側有無水腎（泌尿阻塞），以及膽囊有無結石與發炎（膽道）
  - 預期發現：**右側水腎；膽囊正常、Murphy 陰性**
  - 陰性時下一步：兩邊都乾淨 → 重新考慮腎梗塞、肌肉骨骼、或早期尚未造成水腎的結石
  - 升級條件：見腎臟腫塊或膽管擴張 → CT／MRCP
- **KUB（腹部平片）**：看不透射線的結石。低成本、低輻射

## 階段三：有輻射／顯影劑

- **非顯影低劑量電腦斷層（結石 protocol）**
- 顯影 CT（若懷疑腎梗塞或血管事件）

> **本題我不排顯影電腦斷層，因為腎臟超音波加上 KUB 已經足以回答「右側輸尿管有沒有結石造成阻塞」這個問題**，而且超音波同時把第二順位的膽道也一起看掉了。一次檢查回答兩條線，這是它的價值。
>
> 只有在下列情況才升級：
> 1. 超音波與 KUB 都看不到病灶，但病人持續劇痛 → **非顯影低劑量 CT**（找結石不需要顯影劑，輻射量也比常規 CT 低）
> 2. 出現發燒與膿尿 → 需影像確認阻塞程度以決定引流方式
> 3. 高度懷疑腎梗塞或血管事件 → 此時才需要**顯影** CT
>
> **要分清楚「要不要做 CT」和「要不要打顯影劑」是兩個問題。** 為了找結石而打顯影劑，反而會讓結石被顯影劑蓋住看不見。

# 7. 前三個鑑別診斷

## ① 主診斷：右側輸尿管結石併急性阻塞

**支持證據**
- **兩段式病程**：三個月隱隱作痛（結石在腎盂內）＋ 昨夜突然劇痛（結石掉入輸尿管造成急性阻塞）【已知】
- 疼痛位置在**右腰及右上腹**，符合上段輸尿管結石的轉位【已知】
- **冒冷汗**——腎絞痛的疼痛強度足以引發自主神經反應【已知】
- 噁心想吐（腎絞痛的常見伴隨）【已知】
- 39 歲男性正是結石的好發年齡【已知】
- 情境明示**無外傷、無心血管疾病、無糖尿病**，把幾條競爭路線關掉了【已知】
- 預期：右側 CVA 叩擊痛陽性、血尿、超音波見右側水腎【推論】

**不支持之處（誠實列）**
- 情境**完全沒有提到血尿**。血尿是結石最重要的支持證據之一，沒問到就是缺一角。（但要注意：**完全阻塞時可以沒有血尿**，所以沒血尿也不能推翻）
- 情境未提到疼痛放射至鼠蹊或睪丸。
- **主訴寫的是「右上腹痛」而不是「右腰痛」**，這讓膽道必須被認真考慮，不能因為結石比較合就跳過。
- 情境未提供體溫。

**確診依據**
超音波見右側水腎 ＋ KUB 或非顯影 CT 見輸尿管結石，併尿液常規血尿。

## ② 次可能：急性膽囊炎／症狀性膽結石

**為什麼它還留在名單上**
因為**主訴的第一句話寫的是「右上腹痛」**。這一題的疼痛同時橫跨右腰與右上腹，而右上腹是膽囊的地盤。
39 歲男性的膽結石不如中年女性常見，但完全可能發生，而且**三個月的隱隱作痛也可以是反覆的輕微膽絞痛**——這個病程對膽道一樣說得通。

**要出現什麼證據，它才會翻上第一位**
1. **Murphy's sign 陽性**
2. 問出**進食油膩後發作、疼痛往右肩胛骨放射**
3. **ALP、GGT、膽紅素上升**
4. 超音波見**膽囊壁增厚 > 3 mm、膽結石、sonographic Murphy 陽性**
5. 有發燒且尿液乾淨（發炎來自膽道而非泌尿道）

**翻上來的臨床意義**：從「止痛、大量輸液、依結石大小決定觀察或泌尿科介入」變成「**禁食、抗生素、外科會診評估膽囊切除**」。
**注意兩者對輸液的態度相反**——結石鼓勵水分，膽囊炎要禁食。這一題判斷錯了，連基本處置都會做反。

> **好消息是：這兩條線用同一台超音波就能同時看完。** 這正是本題把超音波放在第一線的理由。

## ③ 不能排除：阻塞性腎盂腎炎（膿腎）

**這一格放的是漏掉會死人的診斷。**

**為什麼必須主動排除**
- 一旦結石造成的阻塞合併細菌感染，膿液被封閉在腎盂裡出不來，**這是泌尿科急症**
- **抗生素無法解決它**——阻塞不解除，藥物到不了感染部位
- 病人可能在數小時內從「腰痛」走到**敗血性休克**
- 本題病人 39 歲、代償能力好，早期生命徵象可能還撐得住，容易被低估
- 情境**完全沒有給體溫**——這一格是空的，而它正是分辨的關鍵

**排除它的最低限度**
> **量一次體溫 ＋ 一份尿液常規（看有無膿尿與亞硝酸鹽）。**

就這兩項。若體溫正常且尿液無膿尿，這個診斷的機率就低到可以往下走。
若**發燒 ＋ 膿尿 ＋ 阻塞** → **不是安排門診追蹤，是立刻通知泌尿科評估緊急引流（輸尿管支架或經皮腎造廔）＋ 靜脈抗生素**，並在給抗生素前抽血液培養。

# 8. 口試委員最可能追問的五題

**Q1「三個月前就開始隱隱作痛，這件事對你的判斷有什麼意義？」**
> 它告訴我這不是昨天才發生的事。這種「慢性前驅加上急性爆發」的兩段式病程，通常代表**有一個東西已經存在一段時間，昨晚它移動了或塞住了**。
> 對這位病人，最合理的解釋是結石在腎盂裡長了三個月，昨夜掉進輸尿管造成急性阻塞。如果我只問昨晚的事，就會漏掉這個病程的形狀。

**Q2「主訴同時寫右腰和右上腹，你怎麼分？」**
> 我會請病人用手指出最痛的一點，而不是接受「兩邊都痛」。然後看三件事：**痛往哪裡放射**——往鼠蹊或睪丸是輸尿管，往右肩胛是膽道；**跟吃東西有沒有關係**——餐後發作偏膽道；**病人痛起來的姿勢**——躁動換姿勢是結石，不敢動是膽囊炎或腹膜炎。
> 而且很幸運，這兩條線用同一台腹部超音波就能同時看完，所以我不必先猜對才能查。

**Q3「這一題你最擔心什麼？」**
> **阻塞加上感染。** 結石本身很痛但通常不會死人，但如果阻塞的上游有細菌，膿液封在腎盂裡出不來，那是膿腎，是泌尿科急症。
> 這種情況光給抗生素沒有用，因為阻塞不解除，藥到不了感染的地方，病人可能幾小時內就敗血性休克。
> 而分辨它只需要兩件事：**量體溫、驗尿看有沒有膿尿。** 情境剛好完全沒給體溫，所以這是我第一個要補的資料。

**Q4「你為什麼不打顯影劑做電腦斷層？」**
> 這裡要分成兩個問題：要不要做 CT，和要不要打顯影劑。
> 如果超音波跟 X 光都找不到病灶但病人持續劇痛，我會做 CT，但用的是**非顯影的低劑量結石 protocol**，因為找結石不需要顯影劑，**而且打了顯影劑反而會把結石蓋住看不見**。
> 只有在懷疑腎梗塞或血管事件的時候，我才需要顯影。這位病人情境明確寫著沒有心血管疾病、沒有糖尿病、沒有中風，所以血管事件的機率已經被壓低了。

**Q5「請向病人解釋。」**
> 先生，您三個月前就開始的右腰隱隱作痛，加上昨晚突然的劇痛跟冒冷汗，最常見的原因是腎臟或輸尿管有結石，昨天晚上它移動了、把尿路塞住，所以才會這麼痛。
> 我等一下會請您驗一次尿，看看有沒有出血，也看有沒有感染。然後照一張腹部 X 光和做腎臟超音波，看看右邊腎臟有沒有積水、結石在哪裡。超音波順便也可以看您的膽囊，因為您右上腹也在痛，我要一併確認。這些檢查都不會痛，超音波也沒有輻射。
> 現在我會先幫您止痛。**有一件事請您務必記得：如果開始發燒、發冷發抖，一定要馬上告訴我們，不要忍。** 因為結石如果加上感染，處理的方式完全不一樣，要盡快處理。

**SBAR 骨幹**

- **B**：三個月前起右側腰部隱隱作痛。過去健康良好，無心血管疾病、糖尿病、中風，無外傷、手術、住院史，無過敏。

# 9. 我不確定的地方

1. **「完全阻塞時可以沒有血尿」的比例**——我知道這個現象存在，但發生率沒有把握，**不要講數字**。
2. **非顯影低劑量 CT（結石 protocol）在台灣急診的可及性與健保給付**——各院差異可能很大，請以你們醫院實務為準。
3. **顯影劑會蓋住結石**——這個說法我信心中等，方向應該是對的，但若被追問細節請保守。
4. **LDH 上升提示腎梗塞**——我把它放在第二層作為輔助，但這個指標的實際鑑別力我沒有把握，口試不要當成主要依據。
5. **39 歲男性膽結石的實際盛行率**——我判斷「不如中年女性常見但完全可能」，台灣的年齡分布請以你的臨床經驗校正。
6. **阻塞性腎盂腎炎的緊急引流時間窗**——我知道要「盡快」，具體小時數不確定。
7. **三個月的前驅期是否典型於結石**——我用「結石在腎盂內慢慢長大」解釋，這個說法合理但我信心中等。若那三個月其實指向別的東西（例如腎腫瘤或腎盂輸尿管交界處阻塞），第 7 節的排序要調整。**這一點值得你自己想一遍。**
