# A-33｜63 歲男性，體重減輕

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #33）

63 歲男性，體重減輕。
最近覺得比較累，還有點右上腹及上腹痛，痛在裡面，常常整天都悶痛悶痛的。兩個月體重減輕 8 公斤。可能是因為胃口不好。在住家附近診所看過一次，醫生懷疑是腸胃發炎，開了些胃藥，沒什麼效果。整天沒胃口，太太也不知道煮什麼才好。不過病患還是儘量吃，因此吃的量應該跟以前差不多。半年前在住家附近診所診斷罹患糖尿病，以口服藥物治療，血糖控制在空腹 180 左右。無 B、C 肝病史、無腸胃病史、無手術或創傷或住院史。對某種感冒藥過敏。

# 1. 情境事實清單

- 63 歲男性
- 最近覺得**比較累**
- **右上腹及上腹痛，「痛在裡面」，整天悶痛**
- **兩個月體重減輕 8 公斤**
- 胃口不好，但**病人自述吃的量跟以前差不多**
- 診所懷疑腸胃發炎，**開胃藥無效**
- **半年前新診斷糖尿病**，口服藥治療，**空腹血糖約 180**（控制不佳）
- **無 B、C 肝病史**
- **無腸胃病史、無手術／創傷／住院史**
- 對某種感冒藥過敏

**情境未給**：黃疸、茶色尿、灰白便、皮膚癢、排便習慣、血便、抽菸飲酒史、家族史、背痛、發燒。

# 2. 第一印象與危險分流

**這一題把三條線索放在一起，而它們指向同一個地方。**

### 線索一：兩個月掉 8 公斤，而且不是因為吃得少

情境特別寫了一句：**「不過病患還是儘量吃，因此吃的量應該跟以前差不多。」**
這句話極為關鍵——**它排除了「吃得少所以瘦」這個解釋。**
攝取量沒變卻在兩個月內掉了 8 公斤，代表這是**代謝性或消耗性的體重減輕**，不是熱量不足。這種瘦法背後通常是惡性腫瘤、內分泌疾病、或吸收不良。

### 線索二：半年前新診斷的糖尿病

**63 歲、半年前才第一次診斷糖尿病、而且血糖控制不佳（空腹 180）。**
成人晚發型糖尿病本身很常見，但**「新發糖尿病 ＋ 不明體重減輕 ＋ 上腹痛」這個組合，是胰臟癌的經典警訊**——胰臟腫瘤會破壞胰島功能，所以**新診斷的糖尿病可能是胰臟癌的早期表現，而不是巧合**。

這一條是本題埋得最深、也最容易被當成無關背景跳過的線索。

### 線索三：「痛在裡面」的悶痛

病人用「痛在裡面」形容，而不是指某一個點。這是**深部內臟痛**的描述，符合**後腹腔器官**（胰臟）而非表淺的腸道。
而且是**整天持續的悶痛**，不是陣發絞痛——這不像膽絞痛，比較像持續存在的佔位性病灶。

### 診所給胃藥無效

這也不是廢話。它排除了單純的胃炎或消化不良，而且代表**已經有一次醫療接觸失敗了**——這在延遲診斷的病人身上很常見。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **胰臟癌（尤其胰頭）** | 新發糖尿病 ＋ 體重減輕 ＋ 深部上腹痛 | 看有無黃疸、腹部超音波、CA 19-9 ＋ CT |
| **壺腹周圍／膽道腫瘤** | 表現重疊，但**可切除、預後較好** | 黃疸、膽紅素、膽管擴張 |
| 胃癌 | 63 歲、上腹痛、體重減輕、胃藥無效 | 上消化道內視鏡 |
| 肝癌 | 右上腹痛 ＋ 體重減輕 | 情境已排除 B、C 肝，機率降低但仍需超音波 |

# 3. 焦點式病史

## 把體重減輕問清楚（本題主戰場）

- **「兩個月前是幾公斤？現在是幾公斤？」**（要數字，不要「瘦很多」）
- **「這兩個月吃的量真的跟以前一樣嗎？請描述一下您昨天吃了什麼。」**（用具體回憶驗證病人的自我評估）
- 有沒有刻意減重、運動量改變？
- 有沒有發燒、夜間盜汗？（感染、淋巴瘤）

## 把腹痛問清楚

- **「痛的位置請用手比出範圍。」**（一片 vs 一點）
- **「這個痛會不會穿到背後去？」**
  → **這是本題最有價值的一問。上腹痛穿透到背部，是胰臟疾病的典型特徵**
- **「什麼姿勢比較舒服？身體往前彎會不會好一點？」**
  → **前傾緩解（leaning forward relief）也是胰臟的特徵**
- 跟吃東西有沒有關係？吃完會不會更痛？
- 晚上會不會痛醒？

## 黃疸相關（情境完全沒給，本題必問）

| 問題 | 意義 |
| :--- | :--- |
| **「眼白或皮膚有沒有變黃？」** | **胰頭癌壓迫總膽管的典型表現** |
| **「小便有沒有變成茶色？」** | 常比皮膚黃疸更早被察覺 |
| **「大便有沒有變成灰白色？」** | 膽汁完全排不出來 |
| **「皮膚會不會癢？」** | 膽鹽沉積，**常在黃疸出現之前就有** |

> **這四題是本題的分水嶺。** 若出現「**無痛性黃疸**」，胰頭癌或壺腹周圍腫瘤的順位立刻確立。

## 消化道症狀

- **排便習慣有沒有改變？**
- **大便會不會浮起來、油油的、很難沖掉？**（脂肪便 steatorrhea → 胰臟外分泌功能不足）
- 有沒有血便、黑便？
- 有沒有噁心嘔吐？吐什麼？
- 有沒有吞嚥困難、早飽感？（胃癌）

## 糖尿病那條線（本題特有）

- **「半年前是怎麼發現糖尿病的？是不舒服去看，還是健檢驗到的？」**
- **「以前有沒有驗過血糖？之前都正常嗎？」**（確認真的是新發）
- 家裡有沒有人有糖尿病？（若無家族史，新發糖尿病更值得懷疑次發原因）
- 血糖藥吃了半年，血糖有沒有越來越難控制？

## 風險因子

- **抽菸？喝酒？**（情境完全沒提，**必問**——抽菸是胰臟癌明確的風險因子）
- 家族有沒有人得過胰臟癌、大腸癌、乳癌、卵巢癌？
- 有沒有慢性胰臟炎病史？

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| 情境已給：**無 B、C 肝病史** | **降低肝細胞癌**（但仍要問有無驗過） |
| 情境已給：無腸胃病史、無手術史 | 降低沾黏、術後併發症 |
| 沒有心悸、怕熱、手抖 | 降低甲狀腺亢進（也會造成吃得多卻瘦） |
| 沒有咳嗽、發燒、盜汗 | 降低結核與慢性感染 |
| 沒有多尿多渴惡化 | 降低單純糖尿病失控造成的體重減輕 |

> ⚠️ **一個必須主動排除的競爭解釋**：**血糖控制不佳（空腹 180）本身就會造成體重減輕**（糖分從尿中流失）。
> 這是本題最合理的「良性解釋」，而且很容易讓人停在這裡。
> **但兩個月掉 8 公斤，用單純血糖控制不佳來解釋是偏多的**，而且它不能解釋上腹痛。
> 口試要主動說出「我有想過這個解釋，但它解釋不了全部」，這比完全沒想過更好。

# 4. 焦點式身體評估

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| **體重與營養狀態** | 全身、顳肌、鎖骨上窩 | 「我先量體重，也看您整體有沒有變瘦，目的是確認這兩個月的變化，這對後面的評估很重要。」 | **明顯消瘦、顳肌凹陷** | — |
| **鞏膜、皮膚、抓痕** | 雙眼鞏膜、全身皮膚 | 「我要看您的眼白和皮膚顏色，也看看身上有沒有抓痕。目的是檢查有沒有黃疸，因為膽汁排不出來會讓皮膚癢。」 | **本題最關鍵的一項**。可能有黃染或抓痕 | **黃疸 → 膽道阻塞，胰頭癌或壺腹癌順位確立** |
| **左鎖骨上淋巴結** | 左側鎖骨上窩 | 「我要摸您左邊鎖骨上方，目的是檢查淋巴結有沒有腫大，因為腹部的腫瘤會轉移到這個位置。」 | 陰性 | **摸到硬結 → 遠端轉移** |
| 腹部視診 | 腹部 | 「我要看您的肚子，目的是看有沒有脹起來、有沒有靜脈浮起、有沒有疤痕。我會注意隱私。」 | **平坦或消瘦，無手術疤痕**（呼應無手術史） | 腹壁靜脈曲張 → 門脈高壓 |
| 腸蠕動音聽診 | 四象限 | 「我用聽診器聽腸子的聲音，目的是判斷腸道蠕動。我會先聽再壓。」 | 正常 | — |
| 腹部叩診含移動性濁音 | 四象限、翻身 | 「我要輕敲您的肚子，等一下請側個身我再敲一次，目的是檢查肚子裡有沒有積水。」 | 陰性 | **移動性濁音 → 腹水 → 腹膜轉移，分期大幅上升** |
| **肝臟觸診與叩診** | 右上腹肋緣 | 「我要摸您右上腹肝臟的位置，請配合深吸氣。目的是確認肝臟有沒有腫大或摸到硬塊。」 | 可能正常 | **肝腫大、表面不平 → 肝轉移** |
| **膽囊觸診（Courvoisier's sign）** | 右上腹肋緣下 | 「我要特別摸一下您右上腹膽囊的位置，目的是確認膽囊有沒有脹大。」 | **本題的關鍵徵象** | **無痛性可觸及的脹大膽囊 ＋ 黃疸 → 高度懷疑遠端膽道被腫瘤阻塞（而非結石）** |
| **上腹深部觸診** | 上腹中央、劍突下 | 「我要在您上腹中間稍微壓深一點，目的是確認胰臟的位置有沒有壓痛或摸到硬塊。會不舒服請告訴我。」 | **上腹中央深部壓痛** | 摸到搏動性腫塊 → 主動脈瘤 |
| 脾臟觸診 | 左上腹 | 「我摸您左上腹脾臟的位置，請配合深呼吸，目的是檢查脾臟有沒有腫大。」 | 摸不到 | 脾腫大 → 脾靜脈受壓或門脈高壓 |
| 肛門指診 | 直腸 | 「我需要做肛門指診，目的是檢查直腸有沒有腫瘤、有沒有出血，也看大便的顏色。會不舒服但很快，我會拉簾並請同仁陪同。您同意嗎？」 | 陰性 | **灰白色糞便 → 膽道完全阻塞** |
| 下肢水腫與深部靜脈 | 雙下肢 | 「我壓一下您的小腿，目的是看有沒有水腫，也確認有沒有血栓。」 | 陰性 | **不明原因深部靜脈栓塞 → 惡性腫瘤的伴瘤現象** |

> **本題的三個關鍵動作：看鞏膜與抓痕、摸左鎖骨上淋巴結、摸膽囊（Courvoisier's sign）。**
> 這三項都不用儀器，卻分別回答「有沒有膽道阻塞」「有沒有遠端轉移」「阻塞是腫瘤還是結石」。

# 5. 需安排的檢查

## 階段一：門診／床邊立即

- 體重、BMI（**與病人自述比對**）
- **血糖（空腹與 HbA1c）**——重新評估糖尿病的實際控制
- 生命徵象
- **糞便潛血**（低成本，順便排除大腸來源）

## 階段二：非侵入性、無輻射

- **腹部超音波** ← **第一線，但要知道它的極限**
  - 目的：看**肝臟有無腫瘤或轉移、膽囊、膽管有無擴張、胰臟、腹水**
  - 預期發現：**若為胰頭癌，可能見肝內外膽管擴張與膽囊脹大**（阻塞的間接證據）
  - **陰性時下一步（本題最重要的一句）：超音波看不清楚胰臟是常態，因為胰臟位在後腹腔、常被胃與腸的氣體遮蔽。超音波正常，絕對不能排除胰臟癌。**
  - 升級條件：見膽管擴張、胰管擴張、肝內佔位、或**臨床高度懷疑但超音波正常** → 一律升級 CT

## 階段三：有輻射／顯影劑

- **腹部電腦斷層（胰臟 protocol，含動靜脈雙期顯影）** ← **本題的關鍵檢查**
  - 目的：**診斷 ＋ 分期一次完成**——腫瘤位置大小、有無侵犯血管（決定能不能開刀）、淋巴結、肝轉移
  - 為什麼要「胰臟 protocol」：一般腹部 CT 的顯影時相不一定看得清楚胰臟腫瘤與血管的關係
- **上消化道內視鏡**：排除胃癌（第二順位需要它）
- **MRCP／內視鏡超音波（EUS）**：進一步評估膽胰管與取得組織
- **ERCP**：主要是**治療性**（放置支架解除黃疸），不是第一線診斷工具

> **這一題我不會停在超音波，這是本題和前面幾題最大的差別，必須講清楚。**
>
> 前面的原則是「能回答同一個問題時，選成本低的」。
> **但在這一題，超音波回答不了關鍵問題——因為胰臟正好是超音波的盲區。**
> 胰臟位在後腹腔，前面隔著胃和橫結腸的氣體，超音波常常「看不到」而不是「看正常」。
>
> 所以本題的邏輯是：
> **超音波先做，因為它能便宜地回答「膽管有沒有擴張、肝有沒有轉移、有沒有腹水」這三件事**——這些都是重要的間接證據。
> **但無論超音波結果如何，只要臨床懷疑成立（新發糖尿病 ＋ 體重減輕 ＋ 深部上腹痛），CT 都必須做。**
>
> **本題最危險的錯誤，是做了一次「胰臟顯示不清」的超音波，就當成沒事。**

# 6. 檢驗

**常規**

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| CBC/DC | Hb ↓ → 慢性失血或營養不良 |
| **T-Bil / D-Bil** | **↑（尤其直接型）→ 膽道阻塞，往胰頭癌或壺腹癌移動** |
| **ALP / GGT** | **↑ 而 AST/ALT 相對正常 → 阻塞型（膽道）模式，本題的關鍵組合** |
| AST / ALT | 單獨 ↑ → 肝細胞型 |
| **Albumin** | ↓ → 營養不良，影響治療耐受度 |
| **Lipase／Amylase** | 可能正常或輕度上升。**正常不能排除胰臟癌** |
| **HbA1c ＋ 空腹血糖** | 重新評估糖尿病；**若半年內急速惡化，更支持胰臟病變** |
| BUN/Cr/電解質 | 顯影劑前必要值 |
| PT/INR | **膽道阻塞 → 脂溶性維生素 K 吸收不良 → PT 延長**，術前必查 |
| 鈣、ALP | 骨轉移（特異度低） |
| **HBsAg / Anti-HCV** | 情境說「無 B、C 肝病史」，但**沒說驗過**。值得驗一次 |

**腫瘤標記**

| 項目 | 說明 |
| :--- | :--- |
| **CA 19-9** | 胰膽系統相關。⚠️ **不能用於診斷也不能用於排除**——膽道阻塞、膽管炎、良性疾病都會上升；而且**約 5–10% 的人先天不表現（Lewis antigen 陰性），永遠是正常的**【數字需查證】。角色是**治療後追蹤基準** |
| CEA | 輔助，同樣不能診斷 |
| AFP | 若要排除肝癌 |

> **口試提到腫瘤標記時，一定要主動說出限制。** 只報數字不講限制，會被視為不懂它的意義。

# 7. 前三個鑑別診斷

## ① 主診斷：胰臟癌（尤其胰頭）

**支持證據（本題的支持證據很強）**
- **兩個月體重減輕 8 公斤，且攝取量未減少**——消耗性體重減輕【已知】
- **半年前新診斷糖尿病，血糖控制不佳**——**新發糖尿病可能是胰臟腫瘤破壞胰島功能的早期表現，而非巧合**【已知】
- **「痛在裡面」的深部上腹悶痛，持續整天**——符合後腹腔器官的內臟痛【已知】
- **胃藥完全無效**——排除單純胃炎【已知】
- 疲倦【已知】
- 63 歲，好發年齡【已知】
- 預期：上腹深部壓痛；若為胰頭癌，可能有黃疸、膽管擴張、Courvoisier's sign【推論】

**不支持之處（誠實列）**
- 情境**完全沒有提到黃疸、茶色尿、灰白便、皮膚癢**。若為胰頭癌，這些是很常見的表現。缺席有兩種解釋：**腫瘤在胰體或胰尾（不壓迫膽管）**，或**還沒到那個程度**。這一點必須問診確認。
- 情境未提到疼痛穿透到背部，也沒提前傾緩解——這兩項是胰臟痛的特徵，需問診補上。
- 情境未提供抽菸史（胰臟癌明確的風險因子）。
- **競爭解釋存在**：空腹血糖 180 控制不佳本身就會造成體重減輕。但這解釋不了上腹痛，而且兩個月 8 公斤偏多。

**確診依據**
> **胰臟 protocol 電腦斷層見胰臟腫塊 ＋ 組織病理（EUS 導引切片或手術檢體）。**
> 影像高度懷疑即可決定手術與否，但**確定診斷仍需病理**。

## ② 次可能：胃癌

**為什麼它還留在名單上**
63 歲男性、上腹痛、體重減輕、食慾不振、**胃藥無效**——這一組症狀對胃癌一樣完全說得通，而且比胰臟癌更常見。
台灣胃癌發生率在亞洲屬中高，幽門螺旋桿菌盛行率也高。**而且情境完全沒有做過胃鏡。**

**要出現什麼證據，它才會翻上第一位**
1. **上消化道內視鏡見胃部病灶併切片病理陽性**（決定性）
2. 問出**早飽感、餐後上腹脹、噁心嘔吐**
3. **解黑便或糞便潛血陽性 ＋ 小球性貧血**
4. 摸到上腹腫塊
5. 幽門螺旋桿菌陽性、有胃癌家族史

**翻上來的臨床意義**：從「胰臟腫瘤手術評估（Whipple 手術，複雜且死亡率較高）」變成「**胃癌分期與胃切除**」。兩者的手術方式、預後、化療處方完全不同。

> **實務上這兩者常常一起查**：安排腹部 CT 的同時安排胃鏡，不必先選一個。這一點在口試可以主動說明——**兩個檢查回答不同的問題，不是二選一。**

## ③ 不能排除：壺腹周圍腫瘤／遠端膽管癌

**這一格放的不是「更致命」的診斷，而是「漏掉會失去治癒機會」的診斷。**

**為什麼必須主動區分**
- **壺腹癌（ampullary carcinoma）與遠端膽管癌的臨床表現和胰頭癌幾乎一模一樣**——同樣是黃疸、體重減輕、上腹痛，同樣在同一個解剖位置
- **但它們的預後明顯較好**，因為壺腹的位置會**很早就造成黃疸**，所以常在腫瘤還小的時候就被發現，**可切除率遠高於胰臟癌**
- **最危險的錯誤是**：影像看到「胰頭附近有腫瘤 ＋ 膽管擴張」，就直接當成胰臟癌、認為預後不佳、態度轉為消極。**而它其實可能是一個可以開刀治癒的壺腹癌。**
- 這一格的意義不是「怕死人」，是**怕在可以治癒的病人身上放棄得太早**

**排除它的最低限度**
> **在安排影像時，明確要求評估「壺腹與遠端膽管」，並在膽管擴張的病人安排 EUS 或 ERCP 取得組織診斷。**

換句話說，這一格不是靠額外的檢查排除，而是靠**不要在影像報告出來前就下結論**。
**在拿到病理之前，「胰頭附近的腫瘤」就是「胰頭附近的腫瘤」，不是「胰臟癌」。**

# 8. 口試委員最可能追問的五題

**Q1「這個病人半年前才診斷糖尿病，你覺得跟現在的症狀有關係嗎？」**
> 我認為很可能有關，而且這是這一題最重要的線索。
> **新發糖尿病加上不明原因體重減輕加上上腹痛，是胰臟癌的經典警訊組合**——因為胰臟腫瘤會破壞胰島功能，所以糖尿病可能不是巧合，而是腫瘤的早期表現。
> 一個 63 歲、半年前才第一次被診斷糖尿病、血糖又控制不好的人，我不會把糖尿病當成無關的背景資料。

**Q2「血糖控制不好本來就會瘦，你怎麼知道不是這個原因？」**
> 這是很合理的競爭解釋，我確實有想過。但有兩點對不上。
> 第一，**兩個月掉 8 公斤，用單純血糖控制不佳來解釋偏多**。第二，**它解釋不了上腹痛**，而且病人吃胃藥完全沒效。
> 所以我不會停在這個解釋。當然我還是會驗 HbA1c 重新評估血糖，但我不會用它來關掉其他可能。

**Q3「情境說他吃得跟以前差不多，這一句重要嗎？」**
> 非常重要。**它排除了「吃得少所以瘦」這個最常見的解釋。**
> 攝取量沒變卻在兩個月掉 8 公斤，代表這是消耗性或代謝性的體重減輕，不是熱量不足。這種瘦法背後通常是惡性腫瘤、甲狀腺亢進、或吸收不良，而不是單純食慾差。
> 不過我還是會請他具體回憶昨天吃了什麼，因為病人對自己食量的評估常常不準。

**Q4「超音波如果報告寫胰臟顯示不清，你會怎麼辦？」**
> 我會繼續往下做 CT，**而且這一題我覺得這是最容易出錯的地方**。
> 胰臟位在後腹腔，前面隔著胃和大腸的氣體，超音波常常是「看不到」而不是「看正常」。**「顯示不清」不等於「沒問題」。**
> 所以只要臨床懷疑成立——新發糖尿病、體重減輕、深部上腹痛——不管超音波結果如何，我都會安排胰臟 protocol 的電腦斷層。

**Q5「請向病人解釋。」**
> 先生，您這兩個月瘦了 8 公斤，而且您說吃的量沒有變少，這一點讓我覺得需要認真查清楚，不能只當成胃不舒服。加上您上腹的悶痛吃胃藥沒效，還有半年前才發現的糖尿病，這幾件事我想一起看。
> 我會安排腹部超音波和一個腹部電腦斷層，另外也安排一次胃鏡。這幾個檢查看的位置不一樣，所以是一起做，不是選一個。同時會抽血看肝膽功能、營養狀況和血糖。
> **我要老實跟您說，這些檢查是為了確認有沒有比較嚴重的原因，包括腫瘤的可能。我現在還不能下結論，但我不希望拖。**
> 這段時間如果眼白或皮膚變黃、小便變成茶色、大便變灰白色、或者皮膚變得很癢，請立刻回來，不要等回診日。

**SBAR 骨幹**
- **S**：63 歲男性，兩個月體重減輕 8 公斤，併右上腹及上腹深部悶痛。
- **B**：**攝取量未明顯減少**。診所給胃藥無效。**半年前新診斷糖尿病，空腹血糖約 180 控制不佳**。無 B、C 肝病史，無腸胃病史，無手術史。抽菸飲酒史待補。
- **A**：（依理學填）體重 ___、**鞏膜與皮膚 ___、抓痕 ___**、左鎖骨上淋巴結 ___、肝臟 ___、**膽囊（Courvoisier）___**、上腹深部壓痛 ___、移動性濁音 ___。**最可能為胰臟癌，尤其胰頭**；因症狀高度重疊且台灣發生率高，**胃癌不能排除，須安排胃鏡**；因壺腹周圍與遠端膽管腫瘤表現相同但**可切除率與預後明顯較好**，**在病理確定之前不可逕行認定為胰臟癌**。
- **R**：建議腹部超音波 ＋ **胰臟 protocol 腹部 CT** ＋ 上消化道內視鏡；抽 CBC/DC、T-Bil/D-Bil、ALP/GGT、AST/ALT、Albumin、Lipase、HbA1c、BUN/Cr、電解質、PT/INR、CA 19-9（註明僅作基準）、HBsAg/Anti-HCV。衛教黃疸相關紅旗症狀與回診時機。轉介一般外科／肝膽腸胃專科。

# 9. 我不確定的地方

1. **「新發糖尿病是胰臟癌早期表現」的證據強度與時間窗**——這個關聯我有把握是存在的，但**多久之內、風險上升幾倍，數字不要在口試講**。
2. **CA 19-9 因 Lewis antigen 陰性而永遠正常的比例**——我寫約 5–10%，**這個數字信心不足，請查證或乾脆不要講數字**，只說「有一部分人天生不表現」。
3. **Courvoisier's sign 的臨床可靠度**——這是古典徵象，現代影像時代的實際價值有多少，我信心中等。方向（無痛性脹大膽囊偏腫瘤而非結石）應該是對的。
4. **胰臟 protocol CT 在台灣各院的可及性與命名**——各院叫法可能不同，請以你們醫院實務為準。
5. **台灣胃癌發生率的實際排名**——我寫「亞洲屬中高」，具體數字請查證。
6. **壺腹癌的可切除率與五年存活率**——我知道明顯優於胰臟癌，**但確切數字沒有把握，不要講**。
7. **胰臟癌的抽菸相對風險**——關聯確定存在，倍數不確定。
8. **這一題若在 15 分鐘內，是否來得及做完我列的全部身評**——我列了 12 項偏多。**必做的是：體重與營養、鞏膜與抓痕、左鎖骨上淋巴結、上腹深部觸診、肝臟與膽囊**，其餘可口頭補充。
