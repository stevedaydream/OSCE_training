# A-14｜65 歲男性，右腳痛

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #14）

65 歲男性，右腳痛。
右腳大拇趾變黑三天，無外傷病史。最近一個月足部夜間疼痛導致醒來（一週兩三次），腳垂在床邊可緩解。最近一年走路約十分鐘會引起雙腳疼痛，走路的時候會一跛一跛的，感覺雙腳冰冷，麻麻的，持續走路會很痛，尤其是小腿肚部位，休息約十分鐘才緩解。20 歲起一天一包菸，現在抽到一包半；朋友聚會時偶而會小酌一番。

# 1. 情境事實清單

- 65 歲男性
- **右腳大拇趾變黑三天**
- **無外傷病史**
- 最近**一個月**：足部**夜間疼痛導致醒來**（一週 2–3 次），**腳垂在床邊可緩解**
- 最近**一年**：走路約十分鐘引起**雙腳**疼痛，**走路一跛一跛**
- 雙腳**冰冷、麻麻的**
- 持續走路會很痛，**尤其小腿肚**
- **休息約十分鐘才緩解**
- **20 歲起抽菸一天一包，現在一包半**（約 45 年，超過 50 pack-year）
- 朋友聚會偶而小酌

**情境未給**：生命徵象、有無糖尿病與高血壓、有無高血脂、心臟病史、家族史、腳趾有無傷口滲液或惡臭、有無發燒、用藥。

# 2. 第一印象與危險分流

**這一題是教科書級的病程，而且它把三個階段完整地依時間寫出來了。** 讀懂這個順序，診斷就出來了：

| 時間 | 症狀 | 臨床階段 |
| :--- | :--- | :--- |
| **最近一年** | 走十分鐘小腿痛、休息十分鐘緩解、一跛一跛 | **間歇性跛行（claudication）**——運動時供血不足 |
| **最近一個月** | **夜間痛醒，腳垂下床可緩解** | **靜止痛（rest pain）**——連休息時的基礎供血都不夠 |
| **最近三天** | **大拇趾變黑** | **組織缺損／壞疽**——組織已經開始死亡 |

**這不是三個症狀，這是同一個疾病在一年之內走完的三個階段。**
從跛行走到靜止痛，代表缺血從「運動時不足」變成「休息時也不足」；再走到趾端變黑，代表**已經進入慢性肢體威脅性缺血（CLTI）**——這是**會失去這隻腳**的階段。

**「腳垂在床邊可緩解」這一句是本題最漂亮的線索**【推論】：平躺時腳與心臟同高，失去重力幫助；把腳垂下床，重力增加末梢灌流，痛就緩解。**這個動作本身就是嚴重動脈缺血的診斷性徵象**——靜脈或神經問題不會有這個特徵。

**「無外傷病史」也不是廢話**：一個變黑的腳趾，如果沒有外傷，就必須用血管、感染、或栓塞來解釋。

**抽菸 45 年、一天一包半**——這是本題唯一寫出來的風險因子，而抽菸是週邊動脈疾病最強的風險因子。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **慢性肢體威脅性缺血（CLTI）** | 跛行 → 靜止痛 → 組織壞死的完整病程 | 摸脈搏、**測 ABI** |
| **急性肢體缺血（acute on chronic）** | 三天前才變黑，可能是急性事件疊加 | **6P** 評估，尤其麻木與無力 |
| **腹主動脈瘤併遠端栓塞** | 65 歲重度吸菸男性，AAA 高風險；栓子可造成趾端壞死 | **摸腹部有無搏動性腫塊** |
| 糖尿病足併感染 | 情境未提糖尿病，但必問 | 驗血糖、看有無滲液惡臭紅腫 |

> ⚠️ **本題最重要的一個時間判斷**：這位病人**同時具有慢性（一年）和急性（三天）的成分**。
> 慢性缺血可以排時間評估，**但如果三天前是一個急性事件（血栓或栓塞）疊加上去，那是有時間窗的**。
> 這一點決定他是「門診排血管攝影」還是「今天就要通知血管外科」。

# 3. 焦點式病史

## 把腳趾變黑問清楚

- **「是三天內突然變黑的，還是慢慢變的？」**（**突然 → 急性栓塞事件**；慢慢 → 慢性缺血進展）
- **變黑之前有沒有先變白、變紫？**
- **有沒有傷口、破皮、滲液？有沒有臭味？**（→ 濕性壞疽併感染，處置急迫性完全不同）
- 有沒有紅腫熱？（感染）
- **這三天痛的程度有沒有變化？是變更痛還是反而不痛了？**
  → ⚠️ **「反而不痛了」是壞消息不是好消息**——可能代表神經已經缺血壞死

## 把跛行問清楚（分辨血管性與神經性）

**這是本題最需要功夫的一段。** 腰椎狹窄造成的「神經性跛行」與動脈缺血的「血管性跛行」都會走一走就腳痛，但處置完全不同：

| 問題 | 血管性（動脈） | 神經性（腰椎） |
| :--- | :--- | :--- |
| **走多遠開始痛？每次都差不多嗎？** | **距離固定、可重複** | 距離不固定 |
| **停下來就好，還是要坐下來才好？** | **站著休息就會好** | **必須坐下或彎腰才會好** |
| **騎腳踏車會不會痛？** | **會（一樣需要血流）** | **不太會（身體前傾，椎管變寬）** |
| 上坡和下坡哪個比較痛？ | 上坡（需氧量高） | 下坡（腰椎後仰） |
| 痛的位置 | **小腿肚為主**（已知） | 常伴腰痛、臀部放射 |

情境已給的「走十分鐘、休息十分鐘緩解、痛在小腿肚」全部指向**血管性**，但**「停下來就好還是要坐下來」這一題必須親口問**。

## 心血管風險因子（本題必問，情境只給了抽菸）

- **有沒有糖尿病？** ← **最重要的一問**。糖尿病足與缺血的處置不同，而且會改變傷口癒合的預期
- **有沒有高血壓？高血脂？**
- **有沒有心臟病、心肌梗塞、心律不整（尤其心房顫動）？** ← 心房顫動 → 栓塞來源
- 有沒有中風或暫時性腦缺血？
- **家族有沒有人心肌梗塞、中風、或動脈瘤？**
- 目前有沒有服用任何藥物？（抗血小板、降血脂）
- **抽菸：已知 45 年、現在一包半。有沒有想過戒菸？**（衛教切入點，而且戒菸是本病最重要的治療之一）

## 其他系統（動脈疾病是全身性的）

- **有沒有胸悶、胸痛、走路會喘？**（冠狀動脈也可能有病灶——**這才是他真正會死於什麼的原因**）
- 有沒有暫時性單眼失明、講話不清、手腳無力？（頸動脈）
- **有沒有勃起功能障礙？**（主動脈髂動脈阻塞的表現之一，Leriche syndrome。要問得有分寸）
- 有沒有腹部或背部的搏動感、悶痛？（腹主動脈瘤）

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| 情境已給：**無外傷病史** | 排除外傷性壞死 |
| 沒有紅腫熱痛、滲液、惡臭、發燒 | 降低感染性濕性壞疽 |
| 沒有腰痛、沒有坐下才緩解、騎車也會痛 | **降低神經性跛行（腰椎狹窄）** |
| 沒有心房顫動、沒有近期心肌梗塞 | 降低心因性栓塞 |
| 沒有雷諾現象、沒有結締組織疾病症狀 | 降低血管炎 |

# 4. 焦點式身體評估

**這一題的身評是可以「摸出診斷」的少數題目之一，而且幾乎不需要任何儀器。**

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| **雙足視診（一定要脫襪子、看趾縫）** | 雙足、趾間、足底、腳跟 | 「請您把兩腳的鞋襪都脫掉，我要看您兩隻腳，包括腳趾中間和腳底。目的是檢查皮膚顏色、有沒有傷口或壞死。兩腳都要看是為了比較。」 | **右大拇趾變黑（壞疽）**、皮膚薄而光亮、**毛髮稀疏、趾甲增厚**、可能蒼白 | **趾縫或足底有潰瘍 → 糖尿病足**（最常被漏掉的位置） |
| **皮膚溫度（雙側比較）** | 雙足、雙小腿 | 「我用手背摸您兩隻腳和小腿，目的是比較兩邊的溫度，因為血流不好的那一邊會比較冰。」 | **雙足冰冷，右側更明顯**，且有明確的溫度分界線 | 溫度分界線的高度提示阻塞位置 |
| **四組脈搏觸診（雙側，由近端到遠端）** | 股動脈、膕動脈、脛後動脈、足背動脈 | 「我要摸您鼠蹊部、膝蓋後面、腳踝內側和腳背這四個位置的脈搏，兩邊都要摸。目的是找出血管是從哪一段開始不通的。」 | **遠端脈搏（足背、脛後）減弱或摸不到**；近端可能仍可觸及 | **脈搏消失的最高位置 = 阻塞的大致位置** |
| **微血管再充填時間** | 趾端甲床 | 「我壓一下您的腳趾甲再放開，目的是看血液回流的速度。」 | **延長（> 3 秒）** | — |
| **抬腿蒼白試驗／下垂潮紅（Buerger's test）** | 雙下肢 | 「請您平躺，我把您的腿抬高 45 度撐一分鐘，然後請您坐起來把腳垂下床邊。目的是觀察抬高和放下時腳的顏色變化，這能反映血流的嚴重程度。」 | **抬高時明顯蒼白；垂下後延遲出現暗紅色潮紅** | 陽性 → 嚴重動脈缺血 |
| **踝肱指數（ABI）** | 雙側踝部與上臂 | 「我要用血壓計和一個小型都卜勒儀器，量您手臂和腳踝的血壓，目的是算出血流到腳的比例，這是評估血管阻塞最重要的一個數字。」 | **降低**（本題預期明顯偏低） | ⚠️ **糖尿病或長期洗腎病人因血管鈣化，ABI 可能假性正常甚至偏高**——此時要改用趾肱指數（TBI） |
| **腹部搏動性腫塊觸診** | 上腹中線、臍周 | 「我要在您肚臍附近稍微壓深一點，目的是確認主動脈有沒有異常膨大，因為長期抽菸的人這裡也要一起檢查。」 | **摸不到異常搏動** | **摸到搏動性腫塊 → 腹主動脈瘤，這是必須主動排除的** |
| **腹部與股動脈聽診** | 上腹、雙側鼠蹊 | 「我用聽診器聽您肚子和鼠蹊部，目的是聽有沒有血流雜音，那代表血管有狹窄。」 | 可能聽到雜音（bruit） | 雜音 → 該處狹窄 |
| **感覺與運動功能（6P 的後兩項）** | 患足 | 「我輕碰您的腳，請告訴我有沒有感覺；然後請您動一下腳趾和腳踝。目的是確認神經和肌肉有沒有受到影響，這關係到緊急程度。」 | **感覺減退但仍有；仍可自主活動** | ⚠️ **完全麻木 ＋ 無法活動 = 急性肢體缺血的晚期，這隻腳有立即截肢風險，必須馬上通知血管外科** |
| 心臟聽診與心律 | 心尖區、脈搏 | 「我聽一下您的心音、摸脈搏，目的是確認心律是否規則，因為心律不整可能是血栓的來源。」 | 心律規則 | **不規則 → 心房顫動 → 栓塞來源** |
| 對側肢體與上肢脈搏 | 雙上肢 | 「我也摸一下您兩隻手的脈搏，目的是了解全身血管的狀況。」 | 正常 | — |

> **這一題身評的核心是「6P」：Pain（疼痛）、Pallor（蒼白）、Pulselessness（無脈）、Paresthesia（感覺異常）、Paralysis（麻痺）、Poikilothermia（冰冷）。**
> **前四個 P 是缺血，後兩個 P（麻痺與感覺完全喪失）是急症。**
> 情境的病人已經有 Pain、Pallor、Poikilothermia、Paresthesia（麻麻的），**必須親自確認 Paralysis 有沒有出現**——那是分辨「排時間處理」與「今天就要處理」的界線。

# 5. 需安排的檢查

## 階段一：床邊立即

- **踝肱指數（ABI）** ← **本題的關鍵檢查，而且它幾乎免費**
  - 目的：客觀量化下肢動脈阻塞的嚴重度
  - 只需要一個血壓計和手持式都卜勒，**床邊五分鐘完成**
  - ⚠️ **限制**：糖尿病或洗腎病人血管鈣化，ABI 可能假性正常，需改測**趾肱指數（TBI）**
- **POCT 血糖 ＋ HbA1c**：糖尿病是必須確認的共病
- **生命徵象**
- **6P 評估**（見上節）

## 階段二：非侵入性、無輻射

- **下肢動脈都卜勒超音波（duplex ultrasound）**
  - 目的：**定位阻塞的位置與長度、評估血流速度與側枝循環**
  - 無輻射、無顯影劑、可重複
- **腹部主動脈超音波**
  - 目的：**篩檢腹主動脈瘤**。65 歲重度吸菸男性是明確的高風險族群
  - 五分鐘、無輻射，**這一項不做很可惜**
- **心臟超音波（若懷疑栓塞來源）**

## 階段三：有輻射／顯影劑／侵入性

- **電腦斷層血管攝影（CTA）**
- **傳統血管攝影（DSA）**——同時可做治療性介入

> **這一題非常適合說明檢查排序的原則，因為它每一階都有明確的分工：**
>
> **ABI 回答「有多嚴重」，都卜勒超音波回答「塞在哪裡」，CTA 或血管攝影回答「怎麼修」。**
>
> **本題我不會一開始就排 CTA**，理由有三：
> 1. **ABI 加都卜勒超音波已經足以做出診斷與嚴重度分級**，而且沒有輻射、沒有顯影劑
> 2. 這位病人 65 歲、長期抽菸，**腎功能未知**。CTA 的顯影劑對腎功能不佳的病人有顯影劑腎病變的風險，在還沒驗腎功能之前先做，是不必要的暴露
> 3. **CTA 的價值在於「決定怎麼介入」——如果還沒決定要不要介入，做了也用不上**
>
> **升級到 CTA 或血管攝影的條件**：
> - 已確認為 CLTI 且**決定要做血管重建**（此時需要精確的解剖圖）
> - 懷疑**急性肢體缺血**（有時間壓力，直接進導管室）
> - 都卜勒超音波結果與臨床不符

# 6. 檢驗

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| **空腹血糖、HbA1c** | **↑ → 糖尿病。改變傷口癒合預期與感染風險，本題必驗** |
| **血脂（LDL、TG、HDL）** | ↑ → 動脈硬化風險因子，也是治療目標 |
| **BUN/Cr、eGFR** | **決定能不能安全使用顯影劑**，本題必驗 |
| CBC/DC | WBC ↑ → 若壞疽已感染；Hb ↓ → 貧血會加重組織缺氧 |
| **CRP、ESR** | ↑ → 感染或發炎（若懷疑濕性壞疽） |
| **傷口／血液培養** | 若壞疽有滲液或全身感染徵象，**抗生素前留取** |
| PT/INR、APTT | 抗凝血或介入前準備 |
| 心電圖 | **確認有無心房顫動（栓塞來源）與潛在冠心症** |
| 同半胱胺酸、發炎指標 | 非必要，若年輕族群或病因不明才考慮 |

# 7. 前三個鑑別診斷

## ① 主診斷：慢性肢體威脅性缺血（CLTI）／週邊動脈阻塞疾病

**支持證據（本題支持證據極強，幾乎是教科書病程）**
- **間歇性跛行**：走十分鐘痛、休息十分鐘緩解、**痛在小腿肚**、走路一跛一跛【已知】
- **靜止痛**：夜間痛醒，**腳垂下床可緩解**——這是嚴重動脈缺血的特異表現【已知】
- **組織缺損**：右大拇趾變黑三天，**且無外傷**【已知】
- 雙腳**冰冷、麻麻的**【已知】
- **抽菸 45 年、目前一天一包半（> 50 pack-year）**——最強的風險因子【已知】
- 65 歲男性【已知】
- 預期：遠端脈搏消失、ABI 明顯降低、Buerger's test 陽性【推論】

**不支持之處（誠實列）**
- 情境**完全沒有提到糖尿病**。65 歲、有動脈疾病的病人，糖尿病的共病率很高，**沒問到就無法判斷這個黑趾頭有多少是缺血、多少是糖尿病足**。
- 情境未提供腳趾有無傷口、滲液或惡臭——**乾性壞疽與濕性壞疽（合併感染）的處置急迫性差很多**。
- 情境未提供高血壓、高血脂、心臟病史。
- 未提供腎功能，而這會影響檢查與用藥選擇。

**確診依據**
臨床病程（跛行 → 靜止痛 → 組織缺損）＋ **ABI 明顯降低** ＋ 都卜勒超音波或血管攝影見動脈狹窄阻塞。

## ② 次可能：急性肢體缺血（acute on chronic）

**為什麼它還留在名單上——而且這是本題的時間炸彈**

病人有一年的慢性病程，但**大拇趾是「三天前」才變黑的**。
這代表兩種可能：
- **慢性缺血自然進展到組織壞死**（時間尺度以週到月計，可以排時間）
- **在慢性狹窄的基礎上，三天前發生了急性血栓或栓塞**（**有時間窗，以小時計**）

這兩者的處置急迫性差了一個數量級。

**要出現什麼證據，它才會翻上第一位**
1. **突然的變化**——問出「是某一天突然變的」而非慢慢變黑
2. **6P 中的後兩項出現**：**感覺完全喪失、無法自主活動**
3. **原本可觸及的脈搏突然消失**
4. 疼痛**突然大幅加劇**，或反而突然不痛（神經壞死）
5. 心房顫動或近期心肌梗塞（栓塞來源）

**翻上來的臨床意義**
> 從「門診排血管超音波、戒菸、運動治療、藥物」變成 **「立即通知血管外科，可能今天就要進導管室或開刀」**。
> 急性肢體缺血有明確的時間窗，**延誤的結果是截肢**。
>
> **這是本題最重要的臨床判斷，而問出它只需要一句話：「是三天前突然變黑的，還是慢慢變的？」**

## ③ 不能排除：腹主動脈瘤

**這一格放的是漏掉會死人的診斷，而且它的位置不在腳上。**

**為什麼必須主動排除**
- **65 歲、男性、抽菸 45 年**——這正是腹主動脈瘤篩檢的高風險族群定義（多數指引建議這個族群做一次超音波篩檢）【推論，需查證】
- **動脈粥狀硬化是全身性的疾病**。這位病人的下肢動脈已經爛到腳趾壞死，**沒有理由假設他的主動脈是好的**
- **腹主動脈瘤內的血栓可能脫落，造成遠端小動脈栓塞——這正是趾端變黑的另一種機轉**（藍趾／黑趾症候群）
- **最危險的是**：我們忙著處理那隻腳，而**破裂的腹主動脈瘤會在幾小時內致死**，而且他來的時候完全沒有腹部症狀
- 本題病人的實際死因，統計上更可能是心血管事件而不是這隻腳

**排除它的最低限度**
> **在肚臍附近深部觸診，看有沒有搏動性腫塊——十秒鐘，不用任何儀器。**
> **若體型肥胖摸不確定，加做一次腹部主動脈超音波——五分鐘，無輻射。**

不需要 CT。**這一格的成本極低，而漏掉的代價是猝死。**

> **延伸的臨床意義**：這位病人真正需要的不只是「處理這隻腳」，而是**全身動脈疾病的評估與危險因子控制**——戒菸、抗血小板、降血脂、控制血糖血壓，以及評估冠狀動脈與頸動脈。
> **口試若只講那隻腳，會被認為視野太窄。**

# 8. 口試委員最可能追問的五題

**Q1「這個病人的病程，你怎麼讀？」**
> 情境把三個階段依時間完整寫出來了。**一年前是間歇性跛行**，走十分鐘痛、休息就好，代表運動時供血不夠；**一個月前變成靜止痛**，夜裡會痛醒、腳垂下床才緩解，代表連休息時的基礎供血都不夠了；**三天前腳趾變黑**，代表組織已經開始死亡。
> 這不是三個症狀，是同一個疾病在一年內走完三個階段，現在已經到了**會失去這隻腳**的程度。

**Q2「腳垂在床邊會緩解，這一句代表什麼？」**
> 這是嚴重動脈缺血很特異的表現。平躺的時候腳跟心臟同高，失去重力的幫助；把腳垂下床，重力增加末梢的灌流，痛就緩解。
> **靜脈或神經的問題不會有這個特徵**，所以病人自己描述的這個動作，本身就是一個診斷性的線索。

**Q3「他走路會痛，你怎麼確定不是腰椎狹窄？」**
> 我會問三題。第一，**走多遠開始痛，每次都差不多嗎**——血管性的距離很固定，神經性的不固定。第二，**停下來就好，還是要坐下來才好**——血管性站著休息就會好，神經性通常要坐下或彎腰。第三，**騎腳踏車會不會痛**——血管性會，因為一樣需要血流；神經性反而不太會，因為身體前傾椎管會變寬。
> 情境給的「痛在小腿肚、走十分鐘、休息十分鐘緩解」都指向血管性，但那三題我還是會親口問。

**Q4「你為什麼不直接做電腦斷層血管攝影？」**
> 因為每一階檢查回答的問題不一樣。**ABI 回答「有多嚴重」，都卜勒超音波回答「塞在哪裡」，CTA 回答「怎麼修」。**
> 我現在需要的是前兩個答案，而 ABI 只要一台血壓計加手持都卜勒，床邊五分鐘就有，都卜勒超音波也沒有輻射沒有顯影劑。
> 而且這位病人 65 歲、抽菸 45 年，**腎功能還不知道**，顯影劑對腎功能不好的人有風險。在還沒驗腎功能、也還沒決定要不要做血管重建之前就打顯影劑，是不必要的暴露。
> 等到確定要做血管重建，那時候 CTA 才真的用得上。

**Q5「這一題你最擔心什麼？」**
> 兩件事，而且都不是那隻腳本身。
> 第一，**三天前是不是有一個急性事件疊上去**。如果是急性血栓或栓塞，那是以小時計的時間窗，處置完全不同。所以我一定會問「是突然變黑還是慢慢變的」，也一定會確認感覺和運動功能有沒有喪失。
> 第二，**腹主動脈瘤**。他 65 歲、男性、抽菸 45 年，正是高風險族群。動脈硬化是全身性的，下肢已經爛到腳趾壞死，沒有理由假設主動脈是好的。而且動脈瘤裡的血栓掉下來，本身就可能是腳趾變黑的原因。
> **摸肚子只要十秒鐘，但漏掉的話病人可能在我們忙著處理腳的時候猝死。**

**SBAR 骨幹**
- **S**：65 歲男性，右大拇趾變黑三天，無外傷。
- **B**：一年來雙下肢間歇性跛行（走十分鐘、休息十分鐘緩解、痛在小腿肚）；一個月來夜間靜止痛，**垂足可緩解**。**抽菸 45 年、目前一天一包半**。糖尿病、高血壓、高血脂、心臟病史待確認。
- **A**：（依理學填）右足背與脛後動脈脈搏 ___、雙足溫度 ___、微血管再充填 ___、**ABI ___**、Buerger's test ___、**感覺與運動功能 ___**、**腹部搏動性腫塊 ___**、心律 ___。**最可能為慢性肢體威脅性缺血（CLTI）**；因三天前才出現組織壞死，**須確認是否為急性缺血疊加於慢性狹窄之上，此為時間敏感之急症**；因病人為 65 歲重度吸菸男性且動脈硬化為全身性疾病，**須主動排除腹主動脈瘤**。
- **R**：建議床邊測 **ABI**（若疑血管鈣化改測 TBI）、6P 評估、EKG；抽空腹血糖、HbA1c、血脂、**BUN/Cr/eGFR**、CBC/DC、CRP、PT/INR；安排下肢動脈都卜勒超音波與**腹部主動脈超音波**。傷口照護、避免加壓與過熱、**患肢保暖但不可直接熱敷**。**通知血管外科評估**。同時處理全身危險因子：**戒菸轉介**、抗血小板與降血脂之評估、血糖血壓控制。

# 9. 我不確定的地方

1. **ABI 的正常值與分級切點**——我刻意沒有寫任何數字。**確切的切點與嚴重度分級請自行查證，這是很容易被追問而且講錯會很明顯的地方。**
2. **腹主動脈瘤篩檢的建議族群與年齡**——我寫「65 歲男性吸菸者」，這方向應該對，但**台灣有沒有相應的篩檢建議與給付，請查證**。
3. **CLTI 的正式分類系統（如 Rutherford、Fontaine、WIfI）**——我用臨床階段描述而未套用分類名稱。若委員問起分類，請以你熟悉的系統回答。
4. **急性肢體缺血的時間窗（黃金時間）**——我知道以小時計，**具體小時數沒有把握，不要講數字**。
5. **糖尿病或洗腎病人 ABI 假性偏高**——這個現象我有把握存在，但發生比例不確定。
6. **「腳垂下床緩解」的正式名稱**——臨床上有這個描述，正式術語我不確定。
7. **戒菸對 PAOD 預後改善的程度**——我知道戒菸是最重要的介入之一，**倍數或百分比不要講**。
8. **患肢保暖但不可熱敷**——我寫進 SBAR，因為缺血的肢體感覺遲鈍容易燙傷。這個護理原則我信心較高，但請以你們的傷口照護實務為準。
