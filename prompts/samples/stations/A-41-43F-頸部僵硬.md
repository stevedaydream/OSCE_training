# A-41｜43 歲女性，頸部僵硬疼痛、右上肢酸麻無力

> Prompt A 輸出（**新版十節格式，委員不提問**）。臨床內容未經人工審核，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #41）

43 歲女性，頸部僵硬疼痛厲害，右上肢酸麻且稍微無力。
兩個月前不小心於浴室滑倒，頸部先往前彎後又往後甩，之後頸部即劇烈疼痛及僵硬，無法轉動。隔天有到診所看診，服用消炎止痛藥及肌肉鬆弛劑後，僅能讓疼痛暫時性的好一點。最近一個月頸部僵硬疼痛更加嚴重且會傳至右側肩胛附近及右上肢。右上肢及右手覺得麻麻的、比較沒有力氣。
銀行職員，上班需長時間打電腦且工作壓力大，已婚，大學畢業，身體健康、沒有開過刀或住院。無抽菸及喝酒。無高血壓、糖尿病等病史、無家族病史。

# 1. 情境事實清單

- 43 歲女性，銀行職員，長時間打電腦、工作壓力大
- **兩個月前浴室滑倒，頸部先前彎後後甩**（揮鞭式機轉 whiplash）
- 之後頸部**劇烈疼痛及僵硬、無法轉動**
- 隔天診所就醫，**消炎止痛藥＋肌肉鬆弛劑僅暫時緩解**
- **最近一個月症狀更加嚴重**，且**傳至右側肩胛附近及右上肢**
- **右上肢及右手麻麻的、比較沒有力氣**
- 已婚，大學畢業，身體健康，**無手術住院史**
- **無抽菸喝酒**，無高血壓糖尿病，無家族病史

**情境未給**：生命徵象、麻的**確切分布（哪幾根手指）**、無力的具體動作、**有沒有步態不穩**、**有沒有手部精細動作變差**、**有沒有大小便功能改變**、有沒有夜間痛醒、有沒有發燒體重減輕。

---

# 2. 第一印象與危險分流

**這一題的關鍵在病程的形狀：外傷後兩個月，症狀不但沒好，反而在最近一個月「往下長」。**

原本是**局部**的頸痛與僵硬，現在**沿著肩胛傳到上肢，並出現麻與無力**。
單純的揮鞭式軟組織損傷應該隨時間改善；**症狀由局部擴展為神經症狀，代表有結構性的東西在壓迫神經根**——最可能是外傷後的椎間盤突出，或既有退化因外傷而症狀化。

**但真正要分辨的是另一件事，而且它決定處置急迫性：**

| | 神經根病變 radiculopathy | **脊髓病變 myelopathy** |
| :--- | :--- | :--- |
| 壓到什麼 | **神經根**（周邊） | **脊髓**（中樞） |
| 症狀 | 沿單一皮節的痛、麻、無力 | **手部笨拙、扣鈕扣困難、步態不穩、大小便異常** |
| 反射 | **減弱** | **亢進**，Hoffmann／Babinski 陽性 |
| 病程 | 常可保守治療改善 | **進行性，通常需要手術** |
| 漏掉的後果 | 慢性疼痛 | **不可逆的癱瘓** |

**病人不會主動說 myelopathy 的症狀**——因為「最近比較常跌倒」「筷子拿不好」「扣子扣很久」在她看來是老化或分心，不是「症狀」。**必須主動問。**

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **頸髓病變（myelopathy）** | 症狀進行性惡化，漏掉會癱瘓 | **問步態與手部精細動作；查 Hoffmann、反射、Babinski** |
| 頸椎不穩定／遲發性韌帶損傷 | 外傷機轉 ＋ 兩個月未改善 | 影像；避免頸椎過度活動 |
| 感染或腫瘤（red flag） | 進行性惡化的疼痛 | 問夜間痛醒、發燒、體重減輕 |

# 3. 焦點式病史（5 分鐘，優先順序由上而下）

## 最優先的五題

1. **「麻的是哪幾根手指？請指給我看。」**
   → **這一題定位神經根**。拇指與食指偏 C6；中指偏 C7；無名指與小指偏 C8。
   若**整隻手都麻**或**兩隻手都麻**，反而要往脊髓病變或周邊神經想
2. **「無力是做什麼動作的時候？拿東西會掉嗎？」**
   → 舉手過頭困難偏 C5；伸腕困難偏 C6；伸肘、伸指困難偏 C7
3. **「最近走路會不會覺得不穩、比較容易絆到，或需要扶東西？」** ← **myelopathy 篩檢**
4. **「手變不變得比較笨？扣鈕扣、拿筷子、寫字有沒有變困難？」** ← **myelopathy 篩檢，最敏感的一題**
5. **「大小便有沒有變化？想尿卻尿不出來，或來不及？」** ← **myelopathy 晚期，出現代表很嚴重**

## 其他必問

- 頸部往哪個方向轉會更痛？**頭往後仰或往右轉會不會讓手更麻？**（神經根受壓的誘發動作）
- **手舉高放在頭上會不會比較舒服？**（shoulder abduction relief sign，偏神經根病變）
- 這兩個月的疼痛曲線？**晚上會不會痛醒？**（red flag）
- 有沒有低頭時像電流竄下背部的感覺？（Lhermitte's sign → 脊髓）
- 有沒有發燒、體重減輕、夜間盜汗？（感染或腫瘤 red flag）
- 滑倒當時**有沒有撞到頭、有沒有短暫失去意識**？
- 診所開的藥吃了多久？有沒有做過復健或物理治療？效果如何？
- 有沒有照過頸椎 X 光？結果如何？
- 工作型態：一天打電腦幾小時？有沒有休息？

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| **沒有步態不穩、手部精細動作正常、大小便正常** | **降低頸髓病變**——這是本題最重要的一組否定 |
| 沒有夜間痛醒、無發燒、無體重減輕 | 降低感染與腫瘤 |
| 沒有兩側同時麻、沒有下肢症狀 | 降低脊髓與中樞病灶 |
| 情境已給：無抽菸、無糖尿病 | 降低血管性與糖尿病神經病變 |
| 沒有胸痛、沒有活動時喘 | 降低轉移痛（心臟來源可表現為左肩，本例為右側） |

# 4. 焦點式身體評估（5 分鐘，最多 8 項）

| 必做？ | 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **必做** | **頸椎姿勢視診與主動活動度** | 頸部 | 「請您慢慢地低頭、抬頭、左右轉、左右側彎，**能做到哪裡就停，會痛就不要勉強**。目的是評估頸椎活動受限的方向和程度。」 | **活動度受限，尤其右轉與後仰** | — |
| **必做** | **上肢肌力（依肌節，雙側對比）** | 肩外展 C5／屈肘、伸腕 C6／伸肘、伸指 C7／屈指 C8／手指外展 T1 | 「我要測您兩隻手各個動作的力氣，請照我說的用力頂住我的手，兩邊我會輪流做比較。目的是找出無力屬於哪一條神經根。」 | **右側特定肌節輕度無力** | 全手無力 → 往脊髓或周邊神經想 |
| **必做** | **上肢感覺（依皮節，雙側對比）** | 上臂外側 C5／拇指食指 C6／中指 C7／小指 C8 | 「我用棉花輕碰您兩隻手臂和手指的不同位置，請告訴我兩邊感覺一不一樣。目的是確認麻的範圍對應到哪一節頸椎的神經。」 | **右側單一皮節感覺減退** | 手套式分布 → 周邊神經病變 |
| **必做** | **深部肌腱反射（雙側對比）** | 二頭肌 C5／肱橈肌 C6／三頭肌 C7 | 「我用小槌子敲您手臂的幾個位置，請放輕鬆。目的是比較兩邊反射的強弱，這能分辨壓迫的位置在神經根還是脊髓。」 | **受影響那一節的反射減弱** | **反射亢進 → 脊髓病變** |
| **必做** | **Hoffmann's sign ＋ 下肢反射與 Babinski** | 中指、膝踝反射、足底 | 「我要彈一下您的中指指甲，再敲膝蓋和腳踝、輕劃腳底。目的是排除壓迫的位置是在脊髓而不是神經根，因為那兩者的處理方式差很多。」 | **陰性——這是本題最重要的一組陰性** | **陽性 → 頸髓病變，須手術評估** |
| **必做** | **Spurling test（誘發神經根痛）** | 頸部 | 「我要請您把頭往右後方稍微仰，我會在頭頂輕輕加一點壓力。目的是看能不能誘發出您平常那個往手臂傳的麻。**只要一有麻就馬上告訴我，我立刻停。**」 | **陽性：誘發右上肢放射性麻痛** | 陽性支持神經根病變 |
| 有時間 | 頸椎棘突與斜方肌觸診 | 頸椎中線、肩胛內緣 | 「我沿著您的頸椎和肩胛骨內側輕壓，目的是找出壓痛點，分辨是肌肉還是骨頭的問題。」 | 肌肉壓痛、可能有激痛點 | 中線骨性壓痛 → 骨頭病灶 |
| 有時間 | **步態與 tandem gait** | — | 「請您走幾步給我看，然後試著像走平衡木一樣腳跟接腳尖走。目的是進一步確認脊髓有沒有受影響。」 | 正常 | **不穩 → 頸髓病變** |

**這一題的檢查順序為什麼這樣排**：**先讓病人主動活動再由我被動施力**——她的頸椎在外傷後兩個月，我不知道穩定性，讓她自己動到會痛就停，比我扳她的頭安全得多。**Spurling test 放最後**，因為它是刻意誘發症狀的動作，做完病人會不舒服，會影響後續配合。

# 5. 需安排的檢查

## 階段一：診間立即

- 完整神經學檢查（上一節）——**這一題的診斷主要靠這裡，不是靠影像**
- 生命徵象

## 階段二：低輻射影像

- **頸椎 X 光（正面、側面、開口位；必要時斜位）**
  - 目的：看**椎間隙變窄、骨刺、排列（alignment）、有無骨折或不穩定**
  - 預期發現：可能只有退化性變化，**甚至完全正常**
  - **陰性時下一步：X 光正常不能排除椎間盤突出——X 光看不到椎間盤與神經**

## 階段三：進階影像

- **頸椎磁振造影（MRI）** ← **本題確認診斷的檢查**
  - 目的：**直接看到椎間盤突出、神經根受壓、以及脊髓有沒有受壓與訊號改變**
  - 無輻射
  - **適應症**：症狀持續超過 4–6 週保守治療無效、**或任何時候出現進行性神經功能缺損、或懷疑脊髓病變**
  - **本例兩項都符合**（兩個月、且症狀進行性惡化）
- 神經傳導檢查／肌電圖（NCV/EMG）：當臨床無法分辨是神經根還是周邊神經（如腕隧道）時使用
- 頸椎 CT：主要看骨頭與術前規劃，**看神經不如 MRI**

> **本題的檢查排序，重點不在「省錢」而在「順序」。**
>
> **我不會一開始就開 MRI**，理由是：**這一題的診斷主要來自神經學檢查，不是影像。**
> 皮節與肌節的分布、反射是減弱還是亢進、Spurling 是不是陽性——這些床邊就能得到，而且它們決定的是「要照什麼」與「多急」。
> **先照 X 光**是因為它便宜、快，而且能回答「排列有沒有問題、有沒有骨性病灶」，這是外傷後兩個月該確認的事。
>
> **但這一題有一個條件會讓我跳過等待，直接安排 MRI：只要 Hoffmann、反射亢進、Babinski、步態不穩任何一項出現，就是脊髓病變的訊號，那不能保守觀察。**
>
> 本例**已經符合 MRI 適應症**（保守治療兩個月無效 ＋ 症狀進行性惡化），所以 X 光與 MRI 我會一起安排，不是先觀察再說。

# 6. 檢驗

**這一題的抽血價值很低，而且要主動說明為什麼。**

| 項目 | 說明 |
| :--- | :--- |
| CBC/DC、**CRP、ESR** | **只在有 red flag 時才驗**（發燒、體重減輕、夜間痛醒、免疫低下）。目的是排除**脊椎感染**與腫瘤 |
| 血糖、HbA1c | 若感覺異常分布不典型，排除糖尿病周邊神經病變。本例情境已說無糖尿病，優先度低 |
| 甲狀腺功能、B12 | 若懷疑代謝性周邊神經病變。本例優先度低 |
| 類風濕因子、抗環瓜胺酸抗體 | **僅在懷疑類風濕性關節炎併寰樞椎不穩定時**才驗 |

> **一個明確的外傷後神經根病變，不需要常規抽血。** 主動說出「我不驗什麼、為什麼」也是臨床推理的一部分。

# 7. 前三個鑑別診斷

## ① 主診斷：頸椎神經根病變（外傷後椎間盤突出，右側 C6 或 C7）

**支持證據**
- **明確的外傷機轉**：滑倒、頸部前彎後後甩（揮鞭式）【已知】
- **症狀由局部頸痛擴展為沿肩胛傳至上肢的放射痛**——神經根受壓的典型走向【已知】
- **右上肢麻木併輕度無力**——單側、有分布【已知】
- **消炎止痛藥與肌肉鬆弛劑僅暫時有效**——不符合單純肌肉損傷【已知】
- **兩個月未改善反而惡化**【已知】
- 職業長時間打電腦，頸椎負擔大【已知】
- 預期：Spurling 陽性、單一皮節感覺減退、對應肌節無力、該節反射減弱【推論】

**不支持之處（誠實列）**
- 情境**沒有說明麻的確切分布是哪幾根手指**——而這是定位神經根、也是區分神經根與周邊神經（如腕隧道）的關鍵。**必須問診補上。**
- 情境**完全沒有提到步態、手部精細動作、大小便**——所以目前無法排除脊髓病變。
- 未提供反射檢查結果。
- 未說明「無力」是主觀感覺還是客觀可測。

**確診依據**
臨床（皮節分布 ＋ 對應肌節無力 ＋ 該節反射減弱 ＋ Spurling 陽性）＋ **頸椎 MRI 見椎間盤突出壓迫對應神經根**。

---

## ② 次可能：揮鞭式損傷後遺症併肌筋膜疼痛症候群

**為什麼它還留在名單上**
外傷機轉明確、頸部僵硬無法轉動、長時間打電腦、工作壓力大——這些完全符合揮鞭式損傷後的慢性頸部肌筋膜疼痛。
而且**肩胛內緣的轉移痛也可以來自斜方肌與提肩胛肌的激痛點**，不一定是神經根。
「麻麻的、比較沒力氣」也可能是疼痛抑制造成的主觀感受，而非真正的神經損傷。

**要出現什麼證據，它才會翻上第一位**
1. **神經學檢查完全正常**——肌力對稱、感覺無皮節性減退、反射對稱
2. **Spurling test 陰性**
3. 觸診可找到明確**激痛點，且按壓能重現轉移痛的路徑**
4. 麻的分布**不符合任何皮節**（例如整隻手臂一片、或範圍浮動）
5. 頸椎 MRI 無神經根壓迫

**翻上來的臨床意義**：從「可能需要神經減壓手術評估」變成「**物理治療、姿勢與工作型態調整、疼痛管理**」。
處置強度與病人的擔憂程度都完全不同。

---

## ③ 不能排除：頸髓病變（cervical myelopathy）

**這一格放的是漏掉會癱瘓的診斷，而且它最大的特點是「病人不會告訴你」。**

**為什麼必須主動排除**
- 她的症狀**兩個月來持續惡化而非改善**——這正是脊髓病變的病程形狀
- **外傷可能讓原本無症狀的椎管狹窄突然症狀化**
- **最關鍵的是：myelopathy 的早期症狀病人不會當成症狀來講。**
  「最近比較常絆到」「筷子拿不好」「扣子扣很久」——她會歸因於年紀、分心、太累。
  **你不問，她就不會說。**
- 一旦進展，脊髓損傷**不可逆**，而且處置從保守治療變成**手術減壓**
- 神經根病變與脊髓病變**可以並存**，找到神經根的證據**不等於排除了脊髓**

**排除它的最低限度**
> **問三題 ＋ 查三項，全部在診間完成，不需要任何儀器：**
>
> **問**：走路會不會不穩／手變不變笨（扣鈕扣、拿筷子）／大小便有沒有變化
> **查**：**Hoffmann's sign、下肢深部肌腱反射是否亢進、Babinski**
>
> **反射「減弱」指向神經根，反射「亢進」指向脊髓——這一個方向的差別，就是保守治療與手術評估的分界。**

若任何一項陽性 → **不再是「保守治療四到六週看看」，而是立即安排 MRI 並轉介脊椎外科**。

# 8. 兩段逐字稿（注意順序：先對病人，再向委員）

> 專科護理師甄審口試中**委員不提問**。實際流程是：

## 8a. 身體評估結束後，對病人說明（約 1 分鐘）

> 陳小姐，我需要的檢查都做完了，謝謝您配合。
>
> 從我剛才的評估來看，**您兩個月前跌倒扭到脖子，一開始只有脖子痛，但最近一個月痛跑到肩胛骨和右手，還會麻、比較沒力，而且我測到您右手某些動作的力氣確實比左邊弱。這個變化代表可能不只是肌肉拉傷，而是頸椎壓到神經了**，所以吃止痛藥和肌肉鬆弛劑只能暫時有效。
>
> 這段時間有幾件事請您先做到：**避免長時間低頭，打電腦每半小時起來活動一下**；**也請暫時不要去給人推拿或扳脖子**，因為在還沒確認之前，那樣做可能會加重。

## 8b. 向口試委員報告鑑別診斷（約 3 分鐘）

> 報告委員。這位是 43 歲女性，銀行職員，主訴是**頸部僵硬疼痛合併右上肢酸麻與輕度無力**。
>
> 病史方面，她**兩個月前在浴室滑倒，頸部先前彎再後甩，屬於揮鞭式的受傷機轉**。當時劇烈頸痛僵硬，隔天在診所拿了消炎止痛藥與肌肉鬆弛劑，**但只有暫時緩解**。**關鍵是最近一個月症狀不但沒好，反而往下延伸**，從局部頸痛變成傳到右側肩胛與整條右上肢，並且出現麻與無力。
> 我特別追問了幾項：麻的分布是 ___ 手指，無力出現在 ___ 動作。另外我主動問了三件病人通常不會自己講的事——**走路會不會不穩、手有沒有變笨（扣鈕扣、拿筷子）、大小便有沒有改變**，答案分別是 ___、___、___。我問這三題是因為它們是脊髓病變的早期表現，而病人多半會把它歸因於年紀或分心，不會當成症狀說出來。
>
> 身體評估方面，頸椎主動活動度受限於 ___ 方向；上肢肌力依肌節檢查為 ___；感覺在 ___ 皮節減退；**深部肌腱反射右側 ___**；**Spurling test ___**；**Hoffmann's sign ___、下肢反射 ___、Babinski ___**。
>
> 綜合以上，**我認為最可能的健康問題是右側頸椎神經根病變，很可能是外傷後的椎間盤突出壓迫神經根**。理由是：疼痛從局部擴展為沿皮節分布的放射痛、對應肌節出現無力、該節反射減弱、Spurling 陽性，而且**消炎止痛藥與肌肉鬆弛劑只能暫時緩解，這不符合單純的肌肉損傷**。
>
> **第二個可能是揮鞭式損傷後的肌筋膜疼痛症候群。** 它還在名單上是因為她的受傷機轉、頸部僵硬、長時間打電腦與工作壓力都符合，而肩胛內緣的轉移痛也可以來自斜方肌的激痛點。**如果神經學檢查完全正常、Spurling 陰性，而且觸診能找到激痛點並重現她的轉移痛，這個診斷就會翻上第一位**，處置也會從手術評估變成物理治療與工作型態調整。
>
> **另外我認為必須主動排除的是頸髓病變。** 它的機率不一定最高，但**漏掉的後果是不可逆的癱瘓**，而且它最麻煩的地方在於**病人不會主動說**。她的症狀兩個月來持續惡化而非改善，這正是脊髓病變的病程形狀，而且外傷可能讓原本無症狀的椎管狹窄突然症狀化。
> 排除它不需要任何儀器：**問走路穩不穩、手笨不笨、大小便有沒有變，再查 Hoffmann、下肢反射與 Babinski。反射減弱指向神經根，反射亢進指向脊髓——這一個方向的差別，就是保守治療與手術評估的分界。**
>
> **處置計畫方面**，我會先安排**頸椎 X 光**，看排列、椎間隙與有沒有骨性病灶，這在外傷後兩個月是該確認的。**但 X 光看不到椎間盤與神經，正常不能排除。**
> 因為她已經保守治療兩個月無效、而且症狀是進行性惡化，**已經符合頸椎 MRI 的適應症**，所以我會兩者一起安排，不是先觀察再說。
> **如果 Hoffmann、反射亢進、Babinski 或步態不穩任何一項陽性，我不會等，會立即安排 MRI 並轉介脊椎外科。**
> 抽血在這一題價值很低，我只在有 red flag 的時候才驗——也就是發燒、體重減輕、夜間痛醒，那時才需要 CRP 與 ESR 排除脊椎感染或腫瘤。報告完畢。

# 9. 我不確定的地方

1. **皮節與肌節的對應（C5–T1）**——我寫的是常見版本，但**教科書之間有出入，且個體差異存在**。口試講出來前請自己再確認一次你熟悉的版本。
2. **Spurling test 的標準操作方式**（伸展＋側彎＋旋轉＋軸向加壓的組合與順序）——各家描述略有不同，請查證你要用的版本。
3. **Hoffmann's sign 的敏感度與特異度**——我知道它是 myelopathy 的篩檢工具，**但陽性也可見於正常人**，數字沒有把握，不要講。
4. **保守治療多久無效才該做 MRI**——我寫 4–6 週，這是常見說法但請查證現行建議。
5. **揮鞭式損傷（whiplash）的分級系統（如 Quebec Task Force）**——我沒有套用，若委員期待分級請自行補。
6. **本題是否適合放進外科題庫**——頸椎神經根病變在台灣多由骨科或神經外科處理，屬外科系。但若你們醫院是復健科為主，這一題的定位請自己判斷。
7. **「不要去推拿」這個衛教**——方向我有把握（未確診前的頸椎操作有風險），但台灣民眾接受度與實際說法的分寸，你比我清楚。

**如果只剩 5 分鐘，我會先放掉這三項：**

1. **頸椎棘突與斜方肌觸診**——它幫忙區分肌筋膜來源，但**MRI 反正會給我答案**，而且它不改變「要不要急」這個判斷。
2. **步態與 tandem gait**——因為我已經用 **Hoffmann、下肢反射與 Babinski** 篩過脊髓了，步態是同一個問題的第二個答案。**先問「走路會不會不穩」，比實際走給我看更省時間。**
3. **完整的頸椎六方向活動度**——改成只做**右轉與後仰**這兩個會誘發症狀的方向。

**放掉它們最不傷的理由**：這三項都是**補強**性質的資訊。
**我保留的六項裡，前四項（活動度、肌力、感覺、反射）建立神經根的定位，第五項（Hoffmann／Babinski）排除脊髓，第六項（Spurling）確認誘發。**
