# A-29｜60 歲女性，腹痛兩個月

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #29）

60 歲女性，腹痛兩個月來門診看病。
過去吃蝦子過敏（全身起疹子，屢試不爽）。不抽菸、不嚼檳榔，應酬時偶喝酒。18 歲時車禍，右大腿骨折，當時接受開刀，手術後康復。目前已停經 10 年。36 歲生下 1 女兒，從沒有流產過。父親有高血壓數十年，75 歲心臟病死亡。**母親是 B 型肝炎帶原者，目前 90 歲。**

---

# 1. 情境事實清單

- 60 歲女性
- **腹痛兩個月**，門診（非急診）
- 蝦子過敏（全身疹）
- 不抽菸、不嚼檳榔、**應酬時偶喝酒**
- 18 歲車禍，右大腿骨折開刀，術後康復
- 停經 10 年（約 50 歲停經）
- 36 歲生一女，無流產
- 父親高血壓數十年，75 歲心臟病死亡
- **母親為 B 型肝炎帶原者，現 90 歲**

**情境未給**：疼痛的位置、性質、程度、時序變化、誘發緩解因子、任何伴隨症狀、體重變化、排便習慣、生命徵象。**主訴本身幾乎是空白的。**

---

# 2. 第一印象與危險分流

**這一題和其他題不一樣：情境給的不是症狀，是背景。**

「腹痛兩個月」五個字，加上一整段跟腹痛沒有直接關係的過去史、家族史、生活史。**這不是資訊不足的瑕疵，這就是考點。** 它要看的是：當主訴極度模糊時，你會不會自己把病史問出來，而不是等著被餵。

所以本題的第一印象不是某個診斷，而是一個判斷：**兩個月的病程，這是慢性腹痛，不是急症。** 急性腹症的鑑別框架（穿孔、阻塞、缺血）在這裡優先度要往下調，往上調的是**惡性腫瘤與慢性器官疾病**。

**情境刻意埋了一條線索，很容易被跳過：**

> **「母親是 B 型肝炎帶原者，目前 90 歲。」**

一位 60 歲的台灣女性，母親是 B 肝帶原者——**她本人有很高的機會是母嬰垂直感染的帶原者**，而且以她的出生年代，很可能從來沒有規律追蹤過。這條線索直接把**肝細胞癌**推進 can't-miss 那一格。

情境提到「應酬時偶喝酒」也不是廢話：**B 肝帶原 ＋ 飲酒**是肝硬化與肝癌的加成風險。

30 秒內要擺上檯面（慢性版本）：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **肝細胞癌** | 母親 B 肝帶原 ＋ 飲酒 ＋ 60 歲 | 問她自己驗過 B 肝沒有、有沒有追蹤 |
| **大腸癌** | 60 歲、慢性腹痛，年齡本身就是指標 | 問排便習慣改變、血便、體重減輕 |
| **胰臟癌** | 深部悶痛、往背放射、不明體重減輕 | 問痛的位置與有無穿透到背、有無黃疸 |
| 卵巢癌 | 60 歲停經女性、腹脹型腹痛常被當腸胃問題 | 問腹圍變化、早飽感 |

# 3. 焦點式病史

**本題的病史就是整場考試。** 情境沒給的，全部要問出來。

## 先把主訴補完整（LQQOPERA 全套，不能省）

**L 部位**——**痛在哪裡？請用手指出來，或者用手比出範圍。**（一點 vs 一片；上腹 vs 下腹 vs 側腹）
會不會往別的地方跑？**往背後？往右肩？往鼠蹊？**（往背 → 胰臟或後腹腔；往右肩 → 膽道）

**Q 性質**——悶痛、絞痛、灼痛、還是脹？**「痛在裡面」還是「痛在表面」？**

**Q 程度**——最痛幾分？平常幾分？**有沒有痛到睡不著或半夜痛醒？**（夜間痛醒是器質性疾病的重要指標）

**O 時序**——兩個月前怎麼開始的？是突然還是慢慢的？
**這兩個月是越來越痛、一樣、還是有起有落？**
一天當中什麼時候比較痛？

**P 誘發**——**跟吃東西有沒有關係？吃完多久痛？**（餐後 30–60 分鐘 → 膽道；空腹痛、進食緩解 → 十二指腸潰瘍；吃油膩加重 → 膽道或胰臟）

**E 緩解**——什麼會讓它好一點？**前傾或抱膝會不會比較舒服？**（胰臟）制酸劑有沒有效？排便後會不會緩解？（大腸來源）

**R 相關症狀（全部必問）**
- **體重這兩個月掉了幾公斤？**（最重要的一題。有意或無意？）
- 食慾如何？**會不會吃一點就飽？**（早飽感 → 腹腔佔位或卵巢病灶）
- **排便習慣有沒有改變？大便形狀有沒有變細？有沒有血便或黑便？**
- 有沒有黃疸、茶色尿、灰白便、皮膚癢？
- 有沒有噁心嘔吐？
- 有沒有發燒、夜間盜汗？
- **肚子有沒有變大、褲子有沒有變緊？**（腹水）
- 停經後有沒有再出血？

## 本題特有、必須主動問的（情境埋的線索）

- **「您媽媽是 B 型肝炎帶原者，那您自己有驗過 B 型肝炎嗎？結果如何？有沒有在追蹤、多久做一次超音波？」**
  → 這一題是本題的分水嶺。問到了，你抓到了情境埋的線索；沒問到，第三順位診斷你根本不會想到。
- 應酬喝酒是多久一次、喝多少、喝了幾年？
- 有沒有 C 型肝炎、有沒有輸過血、有沒有刺青？
- 家族有沒有人得過癌症？（父母資料情境有給，但沒提癌症，要主動問兄弟姊妹）
- **有沒有做過大腸鏡或糞便潛血檢查？**（台灣 50–74 歲有兩年一次的公費糞便潛血篩檢，60 歲的她應該被通知過）
- 18 歲那次車禍開刀是開哪裡？（右大腿骨折——**這是骨科手術不是腹部手術，所以沾黏性腸阻塞的可能性低**，這條線索的作用是排除，不是支持）

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| 沒有腹部手術史（車禍開的是大腿） | **降低沾黏相關的慢性腹痛** |
| 沒有體重減輕、食慾正常 | 顯著降低惡性腫瘤（但不排除） |
| 沒有黃疸、茶色尿 | 降低膽道阻塞與進展期肝膽腫瘤 |
| 沒有血便、排便習慣未變 | 降低大腸癌 |
| 沒有夜間痛醒、痛不影響睡眠 | 降低器質性疾病，往功能性方向移動 |

# 4. 焦點式身體評估

慢性腹痛的身評重點與急症不同：**找腫塊、找肝脾腫大、找腹水、找轉移徵象**，而不是找腹膜刺激徵。

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| 一般外觀與營養狀態 | 全身、顳肌、鎖骨上窩 | 「我先看您整體的狀況，特別是有沒有變瘦，目的是評估這兩個月的營養變化。」 | 依實際而定 | 消瘦、顳肌凹陷 → 惡病質 |
| **鞏膜、皮膚、手掌** | 雙眼鞏膜、皮膚、手掌 | 「我要看您的眼白、皮膚跟手掌，目的是檢查有沒有黃疸和肝臟疾病的表現。」 | 無黃染 | **蜘蛛痣、肝掌、黃疸 → 慢性肝病（呼應 B 肝那條線索）** |
| **鎖骨上淋巴結觸診** | **左側**鎖骨上窩 | 「我要摸您左邊鎖骨上方，目的是檢查淋巴結有沒有腫大，因為腹部的腫瘤會轉移到這個位置。」 | 陰性 | **摸到硬結 → 腹腔惡性腫瘤已遠端轉移** |
| 腹部視診 | 腹部、腹股溝、疤痕 | 「我要看您的肚子，目的是看有沒有脹起來、有沒有疤痕、有沒有明顯的血管浮起來。我會注意隱私。」 | 平坦、**大腿有疤但腹部無疤** | 腹壁靜脈曲張 → 門脈高壓 |
| 腸蠕動音聽診 | 四象限 | 「我用聽診器聽腸子的聲音，目的是判斷腸道蠕動正不正常。我會先聽再壓。」 | 正常 | — |
| **腹部叩診含移動性濁音** | 四象限、兩側翻身 | 「我要輕敲您的肚子，等一下請您側個身我再敲一次，目的是檢查肚子裡有沒有積水。」 | 陰性 | **移動性濁音陽性 → 腹水 → 肝硬化或腹膜轉移** |
| **肝臟觸診與叩診（肝濁音界）** | 右上腹、右肋緣 | 「我要摸您右上腹肝臟的位置，請您深吸氣再吐氣。目的是確認肝臟有沒有腫大或摸到硬塊。」 | 正常 | **肝腫大、表面不平、質地硬 → 肝硬化或肝腫瘤** |
| **脾臟觸診** | 左上腹 | 「我要摸您左上腹脾臟的位置，一樣請配合深呼吸，目的是檢查脾臟有沒有腫大。」 | 摸不到（正常） | **脾腫大 → 門脈高壓** |
| 腹部深部觸診找腫塊 | 四象限 | 「我要稍微用力壓深一點，目的是摸摸看有沒有摸得到的腫塊。會不舒服請告訴我。」 | 依實際而定 | 摸到搏動性腫塊 → 主動脈瘤 |
| Murphy's sign | 右上腹肋緣 | 「我把手放在您右上腹肋骨下面，請深吸一口氣，目的是檢查膽囊有沒有發炎。」 | 陰性（慢性期常陰性） | 陽性 → 膽囊炎 |
| **肛門指診** | 肛門直腸 | 「我需要做肛門指診，目的是檢查直腸有沒有摸得到的腫瘤和有沒有出血。這個會不舒服但很快，我會拉上簾子並請同仁陪同。您同意嗎？」 | 陰性、糞便潛血陰性 | 摸到硬塊或潛血陽性 → 大腸直腸腫瘤 |

> **本題最容易被漏掉的三項：左鎖骨上淋巴結、移動性濁音、脾臟觸診。** 這三項在急性腹症用不到，但在慢性腹痛裡它們是分辨「良性」與「惡性／肝硬化」的關鍵。

# 5. 需安排的檢查

## 階段一：床邊立即

- 生命徵象、體重（**與病人自述的兩個月前體重比對**）
- **糞便潛血檢查**——目的是 rule out 大腸腫瘤出血。極便宜、非侵入，本題必做
- 尿液常規

## 階段二：非侵入性、無輻射

- **腹部超音波** ← **本題的關鍵檢查，而且優先度極高**
  - 目的：**一次回答多條線**——肝臟有無腫瘤、有無肝硬化型態、有無腹水；膽囊有無結石與發炎；膽管有無擴張；胰臟頭部有無腫塊；腎臟；**以及卵巢與骨盆腔有無腫塊**
  - 預期發現：依真正的診斷而定
  - 陰性時下一步：超音波在胰臟（受腸氣遮蔽）與大腸（超音波看不到）這兩處敏感度不足，正常不能排除這兩者
  - 升級條件：見肝內佔位、膽管擴張、胰臟腫塊、或腹水 → 立即安排 CT／MRI 與腫瘤標記
- **胸部 X 光**：肺部轉移初步篩檢

## 階段三：有輻射／侵入性

- **腹部骨盆電腦斷層（含顯影劑）**
- **大腸鏡**
- **上消化道內視鏡**

> **這一題的順序值得講清楚：超音波先做，因為它一次掃過肝、膽、胰、腎、卵巢五條線，沒有輻射、成本低、而且門診當天就能排。**
>
> 但我**不會**說「超音波夠用就不做進一步檢查」，因為超音波有兩個明確的盲區：
> 1. **胰臟**常被腸氣遮蔽，看不清楚是常態
> 2. **大腸腔內的病灶超音波根本看不到**
>
> 所以本題的邏輯是：**超音波是第一線的篩，不是最後的答案。**
> 若超音波乾淨但病人有體重減輕、糞便潛血陽性、或排便習慣改變 → **大腸鏡是必須的，不能因為超音波正常就停手。**
> 若超音波見肝內佔位或胰臟腫塊 → 升級 CT／MRI 做分期。
>
> **這一題最危險的錯誤，是做了一次正常的超音波就跟病人說「沒事」。**

# 6. 檢驗

**常規（1 小時內）**

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| CBC/DC | **Hb ↓ 小球性貧血 → 慢性腸道失血，往大腸癌移動**；血小板 ↓ → 脾功能亢進／肝硬化 |
| **AST/ALT/ALP/GGT/T-Bil/D-Bil** | 異常 → 往肝膽移動。**ALP、GGT ↑ 而 Bil 正常也可能是肝內佔位** |
| **Albumin、PT/INR** | ↓／延長 → **肝合成功能下降，肝硬化的證據** |
| Lipase | ↑ → 胰臟 |
| BUN/Cr/電解質 | 基礎評估 |
| CRP、ESR | 慢性發炎 |

**本題特有（因為情境埋了 B 肝線索）**

| 項目 | 說明 |
| :--- | :--- |
| **HBsAg、Anti-HBs、Anti-HBc** | **這是本題最該加驗的一組。** 母親是帶原者，她自己的狀態必須確認 |
| Anti-HCV | 一併排除 C 肝 |
| **AFP（胎兒蛋白）** | 若 B 肝帶原成立，這是肝癌篩檢的標準組合（AFP ＋ 超音波） |

**其他腫瘤標記**：CEA（大腸）、CA-125（卵巢）、CA 19-9（胰膽）
> ⚠️ **腫瘤標記不能用來診斷也不能用來排除。** 它們的角色是「已經有影像發現時的輔助」與「治療後的追蹤基準」。口試若被追問，一定要主動講出這個限制，不要讓委員覺得你在亂槍打鳥。

# 7. 前三個鑑別診斷

> ⚠️ **本題的前三名信心度低於其他題，因為主訴幾乎是空白的。** 下面的排序建立在「60 歲女性 ＋ 兩個月慢性腹痛 ＋ 情境給的風險因子」，一旦問出疼痛位置與伴隨症狀，順序很可能整個重排。**這一點在口試要主動說出來，那是誠實，不是沒把握。**

## ① 主診斷：慢性膽囊炎／症狀性膽結石

**支持證據**
- 60 歲、女性、已停經、有生育史——膽結石的風險族群【已知＋推論】
- 兩個月**反覆而非持續**的腹痛，符合膽絞痛間歇發作的型態【推論，需問診確認】
- 良性且常見，在慢性腹痛裡是機率最高的一個

**不支持之處（誠實列，本題特別多）**
- **情境完全沒有提供疼痛位置。** 這個診斷目前建立在流行病學而不是症狀，這很弱。
- 沒有進食油膩誘因、沒有右肩放射、沒有噁心嘔吐的資料。
- **它之所以排第一，主要是因為它常見，不是因為證據支持。** 只要問出疼痛在下腹或往背穿透，它立刻掉出前三。

**確診依據**
腹部超音波見膽結石，且疼痛型態符合膽絞痛（餐後、右上腹、往右肩胛放射、數小時緩解）。

---

## ② 次可能：大腸癌

**為什麼它還留在名單上**
**60 歲這個年齡本身就是理由。** 台灣大腸癌發生率高，且 50–74 歲有公費糞便潛血篩檢，代表這是一個在這個年齡必須主動排除的疾病，不需要任何額外理由。
慢性腹痛、腹脹、排便習慣改變都是常見表現，而且病人常自己歸因為「腸胃不好」拖上好幾個月——**兩個月正是這種拖延的典型長度**。

**要出現什麼證據，它才會翻上第一位**
1. **糞便潛血陽性**（門診當天就能有的答案，成本極低）
2. **排便習慣改變、大便變細、間歇血便**
3. **不明原因體重減輕**
4. CBC 見**小球性貧血**（慢性腸道失血）
5. 肛門指診摸到腫塊

**翻上來的臨床意義**：從「安排超音波追蹤」變成「**必須做大腸鏡**」。而且這個翻盤只需要一張糞便潛血——**如果沒做，超音波正常就跟病人說沒事，會漏掉整個大腸。**

---

## ③ 不能排除：肝細胞癌

**這一格放的是漏掉會出事的診斷，而且本題的線索是情境刻意埋的。**

**為什麼即使機率不是最高，仍必須主動排除**
- **母親是 B 型肝炎帶原者。** 以病人的出生年代（約 1960 年代），台灣尚未實施新生兒 B 肝疫苗接種（1984 年才開始），**母嬰垂直感染的機會很高**。
- 情境同時給了**「應酬時偶喝酒」**——B 肝帶原 ＋ 飲酒是肝硬化與肝癌的加成風險。
- **肝癌早期幾乎沒有症狀。** 等到出現腹痛，往往已經是腫瘤長到一定大小、撐開肝包膜，或已經合併肝硬化。
- 最危險的情境是：把她的腹痛當成腸胃問題處理兩個月，而她從來沒有人問過她是不是 B 肝帶原。

**排除它的最低限度**
> **一次腹部超音波 ＋ 一組 HBsAg 與 AFP。**

就這樣。不需要一開始就做 CT 或 MRI。這三項合起來是台灣肝癌篩檢的標準組合，門診當天可完成，成本低。
**若 HBsAg 陽性 → 她從此需要規律追蹤（一般為每 6 個月超音波 ＋ AFP），這件事的價值可能超過這次腹痛本身。**
若超音波見肝內佔位或 AFP 顯著上升 → 升級動態顯影 CT 或 MRI。

# 8. 口試委員最可能追問的五題

**Q1「情境只給你『腹痛兩個月』，你怎麼開始？」**
> 我會先承認我手上幾乎沒有主訴的資訊，所以第一件事是把 LQQOPERA 完整問一遍，特別是位置、與進食的關係、以及有沒有夜間痛醒。
> 同時我會用兩個月這個時間尺度來調整框架——這是慢性腹痛，所以我優先想的不是穿孔和阻塞，而是**惡性腫瘤和慢性器官疾病**，並且會主動問體重、排便習慣和食慾這三項。

**Q2「情境給了一大段家族史和過去史，你覺得哪一句最重要？」**
> **「母親是 B 型肝炎帶原者。」**
> 病人 60 歲，出生在台灣還沒有新生兒 B 肝疫苗的年代，母親是帶原者代表她自己很可能是垂直感染的帶原者，而且很可能從來沒有規律追蹤。
> 這一句話把肝細胞癌放進了我的鑑別診斷，而排除它只需要一次超音波加上 HBsAg 和 AFP。**如果我沒問這一句，我根本不會想到要驗。**

**Q3「那 18 歲車禍開刀那句話呢？」**
> 那一句的作用是**排除**不是支持。她開的是右大腿骨折，是骨科手術，不是腹部手術。
> 所以術後沾黏造成的慢性腹痛在她身上機率很低。情境裡不是每一句都在指向診斷，有些是用來關掉一條路的，我會分清楚。

**Q4「如果超音波都正常，你就跟病人說沒事嗎？」**
> 不會。超音波有兩個明確的盲區：胰臟常被腸氣擋住看不清楚，大腸腔內的病灶超音波根本看不到。
> 所以如果超音波正常，但她有體重減輕、糞便潛血陽性、或排便習慣改變，**大腸鏡還是必須做**。
> 這一題我覺得最危險的錯誤，就是做了一次正常的超音波就讓病人回家。

**Q5「請向病人解釋。」**
> 阿姨，您這個肚子痛已經兩個月了，時間不算短，我想把可能的原因一次查清楚，不要讓您一直跑。
> 今天我會先安排腹部超音波，這個檢查不會痛也沒有輻射，可以一次看肝臟、膽囊、胰臟、腎臟還有骨盆腔。同時抽血看肝功能、貧血，還有留一份大便檢查看有沒有看不見的出血。
> 另外我想特別跟您說一件事——您提到媽媽是 B 型肝炎帶原者，那您自己有沒有驗過？因為在您這個年紀出生的人，很可能從媽媽那邊帶到，而且很多人一輩子沒有症狀。這次我想順便幫您驗一下，如果有，之後固定追蹤就好，不用太緊張，但一定要知道。
> 如果這期間您開始變瘦、大便變細或有血、或者痛到晚上睡不著，請提早回來。

**SBAR 骨幹**
- **S**：60 歲女性，腹痛兩個月，門診就診。
- **B**：18 歲車禍右大腿骨折開刀（非腹部手術），停經 10 年，偶爾應酬飲酒，蝦子過敏。**母親為 B 型肝炎帶原者。**
- **A**：（依問診與理學填）疼痛位置 ___、體重變化 ___、排便習慣 ___；理學：鎖骨上淋巴結 ___、肝脾 ___、移動性濁音 ___、肛門指診 ___。**最可能為慢性膽囊炎或症狀性膽結石，但此判斷主要依流行病學，證據薄弱**；因病人 60 歲，**大腸癌必須主動排除**；因母親為 B 肝帶原者且病人有飲酒史，**肝細胞癌不能排除**。
- **R**：建議腹部超音波、糞便潛血、CBC/DC、肝膽功能、Albumin、PT/INR、**HBsAg／Anti-HCV／AFP**。若糞便潛血陽性或有排便習慣改變、體重減輕，安排大腸鏡。
