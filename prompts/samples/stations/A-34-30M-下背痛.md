# A-34｜30 歲男性，下背痛

> Prompt A 輸出（**新版十節格式，委員不提問，權責邊界已校正**）。
> 臨床內容未經人工審核，第 9 節疑點尚未查證。
> 本題為分流時的「邊界案例」——主診斷屬風濕免疫科，但骨科門診常見，且需與機械性背痛鑑別。

## 輸入情境（SP 63 例 #34）

30 歲男性，下背痛。
兩年前開始有下背痛，剛開始以為是坐姿不良或運動傷害，只要休息便會好，但是症狀一直持續，甚至於受到天氣影響，天冷或潮濕下背痛會更加劇。起初去找中醫推拿、拔罐、熱療，感覺有點效果。這兩年來也看過骨科或復健科醫師，照過 X 光和抽血檢查都說是正常，雖然吃止痛藥及接受物理治療，但仍沒有改善，心情異常沮喪。活動時（打打球、跑跑步、游泳、爬山）會稍微減輕。在坐著看書或打電腦一陣子後會更痛。最近下背痛已經會影響穿襪子鞋子或彎腰撿東西感到困難，背看起來有點駝。

---

# 1. 情境事實清單

- 30 歲男性
- **下背痛兩年**，持續未緩解
- 起初以為坐姿不良或運動傷害
- 天冷或潮濕會加劇
- 中醫推拿、拔罐、熱療**感覺有點效果**
- **看過骨科與復健科，X 光和抽血檢查都說正常**
- **止痛藥與物理治療皆無改善**
- **心情異常沮喪**
- **活動時（打球、跑步、游泳、爬山）會稍微減輕**
- **久坐（看書、打電腦）後會更痛**
- **最近已影響穿襪子鞋子、彎腰撿東西困難**
- **背看起來有點駝**

**情境未給**：**晨間僵硬的時間長度**、**有沒有夜間痛醒（尤其後半夜）**、有沒有臀部交替疼痛、**有沒有眼睛紅痛畏光**、有沒有腹瀉或血便、有沒有乾癬、有沒有腳跟痛、家族史、發燒體重減輕。

---

# 2. 第一印象與危險分流

**這一題的整個答案，藏在一組對比裡。**

情境把**發炎性下背痛**的特徵幾乎全部寫出來了，而它們和一般人以為的「腰不好」正好相反：

| | **發炎性（本例）** | 機械性（一般腰痛） |
| :--- | :--- | :--- |
| **活動 vs 休息** | **活動會改善**（打球、跑步、游泳會減輕） | 活動會加重 |
| **久坐** | **久坐會更痛** | 久坐通常較舒服 |
| 發病年齡 | **年輕（< 40 歲）** | 任何年齡 |
| 病程 | **慢慢開始，超過 3 個月** | 常有明確起始事件 |
| 晨僵 | **超過 30 分鐘** | 短暫或無 |
| 夜間 | **後半夜痛醒，起來動一動才好** | 較少 |
| 對 NSAID 的反應 | **通常反應良好** | 不一定 |

**「活動會改善、久坐會更痛」這一組是本題最關鍵的線索**，而且它就寫在情境裡。
一個 30 歲男性、兩年慢性下背痛、活動改善休息加重——**這是僵直性脊椎炎的典型敘述**。

**「照過 X 光和抽血檢查都說是正常」不是排除，而是本題的陷阱**【推論】：
- **早期僵直性脊椎炎的薦腸關節變化，X 光看不出來**——結構性破壞要好幾年才會顯現
- 一般的抽血（CBC、生化）本來就不會異常；**發炎指標也可能正常**
- 所以「檢查正常」只代表**做錯了檢查**，不代表沒病

**「背看起來有點駝」＋「彎腰穿襪子困難」是壞消息**【推論】：這代表**脊椎活動度已經開始受限**，疾病不只是在痛，已經在影響結構與功能。這讓「單純肌筋膜疼痛」的解釋站不住。

**「心情異常沮喪」不是背景**：兩年、看過多科、吃藥復健都沒用、還被告知「檢查都正常」——這是**被延誤診斷的病人的典型心理狀態**。這一項在溝通上必須被回應。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| **脊椎感染或腫瘤（red flag）** | 進行性、休息不緩解的背痛 | 問發燒、體重減輕、夜間持續痛、癌症史、靜脈藥癮 |
| **急性前葡萄膜炎** | 僵直性脊椎炎最常見的關節外表現，**會影響視力** | **問眼睛有沒有紅、痛、畏光、視力模糊** |
| 神經壓迫／馬尾症候群 | 任何背痛都要排 | 問下肢無力、鞍狀麻木、大小便改變 |

# 3. 焦點式病史（5 分鐘，優先順序由上而下）

## 最優先的五題（發炎性下背痛的核心）

1. **「早上起來背會不會僵硬？僵多久才鬆開？」**
   → **晨僵超過 30 分鐘是發炎性的關鍵指標。** 情境完全沒問到這一題
2. **「晚上會不會痛醒？尤其是後半夜？醒來以後是躺著比較好，還是起來動一動比較好？」**
   → **後半夜痛醒、起來活動才緩解，是發炎性下背痛的特異表現**
3. **「屁股會不會痛？是左右兩邊輪流痛嗎？」**
   → **交替性臀部疼痛指向薦腸關節炎**
4. **「吃消炎止痛藥有沒有效？」**
   → 情境說「止痛藥無效」，但**必須問清楚吃的是普拿疼還是消炎止痛藥（NSAID）**。
   **僵直性脊椎炎對 NSAID 通常反應良好，對普拿疼則不一定**——這個差別很關鍵
5. **「眼睛有沒有紅過、痛過、怕光、或看東西霧霧的？」** ← **關節外表現篩檢，會影響視力**

## 關節外表現（本題必問，情境完全沒給）

| 問題 | 對應 |
| :--- | :--- |
| **眼睛紅痛畏光、視力模糊** | **急性前葡萄膜炎**——最常見的關節外表現 |
| 長期腹瀉、血便、腹痛 | 發炎性腸道疾病 |
| 皮膚有沒有脫屑的紅斑？指甲有沒有凹點？ | 乾癬 |
| **腳跟痛、阿基里斯腱處痛** | 附著點炎（enthesitis） |
| 手指或腳趾整根腫起來像香腸 | 指炎（dactylitis） |
| 有沒有其他關節腫痛？ | 周邊關節炎 |

## Red flag（必問）

- 有沒有**發燒、體重減輕、夜間盜汗**？
- 有沒有癌症病史？
- **有沒有下肢無力、麻木？屁股會陰部有沒有麻？大小便有沒有改變？**
- 有沒有使用靜脈毒品、有沒有免疫低下、有沒有長期使用類固醇？
- 有沒有近期外傷？

## 其他必問

- **家族有沒有人有僵直性脊椎炎、乾癬、發炎性腸道疾病、虹彩炎？**
- 兩年來背痛的位置有沒有往上跑？（脊椎受影響的範圍）
- 胸口會不會痛？**深呼吸時胸廓會不會覺得撐不開？**（肋椎關節受影響）
- 抽菸嗎？（抽菸會加速結構破壞）
- **「這兩年看了很多科都說正常，您心情怎麼樣？」** → 回應那句「心情異常沮喪」

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| 沒有發燒、體重減輕、夜間盜汗、癌症史 | **降低脊椎感染與腫瘤** |
| 沒有下肢無力、鞍狀麻木、大小便改變 | **降低馬尾症候群** |
| 沒有腳往下放射的痛 | 降低椎間盤突出併坐骨神經痛 |
| 沒有明確外傷或搬重物起始事件 | 降低單純機械性背痛 |
| 沒有眼睛紅痛、無腹瀉血便、無乾癬 | 降低其他脊椎關節病變（但不排除 AS 本身） |

# 4. 焦點式身體評估（5 分鐘，最多 8 項）

| 必做？ | 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **必做** | **站姿與脊椎曲線視診（側面）** | 全脊椎、骨盆 | 「請您脫掉上衣站直，我從側面和後面看您整個背的曲線。目的是評估脊椎的排列和有沒有駝背或側彎。」 | **胸椎後凸增加（駝背）、腰椎前凸變平** | 側彎 → 結構性脊椎側彎 |
| **必做** | **脊椎主動活動度（前彎、後仰、側彎、旋轉）** | 腰椎 | 「請您慢慢往前彎去摸腳趾、再往後仰、往兩邊側彎、轉身，能到哪裡就停。目的是評估脊椎各個方向的活動受限程度。」 | **多方向受限，尤其前彎與側彎** | 只有單一方向受限 → 較偏機械性 |
| **必做** | **Schober's test（腰椎前彎活動度量化）** | 腰椎 | 「我在您腰上做兩個記號，請您往前彎，我再量一次距離。目的是客觀量出腰椎前彎的活動度，這個數字可以追蹤變化。」 | **增加量減少（受限）** | 正常 → 腰椎活動度尚可 |
| **必做** | **薦腸關節壓痛與誘發試驗** | 雙側薦腸關節 | 「我要按壓您骨盆後方兩側的關節，再請您躺下做幾個腿部的動作。目的是檢查薦腸關節有沒有發炎，那是這類背痛最早侵犯的位置。會痛請告訴我。」 | **薦腸關節壓痛，誘發試驗可能陽性** | 陰性不能排除早期病變 |
| **必做** | **胸廓擴張度** | 第四肋間 | 「我用皮尺量您胸圍，請您用力吸氣再吐氣。目的是測量胸廓能撐開多少，因為這個病會影響肋骨和脊椎的關節。」 | **擴張度減少** | 正常 → 尚未影響肋椎關節 |
| **必做** | **下肢神經學快篩（肌力、感覺、反射）** | 雙下肢 | 「我測您兩腳的力氣、感覺和反射。目的是確認神經有沒有被壓到，這是任何背痛都必須排除的。」 | **正常** | 異常 → 神經壓迫，優先處理 |
| 有時間 | **附著點壓痛** | 阿基里斯腱、足底筋膜、髂嵴、坐骨結節 | 「我要按壓您的腳跟、腳底和骨盆的幾個點。目的是檢查肌腱附著到骨頭的地方有沒有發炎，這是這類疾病的特徵之一。」 | 可能有壓痛 | 陽性支持脊椎關節病變 |
| 有時間 | **眼睛外觀視診** | 雙眼結膜 | 「我看一下您的眼睛，目的是檢查有沒有發紅，因為這個病可能會合併眼睛的發炎。」 | 無紅眼 | **單側紅眼併畏光 → 急性前葡萄膜炎，須立即轉眼科** |

**這一題的檢查順序為什麼這樣排**：**先站著看整體姿勢與活動度，再躺下做薦腸關節與神經學**——這樣病人只需要換一次姿勢。
而且**視診放第一個是刻意的**：情境已經寫了「背看起來有點駝」，這是最快能確認的客觀證據，也是說服病人「這兩年不是你的錯覺」最有力的一句話。

# 5. 需安排的檢查

## 階段一：診間立即

- 完整脊椎理學檢查（上一節）
- **Schober's test 與胸廓擴張度的數值**——這兩項是可追蹤的客觀基準
- 生命徵象含體溫

## 階段二：抽血

- **CRP、ESR**——發炎指標。**注意：僵直性脊椎炎的病人有相當比例發炎指標是正常的，正常不能排除**
- CBC/DC、生化、腎功能（用藥前基準）
- **HLA-B27**
  - ⚠️ **這一項要講清楚它的角色**：**HLA-B27 不是診斷標準，也不能用來確診或排除。**
    它是一個**風險關聯基因**——陽性提高機率，但一般人群也有一定比例是陽性；
    而且**陰性也不能排除僵直性脊椎炎**。它的價值是在臨床已高度懷疑時**增加支持度**。

## 階段三：影像

- **薦腸關節 X 光（骨盆正面或專門的薦腸關節照）**
  - 目的：看薦腸關節有無**硬化、糜爛、關節腔變窄或融合**
  - **⚠️ 本題最關鍵的一點：結構性變化需要數年才會在 X 光上出現，早期病人 X 光是正常的。**
    **情境說「照過 X 光正常」，很可能就是這個原因——不是沒病，是看不到。**
- **薦腸關節磁振造影（MRI）** ← **本題真正需要的檢查**
  - 目的：**偵測 X 光還看不到的早期發炎（骨髓水腫）**
  - 無輻射
  - **這是「X 光正常但臨床高度懷疑」時的正確下一步**

> **這一題的檢查排序，重點不是「先做便宜的」，而是「別再重複做那個已經正常的檢查」。**
>
> 病人這兩年**已經照過 X 光、抽過血，而且都被告知正常**。
> 如果我再開一次一樣的檢查，只會再得到一次正常的報告，然後他第三年還在這裡。
>
> **正確的思路是問：為什麼那些檢查會正常？**
> 答案是**做的檢查本身看不到早期的病變**——一般抽血不會異常，X 光要等結構破壞才看得到。
>
> 所以我的順序是：
> 1. **先靠病史與理學檢查建立臨床懷疑**（發炎性下背痛的特徵 ＋ 活動度受限 ＋ 駝背）
> 2. **抽 CRP、ESR、HLA-B27**——但要先說明這三項都不能單獨確診或排除
> 3. **建議醫師考慮安排薦腸關節 MRI**，因為那是唯一能看到早期發炎的工具
>
> **我不會為了「保險起見」再照一次腰椎 X 光。** 那不會給我新資訊，只會多一次輻射與一次失望。

# 6. 檢驗

| 項目 | 往哪走支持什麼 |
| :--- | :--- |
| **CRP、ESR** | ↑ 支持發炎性過程。**⚠️ 但相當比例的病人是正常的，正常不能排除** |
| **HLA-B27** | 陽性**提高**機率。**⚠️ 不是診斷標準，陰性不能排除，陽性也不能確診** |
| CBC/DC | 慢性發炎可致輕度貧血；也是用藥前基準 |
| 生化、肝腎功能 | **NSAID 或生物製劑用藥前的基準值** |
| 類風濕因子、抗環瓜胺酸抗體 | **通常為陰性**——這正是「血清陰性脊椎關節病變」名稱的由來。驗它是為了**排除類風濕性關節炎** |
| 尿酸 | 若懷疑合併其他關節問題 |
| **B 型肝炎、C 型肝炎、結核篩檢** | **若未來可能使用生物製劑，這些是必要的前置篩檢**。可在此時一併提出建議 |

# 7. 前三個鑑別診斷

## ① 主診斷：僵直性脊椎炎（中軸型脊椎關節病變）

**支持證據（本題支持證據很強，幾乎全部寫在情境裡）**
- **30 歲男性**——好發年齡與性別【已知】
- **病程兩年（> 3 個月），慢慢開始**【已知】
- **活動時（打球、跑步、游泳、爬山）會減輕**【已知】
- **久坐後會更痛**【已知】
- **物理治療與止痛藥無效**【已知】
- **已出現脊椎活動度受限**：穿襪子、彎腰撿東西困難【已知】
- **背看起來有點駝**——結構性變化已經開始【已知】
- **熱療有效**（中醫推拿拔罐熱療「感覺有點效果」）——符合發炎性背痛對熱與活動的反應【已知】
- 預期：Schober's test 受限、胸廓擴張度減少、薦腸關節壓痛【推論】

**不支持之處（誠實列）**
- 情境**完全沒有提到晨間僵硬的時間長度**——這是發炎性下背痛最核心的指標之一，必須問診補上。
- 情境**沒有提到夜間痛醒**——同上。
- 情境**沒有任何關節外表現的資訊**（眼睛、腸道、皮膚、腳跟）。
- **沒有家族史資訊。**
- **「止痛藥無效」需要釐清是哪一種**——僵直性脊椎炎對消炎止痛藥（NSAID）通常反應良好。若他吃的是普拿疼，「無效」反而不矛盾；**若確實對足量 NSAID 也無效，這個診斷要打折扣。**

**確診依據**
> 依現行分類標準綜合判斷：**發炎性下背痛的臨床特徵 ＋ 影像（薦腸關節 X 光或 MRI 見薦腸關節炎）＋ HLA-B27 與其他脊椎關節病變特徵。**
> **沒有任何單一檢查可以確診。**（正式標準請見第 9 節，需查證）

---

## ② 次可能：慢性機械性下背痛／肌筋膜疼痛症候群

**為什麼它還留在名單上**
這是下背痛最常見的原因，而且情境給了背景：他一開始就以為是**坐姿不良或運動傷害**，而且**推拿拔罐熱療有效**——這些都符合肌筋膜疼痛。
兩年來看過骨科、復健科，**X 光與抽血都正常**，也符合這個診斷（機械性背痛本來就不會有影像與抽血異常）。

**要出現什麼證據，它才會翻上第一位**
1. **問出晨僵很短或沒有、夜間不會痛醒**
2. **問出活動其實會加重、休息才緩解**（與情境相反，需親自確認而不是照抄）
3. 觸診可找到明確**激痛點且能重現疼痛**
4. **Schober's test 與胸廓擴張度正常**
5. **薦腸關節壓痛陰性，MRI 無骨髓水腫**
6. 沒有任何關節外表現與家族史

**翻上來的臨床意義**：從「轉介風濕免疫科、長期抗發炎藥物甚至生物製劑」變成「**運動治療、姿勢調整、核心肌群訓練**」。
**而且對這位病人來說，這個翻盤要非常小心**——他已經被「檢查都正常」打發兩年了。**再一次歸因於姿勢，等於再浪費他一年。**

> ⚠️ **本題最重要的臨床判斷**：**「活動會改善、久坐會加重」這一組，機械性背痛解釋不了。**
> 所以除非問診後發現情境的描述有誤，否則我不會把它放第一位。

## ③ 不能排除：急性前葡萄膜炎（虹彩炎）等關節外表現

**這一格放的不是另一個背痛的原因，而是同一個疾病在別的器官上的表現——而它會傷害視力。**

**為什麼必須主動排除**
- **急性前葡萄膜炎是僵直性脊椎炎最常見的關節外表現**
- **它可能在背痛之前、之中、之後任何時候發作**
- **病人不會把眼睛的問題和背痛聯想在一起**——眼睛紅他會去看眼科，背痛他來看骨科，**兩邊都不知道另一邊的事**
- **延誤治療可能造成視力損害**，而這是不可逆的
- 同樣要一併問的還有：**發炎性腸道疾病**（長期腹瀉血便）、**乾癬**、**附著點炎**（腳跟痛）

**排除／篩檢的最低限度**
> **問一句話 ＋ 看一眼眼睛。**
>
> **問**：「眼睛有沒有紅過、痛過、怕光、或看東西霧霧的？」
> **看**：雙眼結膜有沒有發紅（尤其是**角膜周圍的環狀充血**）
>
> 這一項不需要任何儀器、不到 20 秒。
> **若有紅眼併畏光或視力模糊 → 立即通知醫師並協助轉介眼科，這是不能等的。**

> **順帶一提**：僵直性脊椎炎長期還可能影響**主動脈根部與心臟傳導系統**，以及造成**骨質疏鬆與脊椎骨折風險上升**。這些在第一次評估不必全查，但**應該讓病人知道這是一個全身性疾病，需要長期追蹤**，而不是「腰的問題」。

## 8b. 向口試委員報告鑑別診斷（約 3 分鐘）

> 報告委員。這位是 30 歲男性，主訴是**下背痛已經兩年**。
>
> 病史方面最關鍵的是疼痛的型態：**他打球、跑步、游泳、爬山的時候會減輕，反而久坐看書或打電腦之後會更痛**。這一組特徵和一般的機械性腰痛正好相反，**是發炎性下背痛的典型表現**。
> 加上他是 30 歲男性、病程超過三個月、慢慢開始、**止痛藥與物理治療都無效，但熱療有一點效果**，這些都往同一個方向指。
> 我特別追問了幾項情境沒有提供的：**早上僵硬多久才鬆開、後半夜會不會痛醒、屁股會不會兩邊輪流痛**，答案分別是 ___、___、___。我也釐清了他吃的止痛藥是普拿疼還是消炎止痛藥，因為**這個病對消炎止痛藥通常反應良好**，這個差別會影響判斷。
> 另外我主動問了關節外的表現——**眼睛有沒有紅過痛過怕光、有沒有長期腹瀉血便、皮膚有沒有脫屑紅斑、腳跟會不會痛**，答案是 ___。這幾項病人不會主動聯想到背痛，一定要問。
>
> 身體評估方面，**視診可見胸椎後凸增加、腰椎前凸變平**，也就是情境提到的駝背；脊椎多方向活動受限；**Schober's test 為 ___**；**胸廓擴張度為 ___**；薦腸關節壓痛 ___；下肢神經學檢查 ___。
>
> 綜合以上，**我認為最可能的健康問題是僵直性脊椎炎，也就是中軸型的脊椎關節病變**。理由是完整的發炎性下背痛特徵，加上已經出現**客觀的脊椎活動度受限與姿勢改變**——他穿襪子、彎腰撿東西已經有困難，背也駝了。**這代表疾病不只是在痛，已經在影響結構與功能。**
>
> **第二個可能是慢性機械性下背痛或肌筋膜疼痛症候群。** 它還在名單上是因為這是下背痛最常見的原因，而且推拿拔罐熱療對他有效。**但有一點機械性背痛解釋不了——他是活動會改善、久坐會加重。** 所以除非問診後發現這個描述有誤，我不會把它放第一位。**如果晨僵很短、夜裡不會痛醒、Schober 與胸廓擴張度正常、薦腸關節也沒有壓痛，那它才會翻上來**，處置就會變成運動治療與姿勢調整。
>
> **另外我認為必須主動排除的是急性前葡萄膜炎。** 它不是另一個背痛的原因，而是**同一個疾病在眼睛的表現，而且會傷害視力**。最麻煩的地方是**病人不會把眼睛紅和背痛聯想在一起**——眼睛不舒服他去看眼科，背痛他來看骨科，兩邊都不知道另一邊的事。**排除它只需要問一句話加看一眼眼睛，不到二十秒。**
>
> **關於檢查，我想特別說明一件事。** 這位病人**這兩年已經照過 X 光、抽過血，而且都被告知正常**。如果我再開一次一樣的檢查，只會再得到一次正常的報告。
> **所以要問的是：為什麼那些檢查會正常？** 答案是**做的檢查本身看不到早期病變**——一般抽血不會異常，而**薦腸關節的結構破壞要好幾年才會在 X 光上顯現，早期病人 X 光就是正常的**。
> 因此我會**向主治醫師報告我的評估發現，並建議考慮安排薦腸關節的磁振造影**，因為那是唯一能看到早期發炎的工具。同時建議抽 CRP、ESR 與 HLA-B27，**但這三項我都會註明它們的限制——發炎指標可能正常，而 HLA-B27 不是診斷標準，陰性不能排除、陽性也不能確診。**
> 我不會為了保險起見再照一次腰椎 X 光，那不會給新資訊。
>
> 最後我想提一件事：情境寫他「**心情異常沮喪**」。看了兩年、換了好幾科、吃藥復健都沒用、還一直被告知檢查正常——**這是被延誤診斷的病人很典型的狀態**，我認為這一點需要在說明時被正面回應。報告完畢。
