# A-27｜28 歲男性，右上腹部疼痛

> Prompt A 輸出。**臨床內容未經人工審核**，第 9 節疑點尚未查證。

## 輸入情境（SP 63 例 #27）

28 歲男性，右上腹部疼痛。
因今早突然發生右上腹部疼痛，吃了一顆止痛藥無效之後到附近診所看病，在診所打上大瓶點滴及兩次止痛針仍不見效，診所醫師建議他趕快去急診就診，在抵達急診時距離開始疼痛已有七、八個小時。
過去除了高血壓之外身體狀況良好。目前未婚，不抽菸、不喝酒、不吃檳榔。無藥物或食物過敏、無特殊家族史、無特殊嗜好。不曾做過健康檢查。

---

# 1. 情境事實清單

- 28 歲男性
- **今早突然發生**右上腹部疼痛
- 口服止痛藥無效
- 診所給予大量點滴 ＋ **兩次止痛針仍不見效**
- 到急診時病程約 7–8 小時
- 過去病史：**高血壓**（28 歲即有高血壓，這一點本身值得追問）
- 未婚、不抽菸、不喝酒、不吃檳榔
- 無藥物食物過敏、無特殊家族史
- **不曾做過健康檢查**

**情境未給**：生命徵象、發燒與否、噁心嘔吐、疼痛性質與放射、飲食誘因、血尿、排便狀況、高血壓用藥。

---

# 2. 第一印象與危險分流

**「兩次止痛針仍不見效」是這一題的訊號。** 一般肌肉骨骼疼痛或功能性腹痛，打了止痛針多少會鬆一點。完全無反應，代表背後是持續性、進行性的病理過程，而不是自限性的不適。

**「突然發生」＋ 28 歲男性 ＋ 右上腹**，這個組合要先想到的順序和 50 歲女性完全不一樣。28 歲是**泌尿道結石的高峰年齡**，而膽結石在這個年紀的男性相對少見。所以不能一看到右上腹就自動跳到膽囊。

另外，**28 歲就有高血壓**本身是個伏筆。年輕型高血壓要想到次發性原因，其中腎臟疾病（包括多囊腎）與腹痛可以連在一起。這一條情境給了但很容易被忽略。

30 秒內要擺上檯面：

| 危險診斷 | 為什麼要想到 | 怎麼快速壓下去 |
| :--- | :--- | :--- |
| 消化道穿孔 | 突發劇痛、止痛無效的典型表現 | 腹部有無板硬、立姿 CXR |
| 急性胰臟炎 | 上腹突發劇痛，止痛困難 | Lipase |
| 腎/輸尿管結石併阻塞 | 28 歲男性最常見的突發側腹痛 | 尿液常規、超音波看水腎 |
| 急性膽囊炎/膽絞痛 | 右上腹痛的經典 | 超音波、Murphy's sign |
| 主動脈剝離 | 年輕高血壓病人不能完全不想 | 問疼痛性質（撕裂）、量雙上肢血壓 |

# 3. 焦點式病室

**L 部位**——最痛的一點在哪？請用手指出來。**痛會不會往背後、往右肩、或往鼠蹊部與睪丸放射？**（往右肩胛 → 膽道；往鼠蹊睪丸 → 輸尿管；穿透到背 → 胰臟或後腹腔）

**Q 性質**——**是一陣一陣絞痛還是持續劇痛？**（絞痛且痛起來坐立難安 → 結石；持續加重且不敢動 → 腹膜炎）；有沒有撕裂或刀割的感覺？（剝離）

**Q 程度**——現在幾分？【已知：止痛針兩次無效】

**O 時序**——今早**幾點、在做什麼的時候**突然開始？是瞬間到最痛，還是慢慢爬上去？（瞬間到頂 → 穿孔或血管事件；漸進 → 發炎）

**P 誘發**——發作前有沒有吃油膩的東西？（膽道）；有沒有大量飲酒？（胰臟炎，但本例不喝酒）；有沒有搬重物或外傷？

**E 緩解**——**什麼姿勢比較舒服？**（前傾抱膝緩解 → 胰臟炎；完全不敢動 → 腹膜炎；一直翻身找姿勢 → 結石。這一題的答案本身就有鑑別力）

**R 相關症狀（本題必問，情境完全沒給）**
- 有沒有發燒、畏寒？
- 有沒有噁心嘔吐？吐了幾次？
- **小便會不會痛、有沒有血尿、頻尿？**（輸尿管結石）
- 眼白有沒有變黃、小便有沒有變茶色？（膽道阻塞）
- 有沒有解黑便、嘔血？（潰瘍出血）
- 有沒有排氣排便？

**A 伴隨表現**——有沒有胸悶、冒冷汗、喘？有沒有咳嗽？（右下肺炎可表現為右上腹痛）

**必問的 pertinent negative**

| 問到「沒有」 | 排除／降低什麼 |
| :--- | :--- |
| 沒有血尿、沒有放射到鼠蹊、痛起來不會躁動 | 降低輸尿管結石 |
| 沒有油膩飲食誘因、沒有以前類似發作 | 降低膽絞痛 |
| 沒有長期胃痛、沒有服 NSAID、沒有解黑便 | 降低消化性潰瘍穿孔 |
| 沒有大量飲酒 | 降低酒精性胰臟炎（本例已知不喝酒） |

**其他必問（本題特有）**
- **高血壓從幾歲開始？有沒有在吃藥？吃什麼？**（28 歲的高血壓不正常，要問次發性原因；同時 NSAID 類止痛藥也會影響血壓）
- **家族有沒有人洗腎、有沒有多囊腎？**（年輕高血壓 ＋ 側腹痛的組合）
- 這幾天自己吃了什麼止痛藥、吃了多久？（NSAID 引起潰瘍）
- 職業、最近有沒有劇烈運動或外傷

# 4. 焦點式身體評估

| 檢查項目 | 部位 | 說做合一口白 | 本例預期發現 | 若為其他診斷會見到 |
| :--- | :--- | :--- | :--- | :--- |
| 一般外觀與姿勢 | 全身 | 「我先觀察您現在的姿勢和表情，目的是判斷疼痛的型態，因為不同原因的痛，病人會用不同姿勢。」 | 冒冷汗、表情痛苦 | **一直翻身找姿勢 → 結石**；**完全不敢動 → 腹膜炎**；前傾抱膝 → 胰臟炎 |
| 鞏膜與皮膚 | 雙眼鞏膜、皮膚 | 「我看一下您的眼白和皮膚顏色，目的是檢查有沒有黃疸。」 | 無黃染 | 膽管阻塞：黃染 |
| **雙上肢血壓** | 雙側上臂 | 「我要量您兩隻手的血壓，目的是比較左右差異，排除主動脈的問題。」 | 兩側對稱 | 主動脈剝離：兩側差距大 |
| 腹部視診 | 腹部、腹股溝 | 「我要看您的肚子外觀，目的是看有沒有脹起來、有沒有疤痕或局部凸起，也會看鼠蹊部。」 | 腹部平坦、隨呼吸起伏 | 穿孔：腹部不隨呼吸起伏 |
| 腸蠕動音聽診 | 四象限 | 「我用聽診器聽腸子聲音，目的是判斷腸道蠕動狀況。先聽再壓。」 | 正常或略減弱 | 腹膜炎：消失 |
| 腹部觸診 | 四象限，右上腹最後 | 「我要從離痛最遠的地方開始輕壓，目的是找出最痛的位置。會痛請馬上說。」 | 右上腹局部壓痛 | 上腹中央深部壓痛 → 胰臟炎 |
| **Murphy's sign** | 右上腹肋骨下緣 | 「我把手放在您右上腹肋骨下方，請深吸一口氣。目的是檢查膽囊有沒有發炎，吸氣時痛到停住請告訴我。」 | 陽性或陰性皆可能 | 陽性支持膽囊炎 |
| 反彈壓痛與肌肉防衛 | 右上腹、全腹 | 「我要壓下去再快速放開，目的是看腹膜有沒有發炎，可能會不舒服。」 | 局部輕微 guarding | **全腹板硬 → 穿孔** |
| 肝區叩診 | 右上腹肋緣 | 「我用手指輕敲您右上腹，目的是確認肝臟的大小和位置。」 | 肝濁音界正常 | **穿孔：肝濁音界消失** |
| **右側肋脊角叩擊痛** | 右後腰肋脊角 | 「請稍微側身，我要輕敲您右後腰，目的是檢查腎臟和輸尿管有沒有發炎或阻塞。」 | **本題必做，陽性即翻盤** | **結石／腎盂腎炎：陽性** |
| 心肺聽診 | 心尖區、雙肺底 | 「我聽一下心音和呼吸音，目的是排除心臟和右下肺的問題也會表現成上腹痛。」 | 正常 | 右下肺炎：右下肺囉音 |

> 必做全部。本題的 **CVA 叩擊痛不可省**——它是區分「膽道」與「泌尿」兩條完全不同路線的最便宜工具。

# 5. 需安排的檢查

## 階段一：床邊立即

- **尿液常規**——目的是 rule in/out 輸尿管結石與泌尿道感染。**這是本題 CP 值最高的一項**，五分鐘、幾乎零成本，卻能一口氣把第二順位診斷拉上或壓下。預期：無血尿（若有明顯血尿，②立刻翻上第一）。
- **POCT 血糖**
- **12 導程 EKG**：28 歲、無胸痛，優先度低。若病史問出胸悶冒冷汗才做。

## 階段二：非侵入性、無輻射

- **腹部超音波** ← **本題的關鍵檢查**
  - 目的：**一次回答兩個問題**——膽囊有沒有結石與發炎（膽囊壁 > 3 mm、周圍積液、sonographic Murphy），以及**右側腎臟有沒有水腎**（輸尿管阻塞的間接證據）
  - 預期發現：依真正的診斷而定
  - 陰性時下一步：兩邊都乾淨 → 重新往消化性潰瘍、胰臟炎、早期闌尾炎（後位／高位）方向想
  - 升級條件：見總膽管擴張或膽紅素上升 → MRCP
- **立姿胸部 X 光**：橫膈下游離氣體（穿孔）＋ 右下肺炎。預期陰性。

## 階段三：有輻射／顯影劑

- **腹部電腦斷層／非顯影 CT（結石протокол）**

> **本題我不排 CT，因為腹部超音波一次就回答了膽道與泌尿兩條路線的問題**，而這兩條正是 28 歲男性右上腹痛的前兩大來源。超音波沒有輻射、床邊可做、對膽結石與水腎都很敏感。
>
> 只有在下列情況才升級到 CT：
> 1. 超音波膽道與腎臟皆正常，但病人持續劇痛且止痛無效（病灶還沒找到）
> 2. 出現腹膜刺激徵或懷疑穿孔、膿瘍
> 3. 高度懷疑輸尿管結石但超音波看不到（此時用**非顯影低劑量 CT**，不必打顯影劑）
> 4. 血行動力學不穩

# 7. 前三個鑑別診斷

## ① 主診斷：急性膽囊炎／症狀性膽結石

**支持證據**
- 主訴明確為**右上腹部**疼痛【已知】
- **突然發生**且持續 7–8 小時未緩解【已知】——單純膽絞痛多在 6 小時內緩解，超過就要想已進展為膽囊炎
- **強效止痛（兩次針劑）無效**，符合持續性發炎而非陣發性痙攣【已知】
- 預期 Murphy's sign 陽性、右上腹局部壓痛【推論】

**不支持之處（本題要誠實講）**
- **28 歲男性不是膽結石的典型族群。** 這個診斷排第一，靠的是「痛在右上腹」這個位置，而不是流行病學。
- 情境**沒有提供任何飲食誘因、過去類似發作、發燒、噁心嘔吐**——膽道診斷最重要的支持證據全部缺席，必須靠問診補回來。
- 情境未提供生命徵象，無法判斷有無發燒。

**確診依據**
腹部超音波見膽結石 ＋ 膽囊壁增厚 > 3 mm ＋ sonographic Murphy 陽性，併 WBC/CRP 上升。

---

## ② 次可能：右側輸尿管結石併阻塞

**為什麼它還留在名單上——而且威脅性很高**
**28 歲男性是泌尿道結石的高峰年齡**，比膽結石常見得多。而結石最有名的特徵正是本題明文寫著的那一句：**強效止痛藥打了兩次仍然無效**。腎絞痛的止痛困難是出了名的。

換句話說，這個診斷之所以排第二而不是第一，只是因為主訴寫的是「右上腹」而不是「右腰」。**而右側上段輸尿管結石的痛，完全可以表現在右上腹。**

**要出現什麼證據，它才會翻上第一位**
1. **尿液常規見血尿**（最快、最便宜的一項）
2. 痛會**放射到右鼠蹊部或睪丸**
3. 病人痛起來**躁動、一直換姿勢**（膽囊炎與腹膜炎病人相反，愈不動愈好）
4. **右側 CVA 叩擊痛陽性**
5. 超音波見**右側水腎**

**翻上來的臨床意義**：處置從「禁食、抗生素、外科會診評估膽囊切除」變成「**大量輸液、積極止痛、依結石大小決定觀察或泌尿科介入**」。方向完全相反，而且膽囊炎的禁食對結石病人是錯的。

---

## ③ 不能排除：上消化道穿孔（消化性潰瘍穿孔）

**這一格放的是漏掉會死人的診斷。**

**為什麼即使機率低仍必須主動排除**
- **突發、劇烈、止痛無效**——這三個特徵是穿孔的典型描述，本題三個全中
- 病人「不曾做過健康檢查」，代表若有潛在的消化性潰瘍或幽門螺旋桿菌感染，**沒有人知道**
- 穿孔初期（化學性腹膜炎期）病人可能還走得動、生命徵象還撐得住，最容易被當成膽絞痛收進觀察室
- 一旦進入細菌性腹膜炎期，死亡率大幅上升

**排除它的最低限度**
> **腹部理學（有無板硬、腸音是否消失、**肝濁音界是否消失**）＋ 一張立姿胸部 X 光。**

只要這兩項乾淨，穿孔的機率就低到可以往下走。若腹部已板硬或見橫膈下游離氣體 → 立即停止一切非必要檢查，通知外科準備手術。

# 8. 口試委員最可能追問的五題

**Q1「28 歲男性右上腹痛，你為什麼把膽囊炎放第一而不是結石？」**
> 老實說這兩個非常接近，我把膽囊炎放第一是因為主訴明確寫在右上腹。但 28 歲男性正是結石的高峰年齡，而且「兩次止痛針無效」是腎絞痛的典型特徵。
> 所以我不會用猜的，我會用一張尿液常規來決定順序——這是五分鐘、幾乎零成本的檢查，卻能直接把第二順位拉上來或壓下去。

**Q2「打了兩次止痛針無效，這件事對你的判斷有什麼意義？」**
> 它告訴我這不是自限性的功能性疼痛。一般的腸胃不適或肌肉骨骼疼痛，止痛針多少有反應。完全無效代表背後是持續進行的病理過程——發炎、阻塞、或穿孔，這三類都需要影像確認，而且都可能需要外科介入。

**Q3「病人 28 歲就有高血壓，你會問什麼？」**
> 我會問從幾歲開始、有沒有在服藥、家族裡有沒有人洗腎或有多囊腎。年輕型高血壓要想次發性原因，而腎臟疾病同時可以解釋高血壓和側腹痛。這條線索情境有給，但很容易被當成無關的背景資料跳過。

**Q4「你為什麼不直接開電腦斷層？」**
> 因為腹部超音波一次就回答了這一題最重要的兩個問題——膽囊有沒有發炎、右側腎臟有沒有水腎。這兩個正好對應我的第一和第二順位診斷。超音波沒有輻射、可以床邊做、對膽結石和水腎都很敏感。
> 我會在超音波兩邊都乾淨但病人仍持續劇痛、或出現腹膜刺激徵的時候才升級到 CT。而且如果是為了找輸尿管結石，用的是非顯影的低劑量 CT，不需要打顯影劑。

**Q5「請向病人解釋。」**
> 先生，您右上腹這個痛已經七八個小時，連止痛針都壓不下來，代表不是單純的腸胃不舒服，我們必須找出原因。
> 最常見的兩個可能，一個是膽囊或膽結石發炎，一個是右邊的輸尿管有結石卡住。這兩個的處理方式不一樣，所以我會先請您驗一次尿，再安排腹部超音波，這兩項都不會痛，超音波也沒有輻射。
> 同時我會抽血看發炎的程度和胰臟、肝膽的功能。在結果出來之前請先不要吃東西喝水。
> 如果痛的範圍從右上腹擴散到整個肚子、或者痛到完全不敢動、開始發燒，請馬上告訴我。

- **B**：過去僅高血壓，不菸不酒不嚼檳榔，無過敏史，從未健檢。
- **A**：（依理學結果填）右上腹局部壓痛、Murphy's sign ___、CVA 叩擊痛 ___、無全腹板硬、肝濁音界存在。**最可能為急性膽囊炎或症狀性膽結石**；因病人 28 歲且止痛無效，**右側輸尿管結石不能排除**；因突發劇痛且止痛無效，**須主動排除上消化道穿孔**。

# 9. 我不確定的地方

1. **28 歲男性膽結石的實際盛行率**——我判斷「不典型」，但台灣的年齡分布可能與教科書不同（飲食型態差異），這個排序請以你的臨床經驗校正。
2. **超音波偵測水腎以間接診斷輸尿管結石的可靠度**——我知道水腎是間接證據而非結石本身，但敏感度數字沒有把握，不要講百分比。
3. **非顯影低劑量 CT 是否為台灣急診診斷結石的常規**——我不確定各院實務與健保給付。
4. **年輕型高血壓要不要在 15 分鐘的口試裡追問**——這條線索確實在情境裡，但可能被委員視為離題。你比我清楚委員的偏好。
5. **「兩次止痛針」是什麼藥**——情境沒說。若是 NSAID（如 Ketorolac），對結石效果通常不錯，無效反而更奇怪；若是 Buscopan 這類抗痙攣藥，無效就不代表什麼。這一點值得在口試主動點出，但我不確定台灣診所的常規用藥。
6. **穿孔初期是否一定看得到橫膈下游離氣體**——我知道有一定比例看不到，但比例多少沒有把握，所以文中寫成「若見到即確認」，沒有寫「沒見到即排除」。
